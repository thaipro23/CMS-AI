# v25.9.16.7.2.50 — Bank Quiz Final Test Production QA

## Mục tiêu

Bản này tiếp tục từ `.45` và bổ sung dashboard SLA vận hành cho pipeline học online:

```text
tracking.log ingest → post-ingest recalculate → behavior snapshot → UI /analytics/learning
```

Mục tiêu là để UAT/production test biết hệ thống đang chạy chậm ở tầng nào mà không phải đọc Docker log thủ công.

## Thay đổi chính

- Thêm endpoint read-only `GET /api/analytics/ops/sla`.
- SLA dùng dữ liệu đã materialize: checkpoint ingest, normalized events, `academic_class_sync_jobs`, behavior snapshots và roster AP.
- Không đọc raw `tracking.log` trong request.
- Không enqueue job trong request.
- Không tính lại snapshot trong request.
- UI `/analytics/learning` có panel `SLA vận hành analytics` với:
  - Ingest gần nhất.
  - Snapshot gần nhất.
  - Event trong 1 giờ gần nhất.
  - Job recalculate active/success/failed.
  - Số lớp có roster nhưng thiếu/stale snapshot.
  - Danh sách lớp cần ưu tiên tính lại.
- Thêm env SLA target để tuning UAT/production.
- Không có migration mới.

## Env nên set

```env

ANALYTICS_SLA_INGEST_TARGET_SECONDS=300

ANALYTICS_SLA_MAX_QUEUED_JOBS=50
ANALYTICS_SLA_MAX_FAILED_JOBS_LAST_HOUR=0

```

## Deploy

```bash
cd /opt/ai-server
unzip -o ai-server-openedx-v25.9.16.7.2.50-bank-quiz-final-test-production-qa.zip -d /tmp/ai-server-v25.9.16.7.2.50
rsync -a --delete /tmp/ai-server-v25.9.16.7.2.50/ai_server_openedx_v25_9_16_7_2_47/ /opt/ai-server/
docker compose -f docker-compose.prod.yml --env-file .env.production build backend frontend worker beat
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend worker beat
```
