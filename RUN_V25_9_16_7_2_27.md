# v25.9.16.7.2.27 — Learning Behavior Logic Calibration

## Mục tiêu

Nâng cấp logic đánh giá học online theo hướng rule engine có bằng chứng, không kết luận vi phạm/gian lận. UI vẫn chỉ hiển thị nhãn mềm.

Luồng giữ nguyên:

```text
tracking.log → normalized events → video/quiz/session features → behavior snapshot → UI
```

## Thay đổi chính

1. Video quality score:
   - Không cộng riêng completion và watch percent.
   - Dùng `consistency = 1 - abs(completion - watch)`.
   - Dùng `video_quality = min(completion, watch) * consistency`.

2. Dynamic watch cap:
   - Không cap cứng 600s cho mọi đoạn play.
   - Chỉ cap mạnh khi đoạn play dài và không có tương tác.
   - Feed `LONG_PASSIVE_PLAYBACK` vào idle score.

3. Suspicious score theo tỷ lệ:
   - `suspicious_video_count / total_video_count`.
   - `quiz_before_video_count / total_quiz_sessions`.
   - `crammed_low_watch_count / total_completed_sessions`.
   - `suspicious_quiz_speed_count / total_quiz_attempts`.

4. Quiz attempt parser:
   - Parse `/api/unit-reset/v1/quiz-session/start|status|reset`.
   - Parse `edx.itembankblock.content.assigned`.
   - Parse `edx.grades.problem.submitted` làm canonical submission.
   - Parse `problem_show` / `showanswer` theo chính sách neutral.
   - Không dùng event `user_id=null` để tính hành vi cá nhân.

5. Session typing:
   - `LEARNING_SESSION`.
   - `FINAL_TEST`.
   - `ASSIGNMENT`.
   - `SUPPLEMENTARY`.
   - `UNKNOWN`.
   - Final test / Assignment không tính như bài học online thường.

6. Internal label:
   - Ghi mới `POSSIBLE_ANOMALY`.
   - Vẫn đọc được snapshot cũ `POSSIBLE_CHEATING`.
   - UI vẫn hiển thị: `Dấu hiệu bất thường cần kiểm tra`.
