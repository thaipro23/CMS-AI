## Xuất báo cáo Markdown/JSON

```bash
cd /opt/ai-server
API_BASE_URL=https://api-ai.cms-test.poly.edu.vn/api \
TOKEN='<TOKEN>' \
BRANCH=poly \
CAMPUS=ph \
TERM_ID='<TERM_ID>' \
OUT_DIR=/tmp/analytics-course-class-mapping-$(date +%Y%m%d-%H%M%S) \
./scripts/analytics-course-class-mapping-report.sh
```

## Kỳ vọng

- `READY`: có thể pilot theo scope.
- `READY_WITH_WARNINGS`: mapping rõ nhưng còn thiếu event/snapshot, xử lý qua orchestrator/doctor.
- `BLOCKED`: thiếu mapping, ambiguous mapping hoặc course có event nhưng không resolve được class.
