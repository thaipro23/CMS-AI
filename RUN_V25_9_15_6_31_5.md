# v25.9.15.6.31.5 — Chapter Action Buttons + System Font Polish

## Scope
- Frontend only.
- No database migration.

## Changes
- Makes chapter workspace actions more visible: Tài liệu, Tạo câu hỏi, Duyệt câu hỏi, Kiểm tra thay đổi, Chốt/Publish/Đã publish.
- Uses system UI font stack globally to avoid odd question-card font rendering.
- Resets question cards, answers, explanation and metadata to inherit system font.
- Keeps the modern white UI from v31.x.

## Deploy
```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

Then hard refresh the browser with Ctrl+F5.
