# v25.9.16.5.7 — Student Insight HMAC + Vietnam Timezone Hotfix

## Purpose

Fix full CMS sync failure at `/api/ai-student-insight/v1/users/resolve`:

```text
403 Forbidden
Không tạo/kiểm tra được tài khoản CMS trước khi enrollment
```

Root cause in Ulmo/Tutor deployments is usually that the Student Insight endpoints are called on LMS (`cms-test.poly.edu.vn`) but the HMAC settings were only injected into CMS/Studio settings. LMS must also know the same secret.

## AI Server env

```env
OPENEDX_STUDENT_INSIGHT_BASE_URL=http://cms-test.poly.edu.vn
OPENEDX_LMS_BASE_URL=http://cms-test.poly.edu.vn
OPENEDX_CMS_BASE_URL=http://scms-test.poly.edu.vn
OPENEDX_MFE_BASE_URL=http://app.cms-test.poly.edu.vn

OPENEDX_CONNECTOR_HMAC_SECRET=<same-secret>
OPENEDX_STUDENT_INSIGHT_SHARED_SECRET=<same-secret>
```

## Tutor/Open edX env

Copy the updated Tutor plugin:

```bash
cp tutor-plugins/ai_learning_connector_env.py "$(tutor plugins printroot)/ai_learning_connector_env.py"
tutor plugins enable ai_learning_connector_env

tutor config save --set AI_CONNECTOR_HMAC_SECRET='<same-secret>'
tutor config save --set AI_STUDENT_INSIGHT_SHARED_SECRET='<same-secret>'

tutor local restart lms cms lms-worker cms-worker
```

The plugin now patches both:

```text
openedx-lms-common-settings
openedx-cms-common-settings
```

## Deploy AI Server

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Test HMAC from AI backend

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production exec -T backend python - <<'PY'
from app.services.openedx_student_insight import OpenEdXStudentInsightClient

client = OpenEdXStudentInsightClient()
print('configured=', client.configured())
print('base_url=', client.base_url)
print('endpoint=', client.endpoint)
print('student_secret_len=', len(client.shared_secret or ''))
print('connector_secret_len=', len(client.connector_secret or ''))

rows = client.resolve_users([
    {'username': 'test_not_existing_zzzz', 'student_code': 'TEST0000', 'full_name': 'Test User'}
], create_missing=False)
print(rows[:1])
PY
```

Expected: no 403. Missing user is fine; HMAC must pass.
