# v25.9.16.5.46 — Training Management Teacher Report + Excel Export

## Mục tiêu

Bổ sung bước tiếp theo cho AI Server: **Quản lý đào tạo** theo giảng viên.

Màn mới cho phép quản trị/đào tạo xem một giảng viên đang dạy bao nhiêu lớp, bao nhiêu sinh viên, sinh viên học như nào trên CMS/Open edX, và xuất báo cáo Excel.

## Thay đổi chính

### 1. Backend API

Thêm endpoint:

```text
GET /api/academic/training/teachers
GET /api/academic/training/teachers/export
```

Báo cáo hỗ trợ filter:

```text
term_id
branch
campus
search
learning_status
page
page_size
```

Nguồn dữ liệu dùng lại bảng hiện có, không thêm migration:

```text
academic_teachers
academic_teacher_assignments
academic_classes
academic_class_students
openedx_user_mappings
academic_student_learning_snapshots
academic_course_mappings
academic_class_course_mappings
```

### 2. Chỉ số theo giảng viên

Mỗi giảng viên có:

- số môn đang dạy
- số lớp đang dạy
- số sinh viên theo lượt lớp
- số sinh viên riêng biệt
- số user đã đồng bộ CMS
- số sinh viên đã enroll CMS
- số sinh viên có hoạt động học tập
- Course completion trung bình
- điểm tổng trung bình hệ 10
- số lớp chưa map Course CMS
- số sinh viên cần theo dõi
- phân bố trạng thái học tập:
  - chưa đồng bộ CMS
  - chưa enroll
  - chưa học
  - tiến độ thấp
  - điểm thấp
  - lỗi đồng bộ
  - đang học
  - ổn

### 3. Frontend

Thêm route:

```text
/training-management
```

Thêm menu sidebar:

```text
Quản lý đào tạo
```

Màn có:

- bộ lọc hệ/kỳ/cơ sở/trạng thái/tìm kiếm
- KPI tổng quan
- bảng giảng viên
- nút xem chi tiết lớp của từng giảng viên
- nút xuất Excel

### 4. Xuất Excel

Endpoint export trả file:

```text
training-management-teacher-report.xlsx
```

File gồm 4 sheet:

1. `TongQuanGV`
2. `ChiTietLop`
3. `SinhVienCanTheoDoi`
4. `HuongDan`

`SinhVienCanTheoDoi` liệt kê sinh viên có trạng thái cần xử lý:

- chưa đồng bộ CMS
- chưa enroll
- chưa học
- tiến độ thấp
- điểm thấp
- lỗi đồng bộ

Điểm tổng trong Excel đã quy đổi sang hệ 10.

## Deploy

Bản này sửa backend + frontend, không có Alembic migration.

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Kiểm tra sau deploy

1. Vào `/training-management`.
2. Chọn hệ/kỳ/cơ sở.
3. Kiểm tra mỗi giảng viên có đúng số lớp, sinh viên, enroll, completion, điểm hệ 10.
4. Bấm `Xem lớp` để xem chi tiết từng lớp.
5. Bấm `Xuất Excel`.
6. Mở file Excel kiểm tra 4 sheet:
   - tổng quan giảng viên
   - chi tiết lớp
   - sinh viên cần theo dõi
   - hướng dẫn

## Ghi chú kỹ thuật

- Không hard-code đầu điểm.
- Không gọi Open edX trực tiếp khi mở báo cáo; báo cáo đọc snapshot đã đồng bộ trong DB.
- Muốn số liệu mới nhất thì chạy `Đồng bộ full CMS` ở lớp/môn trước, sau đó mở báo cáo.
- Quyền truy cập dùng lại academic access filter: admin thấy toàn bộ, giảng viên chỉ thấy scope/lớp được phân công.
