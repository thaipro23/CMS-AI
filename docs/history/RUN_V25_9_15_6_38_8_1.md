# v25.9.15.6.38.8.1 — Header Copy Cleanup Hotfix

Bản này tinh gọn phần header và hero dashboard theo yêu cầu người dùng.

## Đã sửa

- Xóa chữ `Không gian làm việc` khỏi header.
- Xóa chip `Scope theo phân quyền` khỏi header.
- Xóa nút `Phiên làm việc` khỏi header.
- Xóa mô tả phụ như `Việc cần xử lý` khỏi header.
- `/bank` hero chỉ còn tiêu đề chính: `Tổng quan Ngân hàng đề`.
- Đổi `Scope:` trong Dashboard thành `Phạm vi:`.
- Cập nhật footer version lên `.38.8.1`.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic heads

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Env

```env
APP_VERSION=25.9.15.6.38.8.1-header-copy-cleanup-hotfix
```
