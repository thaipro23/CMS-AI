# Run v25.9.15.6.38.8.4 - Search Index Drilldown Performance Guard

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic heads

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Set:

```env
APP_VERSION=25.9.15.6.38.8.4-search-index-drilldown-performance-guard
```

## Check search index health

```bash
curl -s "http://api-ai.cms-test.poly.edu.vn/api/question-bank-v2/admin/search/health" \
  -H "Authorization: Bearer <TOKEN>" | python3 -m json.tool
```

If `missing_or_unindexed_count` is greater than `0`, rebuild the index:

```bash
curl -X POST "http://api-ai.cms-test.poly.edu.vn/api/question-bank-v2/admin/search/rebuild" \
  -H "Authorization: Bearer <TOKEN>" | python3 -m json.tool
```
