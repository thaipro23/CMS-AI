# v25.9.16.5.49 — AP Relearn + Class Sync 500 Fix + ACMS UI Polish

## Mục tiêu

Bản này sửa trực tiếp các lỗi/ý kiến sau từ UAT:

- AP student payload có `total_relearn` nhưng AI Server chưa lưu/hiển thị.
- Job `academic.class_sync.async` lỗi: `AcademicService._snapshot_has_learning_activity() takes 1 positional argument but 2 were given`.
- API `GET /api/academic/teacher/subjects?...` có thể trả `500 Internal Server Error` vì lỗi method trên.
- Workspace bài ở Bank đang có thanh thao tác sticky đi theo khi cuộn, bo góc quá lớn và font quá đậm so với ACMS.

## Sau deploy cần kiểm tra

1. Chạy lại AP sync để lấy `total_relearn` mới từ AP.
2. Mở `/student-management/classes/{classId}` kiểm tra cột `Học lại`.
3. Mở `/training-management` kiểm tra KPI/bảng học lại và xuất Excel.
4. Gọi lại `GET /api/academic/teacher/subjects?...` không còn 500.
5. Vào `/bank/chapters/{id}` kiểm tra thanh `Bài học` không còn sticky, bo góc/font gọn hơn.
