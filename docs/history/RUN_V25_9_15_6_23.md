# Run v25.9.15.6.23

## 1. Deploy AI Server backend/worker/frontend

Bản này có sửa backend + frontend AI Server + connector plugin. Nếu Docker Hub bị timeout khi build frontend, có thể build backend/worker trước, nhưng để cập nhật UI preview material balancing thì nên build frontend khi mạng ổn.

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Không có migration mới.

## 2. Cập nhật connector Open edX

```bash
cp /opt/ai-server/openedx-connector-plugin/openedx_ai_connector/views.py \
  /opt/openedx/CMS-FPT/openedx_connector_plugin/openedx_ai_connector/views.py

tutor local restart cms cms-worker
```

## 3. Build lại Learning MFE với HTTP

Tạo/kiểm tra file env build, ví dụ `.env.production` trong `/opt/openedx/frontend-app-learning`:

```env
BASE_URL=http://app.cms-test.poly.edu.vn/learning
LMS_BASE_URL=http://cms-test.poly.edu.vn
LOGIN_URL=http://cms-test.poly.edu.vn/login
LOGOUT_URL=http://cms-test.poly.edu.vn/logout
REFRESH_ACCESS_TOKEN_ENDPOINT=http://cms-test.poly.edu.vn/login_refresh
STUDIO_BASE_URL=http://scms-test.poly.edu.vn
```

Build bằng Docker Node vì server không có npm:

```bash
cd /opt/openedx/frontend-app-learning

git fetch origin
git checkout mfe-unit-reset
git reset --hard origin/mfe-unit-reset

docker run --rm \
  -v "$PWD":/app \
  -w /app \
  --env-file .env.production \
  node:20-bullseye \
  bash -lc "npm ci && npm run build"

sudo chown -R $(id -u):$(id -g) /opt/openedx/frontend-app-learning

docker cp dist/. tutor_local-mfe-1:/openedx/dist/learning/

tutor local restart mfe
```

Kiểm tra không còn HTTPS cũ:

```bash
docker exec -it tutor_local-mfe-1 sh -lc '
grep -R "https://cms-test.poly.edu.vn" -n /openedx/dist/learning | head -20 || true
grep -R "http://cms-test.poly.edu.vn/login_refresh" -n /openedx/dist/learning | head -20 || true
'
```

## 4. Test nghiệp vụ

### Tạo Quiz

1. Vào `/bank/quiz`.
2. Dán course ID.
3. Chọn version môn.
4. Tạo Quiz 5 câu tỷ lệ 60/20/20.
5. Vào Studio kiểm tra:

```text
Section: Bài 1.1
  Subsection: Quiz 1.1
    Grade as: Quiz
    Unit: Quiz
      Problem Bank EASY    max_count=3
      Problem Bank MEDIUM  max_count=1
      Problem Bank HARD    max_count=1
```

### Tạo câu hỏi theo tài liệu

1. Chapter có nhiều tài liệu.
2. Tạo 30 câu.
3. Kiểm tra response `material_balancing` và danh sách câu hỏi.
4. Mỗi tài liệu phải có quota gần đều nhau.
