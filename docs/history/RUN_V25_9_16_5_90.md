# RUN v25.9.16.5.90 — Sequential-only StudentModule Completion Fix

## Mục tiêu

Sửa dứt điểm lỗi AI Server tính Course completion sai do lấy nhầm StudentModule `itembank/problem` hoặc mẫu số `70`.

Dữ liệu debug thực tế của `course-v1:FPT+COM1071+SU26`:

- Course tree: `sequential = 8`.
- `non_container_blocks = 70` là `problem 50 + video 5 + itembank 15`, không phải mẫu số completion.
- `duongddph69321`: có `StudentModule type=sequential` đúng 5 row với `state={"position":1}` nên CMS tính `5/8 = 62.5% ≈ 63%`.
- `tienpdph69628`: chỉ có 15 row `itembank`, không có `sequential/video/problem` activity thật, nên completion phải là `0/8 = 0%`.

## Thay đổi v90

- Connector version: `25.9.16.5.90`.
- StudentModule fallback không quét toàn bộ rows nữa khi course có subsection/sequential.
- Query nhẹ hơn:
  - chỉ lấy `StudentModule` với `module_type='sequential'`
  - chỉ lấy fields cần dùng: `student_id`, `module_state_key`, `state`, `modified`
- Tử số:
  - count reachable sequential rows của user có `state.position > 0`.
- Mẫu số:
  - count reachable sequential/subsection trong course tree.
- Bỏ hoàn toàn khỏi Course completion fallback:
  - `itembank`
  - `problem`
  - `video`
  - leaf blocks/raw non-container blocks
- Học viên chỉ có `itembank` rows sẽ ra `0/8`, không còn `15/70 = 21.4%`.
- Backend diagnostic note đổi sang rule v90.

## Kiểm tra mẫu số

```bash
COURSE_ID='course-v1:FPT+COM1071+SU26'

tutor local run lms bash -lc "cat > /tmp/debug_connector_v90.py <<'PY'
from opaque_keys.edx.keys import CourseKey
from openedx_ai_connector.student_insight import CONNECTOR_VERSION, _completion_denominator_block_snapshot
course_id='${COURSE_ID}'
k=CourseKey.from_string(course_id)
print('CONNECTOR_VERSION=', CONNECTOR_VERSION)
s=_completion_denominator_block_snapshot(k)
for key in ['eligible_total','subsection_total','leaf_eligible_total','raw_reachable_blocks','non_container_blocks','breakdown_by_type','denominator_source','denominator_rule']:
    print(key, '=', s.get(key))
PY
./manage.py lms shell < /tmp/debug_connector_v90.py"
```

Kỳ vọng course COM1071/SU26:

