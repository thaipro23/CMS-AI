# v25.9.16.4.10 — AP get-course File Cache for get-data-cms

Mục tiêu: `/get-course` chỉ dùng để lấy danh sách mã môn, lưu thành file JSON, rồi `/get-data-cms` đọc danh sách mã môn từ file đó để gọi tiếp. Không lưu catalog môn từ `/get-course` vào DB theo mặc định.

## Luồng mới

```text
1. Sync AP theo kỳ/cơ sở
2. Backend gọi /get-course?branch=poly&term_name=... nếu file cache chưa có hoặc hết hạn
3. Backend chuẩn hóa danh sách mã môn và lưu JSON vào file cache
4. Backend lấy subject_code từ file cache để gọi /get-data-cms theo từng campus + subject_code
5. Chỉ khi /get-data-cms trả lớp có sinh viên hợp lệ thì mới ghi subject/class/student vào DB
6. Bấm sync lại: nếu cache còn hạn, backend không gọi lại /get-course mà đọc file cache
```

## Env khuyến nghị production/UAT

```env
ACADEMIC_AP_SKIP_EMPTY_CLASSES=true
ACADEMIC_AP_IMPORT_CATALOG_SUBJECTS=false

ACADEMIC_AP_GET_COURSE_FILE_CACHE_ENABLED=true
ACADEMIC_AP_GET_COURSE_FILE_CACHE_DIR=/tmp/ai-server-ap-cache/get-course
ACADEMIC_AP_GET_COURSE_FILE_CACHE_TTL_SECONDS=86400
ACADEMIC_AP_GET_COURSE_FILE_CACHE_REFRESH=false
```

Nếu muốn cache sống qua recreate container, mount thư mục host vào container, ví dụ host `/opt/ai-server/.cache/ap-get-course` vào container `/tmp/ai-server-ap-cache/get-course`, hoặc đổi `ACADEMIC_AP_GET_COURSE_FILE_CACHE_DIR` sang một mount volume bền.

## Khi AP đổi catalog môn

Có 2 cách làm mới cache:

```env
ACADEMIC_AP_GET_COURSE_FILE_CACHE_REFRESH=true
```

Recreate backend/worker, chạy sync một lần, sau đó đổi lại:

```env
ACADEMIC_AP_GET_COURSE_FILE_CACHE_REFRESH=false
```

Hoặc xóa file cache:

```bash
rm -rf /tmp/ai-server-ap-cache/get-course
```

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker
```

Không cần migration.

## Kiểm tra file cache trong container

Bấm sync AP một lần, sau đó chạy:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend sh -lc '
find /tmp/ai-server-ap-cache/get-course -type f -maxdepth 1 -name "*.json" -print -exec sh -c "echo --- {}; head -40 {}" \;
'
```

## Kiểm tra sync dùng cache

Chạy sync lần 2, backend sẽ dùng file nếu cache còn hạn. Trong response/audit `subject_source` có thể là:

```text
ap.get-course.file-cache
```

## Kiểm tra DB không phình vì lớp rỗng

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend sh -lc '
python - <<PY
from sqlalchemy import text
from app.db.session import SessionLocal

term_id = "5ad7f095-113f-599c-a5a0-d720fe5f509e"
with SessionLocal() as db:
    print("classes", db.execute(text("SELECT count(*) FROM academic_classes WHERE term_id=:id"), {"id": term_id}).scalar())
    print("class_students", db.execute(text("""
        SELECT count(*)
        FROM academic_class_students cs
        JOIN academic_classes c ON c.id = cs.class_id
        WHERE c.term_id=:id
    """), {"id": term_id}).scalar())
    print("empty_classes", db.execute(text("""
        SELECT count(*)
        FROM academic_classes c
        WHERE c.term_id=:id
          AND NOT EXISTS (
              SELECT 1 FROM academic_class_students cs WHERE cs.class_id = c.id
          )
    """), {"id": term_id}).scalar())
PY
'
```
