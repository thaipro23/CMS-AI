# RUN v25.9.15.6.38.5.3 — DOCX OCR Upload Preflight Feedback Hotfix

## Mục tiêu

Sửa luồng upload tài liệu Bank để:

- File không đọc/tách được text báo lỗi ngay tại popup upload.
- DOCX dạng scan/ảnh có thể OCR khi đã bật `FILE_OCR_ENABLED=true`.
- Worker và frontend trả thông báo lỗi/thành công dễ hiểu hơn cho người dùng.

## Env cần kiểm tra

Trong `.env.production` nên có:

```env
APP_VERSION=25.9.15.6.38.5.3-docx-ocr-upload-preflight-feedback-hotfix
LOCAL_STORAGE_PATH=/app/.runtime

FILE_OCR_ENABLED=true
FILE_OCR_LANGUAGE=vie+eng
FILE_OCR_MAX_PAGES=80
FILE_OCR_TESSERACT_CONFIG=--oem 3 --psm 6
PPTX_EXTRACT_SPEAKER_NOTES=true
PPTX_OCR_IMAGES_ENABLED=true
DOCX_OCR_IMAGES_ENABLED=true
DOCX_OCR_MAX_IMAGES=80
MATERIAL_UPLOAD_PREFLIGHT_ENABLED=true
```

Ghi chú: nếu tài liệu scan DOCX có 65 trang/ảnh, `FILE_OCR_MAX_PAGES=20` chỉ OCR tối đa 20 ảnh đầu. Muốn OCR đủ, đặt `DOCX_OCR_MAX_IMAGES=65` hoặc cao hơn.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic heads

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Test nhanh DOCX OCR/preflight

1. Mở `/bank/chapters/{chapter_id}`.
2. Bấm **Tài liệu**.
3. Upload lại file DOCX.

Kỳ vọng:

- Nếu file đọc được: popup chờ xử lý rồi báo thành công, có chunk tài liệu.
- Nếu file không có text và OCR tắt/sai cấu hình: lỗi hiện ngay tại popup upload, không cần vào audit log.
- Nếu là DOCX scan/ảnh và OCR bật: hệ thống OCR ảnh trong DOCX theo giới hạn `DOCX_OCR_MAX_IMAGES`/`FILE_OCR_MAX_PAGES`.

## Kiểm tra volume runtime dùng chung

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend sh -lc 'echo backend:$LOCAL_STORAGE_PATH; touch $LOCAL_STORAGE_PATH/shared-test.txt; ls -l $LOCAL_STORAGE_PATH/shared-test.txt'

docker compose -f docker-compose.prod.yml --env-file .env.production exec worker sh -lc 'echo worker:$LOCAL_STORAGE_PATH; ls -l $LOCAL_STORAGE_PATH/shared-test.txt'
```

Worker phải thấy được `shared-test.txt`.
