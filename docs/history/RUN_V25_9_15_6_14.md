cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build --no-cache backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

```

## Connector plugin trong CMS/Open edX

Bản này có sửa `openedx-connector-plugin/openedx_ai_connector/views.py` để set `Grade as: Quiz`.

Nếu plugin được mount/copy thủ công vào repo Open edX trên server, copy lại file plugin và restart CMS:

```bash
cp /opt/ai-server/openedx-connector-plugin/openedx_ai_connector/views.py \
  /opt/openedx/CMS-FPT/openedx_connector_plugin/openedx_ai_connector/views.py

tutor local restart cms cms-worker
```

Nếu plugin nằm trong image Open edX thì cần rebuild image theo cách deploy Open edX hiện tại của server.

## Kiểm tra

1. Vào `/bank/quiz`.
2. Dán Course ID ví dụ `course-v1:FPT+WEB107+SU25`.
3. Kiểm tra có phần cấu hình timer.
4. Tạo Quiz cho Section `Bài 1`.
5. Vào Studio kiểm tra:
   - Subsection tên `Quiz 1`
   - Unit tên `Quiz`
   - Grade as = `Quiz`
```
