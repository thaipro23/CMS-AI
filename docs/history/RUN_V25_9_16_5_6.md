# v25.9.16.5.6 — Course Mapping Exact CourseKey Hotfix

## Mục tiêu

Fix auto-map Course CMS khi course thật đã tồn tại trên Open edX/MFE, ví dụ:

```text
http://app.cms-test.poly.edu.vn/learning/course/course-v1:FPT+WEB107+SU26/home
```

nhưng API auto-map vẫn báo không tìm thấy course.

## Nguyên nhân chính

Trên Open edX Ulmo.3, `CourseOverview.id` là `CourseKeyField`. Một số deployment không match ổn định khi query bằng raw string:

```python
CourseOverview.objects.filter(id="course-v1:FPT+WEB107+SU26")
```

Bản này sửa plugin để parse bằng `CourseKey.from_string(...)` trước khi query.

## Thay đổi

- Plugin `openedx_ai_connector` endpoint `POST /api/ai-student-insight/v1/courses/search`:
  - exact lookup dùng `CourseKey.from_string(exact_course_id)`
  - fallback raw string lookup nếu custom deployment cần
- AI Server `OpenEdXStudentInsightClient.find_exact_course(...)`:
  - ưu tiên Student Insight plugin exact search
  - fallback sang LMS Courses API exact detail `/api/courses/v1/courses/<encoded-course-id>/`
  - encode `+` thành `%2B` để tránh proxy/framework hiểu sai

## Deploy AI Server

```bash
cd /opt/ai-server
docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Deploy plugin Open edX

Cần cập nhật `openedx-connector-plugin/openedx_ai_connector` vào LMS/CMS image rồi restart LMS/CMS. Nếu dùng Tutor custom image, rebuild image Open edX sau khi copy plugin.

## Test nhanh trong AI backend

```bash
cd /opt/ai-server
docker compose -f docker-compose.prod.yml --env-file .env.production exec -T backend python - <<'PY'
from app.services.openedx_student_insight import OpenEdXStudentInsightClient
client = OpenEdXStudentInsightClient()
print("configured=", client.configured())
print("base_url=", client.base_url)
print(client.find_exact_course("course-v1:FPT+WEB107+SU26"))
rows = client.search_courses(query="WEB107", exact_course_id="course-v1:FPT+WEB107+SU26", limit=20)
print("count=", len(rows))
for row in rows:
    print(row.get("course_id"), row.get("display_name"))
PY
```

Kỳ vọng: `find_exact_course` trả `course-v1:FPT+WEB107+SU26`.
