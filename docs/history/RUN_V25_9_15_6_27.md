# v25.9.15.6.27 - FPT Light Orange Theme Polish

Bản này chỉ sửa frontend UI theme của AI Server.

## Nội dung

- Màu chủ đạo: cam nhạt + trắng.
- Sidebar sáng, có icon, nhóm menu, active state màu cam.
- /bank/quiz giữ layout workbench 2 cột: kết quả bên trái, settings sticky bên phải.
- Bổ sung style đồng bộ cho card, alert, toggle, option grid, input, table header.

## Deploy

Không cần migrate DB.

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

Nếu cache trình duyệt còn cũ, vào `http://ai.cms-test.poly.edu.vn/bank/quiz` rồi nhấn `Ctrl + F5`.
