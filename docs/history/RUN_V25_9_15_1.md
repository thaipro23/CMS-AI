# Run v25.9.15.1

Build an toàn, không down Open edX:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production build --no-cache backend worker frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --no-deps backend worker frontend
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend alembic upgrade head
```

Test compile trong container backend:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend \
  python -m compileall -q app alembic
```

Test service mapping guard:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend \
  pytest app/tests/test_v25_9_15_1_mapping_guard.py -q -vv
```

Quy trình test UI:

1. Vào `/bank`.
2. Tạo Bộ môn/Môn/Chapter.
3. Tạo Bank Version.
4. Tạo Bank Release.
5. Bấm **Publish Library** để import câu approved vào Open edX Library riêng của release.
6. Nhập Course ID, bấm **Kiểm tra mapping**.
7. Chỉ bấm **Lưu mapping an toàn** khi validate không high risk.
8. Map chapter sau khi release đã `published`.
