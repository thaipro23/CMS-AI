# v25.9.15.6.38.2.4 - RBAC Alembic Headline Hotfix

## Mục tiêu

Sửa lỗi Alembic `Multiple head revisions are present` do hai migration hotfix cùng trỏ về `0023_v25_9_15_6_38_2_1`:

- `0024_v25_9_15_6_38_2_2`
- `0024_v25_9_15_6_38_2_3`

Bản này tuyến tính hóa chain:

```text
0023_v25_9_15_6_38_2_1
  -> 0024_v25_9_15_6_38_2_2
  -> 0024_v25_9_15_6_38_2_3
```

Không đổi schema DB; chỉ sửa `down_revision` của migration `.38.2.3`.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic heads

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Sau khi `alembic heads`, chỉ nên còn một head:

```text
0024_v25_9_15_6_38_2_3
```
