# v25.9.16.5.64 — Immediate Student Table Horizontal Scroll

## Scope

This is a frontend UX hardening package on top of v25.9.16.5.63.

The main fix is for `/student-management/classes/{classId}` when the class has many dynamic Quiz/Detailed grades columns.

## Fixed

- The `Danh sách sinh viên` table now has a synchronized top horizontal scrollbar, so users can scroll horizontally immediately without going to the bottom of the table.
- The table remains wrapped in an `overflow-x: auto` container and keeps iOS smooth scrolling.
- The first column (`Sinh viên`) remains sticky while horizontally scrolling.
- The table wrapper now has left/right shadow indicators to signal hidden columns.
- The horizontal table layout is isolated inside the student-list card and does not widen the whole page.

## Deploy

No Alembic migration.

Frontend-only deployment is enough:

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

Full rebuild is also safe:

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```
