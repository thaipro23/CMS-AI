# v25.9.16.3.3 — Student Management Compact Filters

## Mục tiêu

Gom bộ lọc vào trực tiếp card danh sách để màn hình gọn hơn, không còn card filter riêng phía trên.

## Thay đổi

- `/student-management`: đưa bộ lọc Hệ/Học kỳ/Cơ sở/Tìm môn vào card **Danh sách môn**.
- `/student-management/subjects/{subjectId}/classes`: đưa bộ lọc Block/Tìm lớp vào card **Danh sách lớp**.
- Giữ nguyên toàn bộ logic AP/CMS/Open edX từ v25.9.16.3.2.
- Không thêm migration.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

Nếu muốn build lại đồng bộ toàn bộ stack:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Kiểm tra

- `/student-management`
- `/student-management/subjects/{subjectId}/classes`
