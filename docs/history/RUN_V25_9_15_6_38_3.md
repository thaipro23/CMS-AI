# v25.9.15.6.38.3 — Dashboard Analytics Scope Actionable Redesign

## Mục tiêu

Thiết kế lại `/bank` Dashboard để người dùng nắm được tình trạng thật trong scope được giao và đi thẳng tới màn xử lý.

Phạm vi bản này:

- Dashboard analytics API.
- Dashboard charts UI tự render bằng SVG/CSS, không thêm thư viện chart ngoài.
- Drill-down từ KPI / chart / alert / activity.
- Alert panel.
- Activity feed.
- Time filter: hôm nay / 7 ngày / 30 ngày / tùy chọn.
- Scope enforcement server-side.
- Cache dashboard bằng Redis.

Không làm Export Excel/PDF theo yêu cầu mới.

## API mới

```http
GET /api/question-bank-v2/dashboard/analytics?date_range=30d
GET /api/question-bank-v2/dashboard/analytics?date_range=custom&from_date=2026-06-01&to_date=2026-06-15
GET /api/question-bank-v2/dashboard/alerts?date_range=30d&limit=12
GET /api/question-bank-v2/dashboard/activity-feed?limit=10
```

Response `/dashboard/analytics` gồm:

- `scope`: role/scope label hiện tại.
- `kpis`: tổng câu hỏi, chờ duyệt, đã duyệt, bị từ chối.
- `charts`: trạng thái câu hỏi, câu hỏi mới theo ngày, câu hỏi theo môn, độ khó, loại câu hỏi, so sánh kỳ.
- `alerts`: pending quá hạn, thiếu câu hỏi, job lỗi, user chưa hoạt động.
- `activity_feed`: 10 hoạt động mới nhất trong scope.
- `cache`: trạng thái cache.

## Scope enforcement

Backend dùng `BusinessRBACService` để filter dữ liệu trước khi trả response:

- `SYSTEM_ADMIN`: toàn hệ thống.
- `DEPARTMENT_HEAD`: bộ môn được giao.
- `SUBJECT_OWNER`: môn/version/chapter được giao.
- `QUESTION_REVIEWER`: chỉ môn/chapter được giao duyệt.

Frontend không tự lọc scope.

## Cache

Redis keys:

```text
dashboard:analytics:{scope_hash}:{date_range}:{from}:{to}
dashboard:alerts:{scope_hash}:{date_range}:{from}:{to}:{limit}
dashboard:activity:{scope_hash}:{limit}
```

TTL:

- Analytics: 60s.
- Alerts: 15s.
- Activity: 30s.
