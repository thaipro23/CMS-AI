# v25.9.15.6.6 - Bank Review UI + Release Guard Hotfix

## Mục tiêu

Hotfix này sửa đúng 2 điểm:

1. Danh sách câu hỏi trong `/bank/chapters/{chapterId}` học theo UI của trang `/review`: hiển thị thẻ câu hỏi đầy đủ đáp án A/B/C/D, đáp án đúng, trạng thái, độ khó, concept/family và nút duyệt/bỏ rõ ràng.
2. Chỉ cho **Chốt bộ đề** khi tất cả câu hỏi trong chapter đã được xử lý xong: câu chờ duyệt phải được duyệt hoặc bỏ; câu lỗi phải được sửa hoặc bỏ. Backend cũng chặn, không chỉ chặn ở UI.

## File đã sửa

```text
frontend/app/bank/_components/BankPages.tsx
frontend/types/index.ts
backend/app/schemas/question_bank.py
backend/app/services/question_bank_service.py
```

## Chạy lại bản mới

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build --no-cache backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Nếu chỉ muốn test nhanh frontend

Bản này có sửa cả backend guard, nên production nên build đủ backend + frontend. Chỉ rebuild frontend khi muốn xem giao diện trước:

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build --no-cache frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

## Kiểm tra sau deploy

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production ps

docker compose -f docker-compose.prod.yml --env-file .env.production logs backend --tail=200

docker compose -f docker-compose.prod.yml --env-file .env.production logs frontend --tail=200
```

Vào UI:

```text
/bank/chapters/{chapterId}
```

Kiểm tra:

- Danh sách câu hỏi có đủ A/B/C/D như trang `/review`.
- Nếu còn câu `pending_review`, `needs_review` hoặc `draft_error`, nút **Chốt bộ đề** bị khóa.
- Bấm **Duyệt hết câu chờ** chỉ xử lý câu chờ duyệt.
- Câu lỗi phải bấm **Bỏ câu lỗi** hoặc sửa sau mới chốt được.
- Tổng quota 100 câu/chapter tính theo tổng câu đã tạo trong chapter, kể cả câu bị bỏ.
