## Deploy

Bản này sửa backend, frontend và connector plugin source. Không có Alembic migration.

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Nếu connector plugin trong Open edX đang được build/cài từ artifact này, cần rebuild/reinstall phần plugin theo quy trình hiện tại của hệ thống để LMS dùng fallback completion mới. Nếu chưa rebuild plugin, backend vẫn đọc payload tốt hơn nhưng completion từ LMS có thể chưa cải thiện.


Thao tác:

1. Bấm **Đồng bộ full CMS**.
2. Chờ job completed.
3. Kiểm tra `Course completion` không còn N/A nếu LMS có dữ liệu completion hoặc StudentModule activity.
4. Kiểm tra các cột Detailed grades/Quiz xuất hiện nếu LMS có grade component/subsection/problem grade data.
5. Vào `/training-management`, bấm **Xem lớp** để kiểm tra cột đầu điểm động.
6. Xuất Excel để kiểm tra sheet `ChiTietLop` có cột đầu điểm động.
