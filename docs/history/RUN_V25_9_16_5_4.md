# v25.9.16.5.4 — Persistent Class Sync Jobs & F5 Recovery

## Mục tiêu

- Màn chi tiết lớp phải thấy tiến trình đồng bộ CMS/Course/Learning/full CMS.
- F5 không làm mất trạng thái job đang chạy.
- Tránh bấm nhiều lần tạo nhiều job đồng bộ cùng một lớp.

## Thay đổi backend

- `POST /api/academic/classes/{class_id}/.../jobs` giờ idempotent theo lớp.
- Nếu lớp đang có job `queued` hoặc `running`, backend trả lại job đang chạy thay vì tạo job mới.
- Điều này chặn race condition khi người dùng F5 rồi bấm lại nhiều lần.

## Thay đổi frontend

- Thêm API client `getAcademicClassSyncJobs()`.
- Màn `/student-management/classes/{classId}` tải danh sách job gần đây từ database.
- Nếu có job `queued/running`, tự khôi phục và tiếp tục polling sau khi F5.
- Lưu active job id vào `localStorage` như fallback, nhưng nguồn chính vẫn là database `/sync-jobs`.
- Khi có job đang chạy, khóa các nút đồng bộ để tránh tạo job trùng.
- Thêm khu `Tiến trình đồng bộ gần đây` và nút `Tải lại jobs`.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Không cần migration.

## Test

1. Vào `/student-management/classes/{classId}`.
2. Bấm `Đồng bộ full CMS`.
3. Thấy thanh tiến trình và danh sách job gần đây.
4. F5 khi job đang chạy.
5. Trang tự khôi phục tiến trình và tiếp tục polling.
6. Trong lúc job chạy, các nút đồng bộ bị disable.
7. Nếu bấm lại rất nhanh từ tab khác, backend trả lại job đang chạy thay vì tạo job mới.

## Kiểm tra nhanh DB jobs

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec -T backend python - <<'PY'
from sqlalchemy import text
from app.db.session import SessionLocal

with SessionLocal() as db:
    rows = db.execute(text('''
        SELECT id, job_type, status, class_id, progress_current, progress_total, progress_label, created_at, updated_at
        FROM academic_class_sync_jobs
        ORDER BY created_at DESC
        LIMIT 10
    ''')).mappings().all()
    for row in rows:
        print(dict(row))
PY
```
