# v25.9.15.6.31.11 - Remove dark/landing and rebuild Bank dashboard

## Mục tiêu

- Bỏ giao diện tối.
- Bỏ landing page `/` xấu, chuyển `/` về `/bank`.
- Làm lại `/bank` thành dashboard vận hành hữu ích hơn: việc cần xử lý, KPI, biểu đồ, Quiz gần đây, job gần đây, nhật ký gần đây.

## File sửa

- `frontend/components/layout/AppShell.tsx`
- `frontend/app/page.tsx`
- `frontend/app/bank/_components/BankPages.tsx`
- `frontend/app/globals.css`
- `CHANGELOG.md`

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

Sau đó mở:

```text
http://ai.cms-test.poly.edu.vn/
http://ai.cms-test.poly.edu.vn/bank
```

Nhấn Ctrl + F5.

## Kỳ vọng

- `/` tự về `/bank`.
- Không còn nút Sáng/Tối, không còn dark theme.
- `/bank` có thông tin hữu ích hơn: cần xử lý, tổng câu, Quiz, job, biểu đồ và feed gần đây.
