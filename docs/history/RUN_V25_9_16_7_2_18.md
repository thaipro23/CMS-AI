# v25.9.16.7.2.18 — Teacher Learning Behavior Guardrails

## Mục tiêu

Sửa lỗi `/analytics/learning` gửi `page_size=500` tới API học vụ trong khi backend giới hạn `page_size <= 200`, gây lỗi 422:

```json
{
  "code": "VALIDATION_ERROR",
  "loc": ["query", "page_size"],
  "msg": "Input should be less than or equal to 200",
  "input": "500"
}
```

Đồng thời tinh gọn tiếp màn phân tích hành vi học để giáo viên quản lý dễ hơn: đi từ kỳ/cơ sở/môn tới danh sách lớp, xem kết quả chính, rồi mới bấm vào sinh viên để xem lý do.

## Thay đổi chính

### 1. Không còn gửi `page_size=500` vào academic API

- `/analytics/learning` không gọi `getAcademicTeacherSubjects(... pageSize: 500)` nữa.
- Thay bằng `loadAllSubjects()` gọi từng trang với `pageSize=200`.
- `frontend/lib/api.ts` thêm `clampAcademicPageSize()` để mọi API học vụ bị giới hạn về `<= 200` trước khi gọi backend.

### 2. Không cần gọi `/academic/subjects/{subject_id}/classes?page_size=500`

- Màn analytics không còn gọi `getAcademicSubjectClasses` chỉ để lấy `openedx_course_id`.
- Endpoint overview lớp đã trả thêm:
  - `openedx_course_id`
  - `openedx_mapping_source`
- FE dùng trực tiếp `selectedClassOverview?.openedx_course_id` để tải kết quả sinh viên.

### 3. Dễ quản lý cho giáo viên

Màn `/analytics/learning` được giữ theo luồng:

```text
Hệ → Học kỳ → Cơ sở → Môn → Danh sách lớp cần quản lý → Chi tiết lớp → Lý do kết quả
```

Bảng lớp rút gọn:

- STT
- Lớp
- Kết quả lớp
- Học thật
- Cần xem
- Chưa đủ dữ liệu
- Thao tác

Không phơi riêng nhiều vấn đề ở màn chính. Lý do chi tiết chỉ mở khi bấm pill kết quả của sinh viên.

## Deploy

```bash
cd /opt/ai-server

unzip -o ai-server-openedx-v25.9.16.7.2.18-teacher-learning-behavior-guardrails.zip -d /tmp/ai-server-v25.9.16.7.2.18

rsync -a --delete /tmp/ai-server-v25.9.16.7.2.18/ai_server_openedx_v25_9_16_7_2_18/ /opt/ai-server/

docker compose -f docker-compose.prod.yml --env-file .env.production build backend frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend
```

Cập nhật `.env.production`:

```env
APP_VERSION=25.9.16.7.2.18
```

## Kiểm tra sau deploy

1. Vào `/analytics/learning`.
2. Chọn hệ, kỳ, cơ sở, môn.
3. Network không được còn request academic API với `page_size=500`.
4. Danh sách lớp hiển thị kết quả gọn.
5. Bấm **Xem kết quả** ở một lớp.
6. Bấm pill kết quả của sinh viên để mở lý do.
