# RUN v25.9.16.5.87 — StudentModule Activity-Only Progress Fix

## Mục tiêu

Sửa lỗi sau v86: một số sinh viên chưa học vẫn hiện Course completion 21.4% vì connector đếm toàn bộ `StudentModule` row như `completed_blocks`.

V87 đổi rule StudentModule fallback:

- Không tính row container: `course`, `chapter`, `sequential`, `vertical`, `library_content`.
- Không tính row state rỗng: `{}`, `[]`, `null`, empty.
- Chỉ tính row có learner activity rõ ràng: problem grade/state có answer/submission/correct_map/attempt, video/html state có hoạt động thật.
- Diagnostics trả thêm:
  - `student_module_raw_rows`
  - `student_module_activity_blocks`
  - `student_module_ignored_rows`
  - `student_module_fallback_rule=activity_rows_only_excluding_empty_container_rows`

## Vì sao trước đó ra 8.6%, 18.6%, 21.4%

Connector v86 tính:

```text
progress_percent = Count(StudentModule rows for learner in course) / total_blocks * 100
```

Với course có `total_blocks=70`:

```text
6 / 70 * 100 = 8.57%  -> UI làm tròn 8.6%
13 / 70 * 100 = 18.57% -> UI làm tròn 18.6%
15 / 70 * 100 = 21.43% -> UI làm tròn 21.4%
```

Lỗi là `Count(StudentModule rows)` không đồng nghĩa với `completed_blocks`. Một số row được Open edX tạo khi render/courseware/enroll/shell sync hoặc row container/state rỗng, nên sinh viên chưa học vẫn có baseline 15/70.

## SQL kiểm tra snapshot sau khi cập nhật điểm

```sql
select
  s.student_code,
  snap.progress_percent,
  snap.completed_blocks,
  snap.total_blocks,
  snap.raw_json->'payload'->'progress'->>'source' as progress_source,
  snap.raw_json->'payload'->'progress'->>'student_module_raw_rows' as sm_raw_rows,
  snap.raw_json->'payload'->'progress'->>'student_module_activity_blocks' as sm_activity_blocks,
  snap.raw_json->'payload'->'progress'->>'student_module_ignored_rows' as sm_ignored_rows,
  snap.raw_json->'payload'->'progress'->>'student_module_fallback_rule' as sm_rule
from academic_student_learning_snapshots snap
join academic_students s on s.id = snap.student_id
where snap.class_id = '<CLASS_ID>'
order by s.student_code;
```
