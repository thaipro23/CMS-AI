# v25.9.15.6.30 - Bank Quiz Focused Navigation + Create Confirm UX

## Phạm vi

Bản này chỉ sửa frontend AI Server.

## Thay đổi chính

- Sidebar chỉ giữ các trang đang dùng cho luồng Ngân hàng đề.
- Tạm ẩn nhóm Tạo & duyệt cũ.
- Vận hành đổi nhãn theo job/log của luồng mới.
- /bank/quiz chuyển ghi chú FPT naming sang popup xác nhận khi tạo Quiz.
- Settings đổi giới hạn tạo câu hỏi theo khóa học thành giới hạn theo Bài/Chapter.
- Settings bỏ UI Phân quyền demo.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

Sau deploy vào `http://ai.cms-test.poly.edu.vn/bank/quiz` và nhấn Ctrl + F5.
