# v25.9.15.6.21 - Library LearningPackage Canonical Key Hotfix

Fix lỗi Publish Library trên Open edX Ulmo:

```text
LearningPackage matching query does not exist
```

Nguyên nhân: AI Server/connector gửi library key theo format có kỳ, ví dụ:

```text
lib:FPT:web107-FA26-b-i-2-1-v1-0
```

nhưng Content Libraries V2 của Open edX có thể normalize slug khi tạo LearningPackage. Sau đó connector vẫn dùng requested key cũ để set OLX nên `set_library_block_olx()` không tìm thấy LearningPackage.

## Fix

- Connector luôn lấy lại library key thực tế từ Open edX sau `create_library/get_library`.
- Import problem dùng đúng key thực tế đã persist trong LearningPackage.
- AI Server cập nhật `release.openedx_library_key` theo key thực tế do connector trả về trước khi import problem.
- Không cần migration.

## Deploy

Bản này sửa backend AI Server và openedx-connector-plugin.

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build --no-cache backend worker

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker
```

Copy connector vào Open edX/CMS rồi restart:

```bash
cp /opt/ai-server/openedx-connector-plugin/openedx_ai_connector/views.py \
  /opt/openedx/CMS-FPT/openedx_connector_plugin/openedx_ai_connector/views.py

tutor local restart cms cms-worker
```

Sau đó bấm Publish Library lại.
