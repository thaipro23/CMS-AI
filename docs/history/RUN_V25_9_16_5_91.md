# RUN v25.9.16.5.91 — Class Detail Cleanup + Fast Learning Sync

## Mục tiêu

Bản này giữ nguyên kết quả đúng của v90 nhưng tối ưu đường cập nhật điểm và dọn UI chi tiết lớp.

## Sửa hiệu năng

AI Server khi gọi connector `class-analytics` giờ gửi payload compact:

```json
{
  "compact": true,
  "include_diagnostics": false,
  "skip_course_home_progress": true
}
```

Ý nghĩa:

- Không gọi Course Home Progress route nội bộ theo từng sinh viên trong luồng cập nhật điểm hàng loạt.
- Không trả diagnostics/tree breakdown nặng trong response hot path.
- Không gửi sample block keys dài.
- Completion vẫn tính theo rule đã xác minh trên COM1071/SU26:
  - mẫu số = reachable `sequential/subsection`
  - tử số = `StudentModule` type `sequential` có `state.position > 0`
  - bỏ `itembank/problem/video` khỏi Course completion fallback.

Kỳ vọng:

- `duongddph69321 = 5/8 = 62.5% ≈ 63%`.
- Sinh viên chỉ có `itembank` rows = `0/8 = 0%`.

## Sửa UI

Màn chi tiết lớp đã bỏ các dòng copy/diagnostic không cần thiết:

- Bỏ breadcrumb text kiểu `Luồng: Môn → Lớp → Chi tiết lớp`.
- Bỏ mô tả dài dưới nút `Đồng bộ full CMS`.
- Bỏ box `Chẩn đoán điểm CMS`.
- Bỏ source/note kỹ thuật trong từng dòng sinh viên.
- Bỏ hint kéo ngang dài phía trên bảng.
- Rút gọn message hoàn tất đồng bộ/cập nhật điểm.

## Deploy AI Server

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Deploy/restart Open edX connector

Sau khi cập nhật plugin connector vào Open edX, restart:

```bash
tutor local restart lms cms lms-worker cms-worker
```

Kiểm tra connector:

```bash
tutor local run lms python - <<'PY'
import importlib
m = importlib.import_module('openedx_ai_connector.student_insight')
print('file=', getattr(m, '__file__', None))
print('CONNECTOR_VERSION=', getattr(m, 'CONNECTOR_VERSION', None))
PY
```

Kết quả cần thấy:

