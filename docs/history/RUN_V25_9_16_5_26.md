# v25.9.16.5.26 — Timed Quiz API Auto-submit + Timer Sync Hotfix

## Mục tiêu

Sửa các lỗi Quiz Open edX/timed practice:

1. Vào quiz lần đầu bị trắng, F5 mới thấy câu hỏi.
2. Có lúc báo `Bạn cần chờ thêm 0 giây để làm lại bài`.
3. Countdown lệch khi người dùng chuyển tab/trình duyệt throttle timer.
4. Auto-submit không dùng click button nữa, chuyển sang gọi Open edX `problem_check` API cho các câu đã chọn.

## Thành phần thay đổi

### Learning MFE patch

File:

```text
frontend-app-learning-patch/src/courseware/course/sequence/unit-reset/UnitResetButton.jsx
```

Thay đổi chính:

- Không hard-remount iframe trong lần `quiz-session/start` đầu tiên.
- Chỉ hard-remount iframe sau luồng `reset -> start` khi có session ACTIVE mới.
- Timer tính lại từ `expiresAt`/`resetAvailableAt` theo `Date.now()`, không trừ dần bằng interval.
- Khi tab visible/focus, tự gọi lại status để đồng bộ với server.
- Timeout gửi message `AI_QUIZ_TIMEOUT_API_SUBMIT`.

### openedx-unit-reset-plugin

Files:

```text
openedx-unit-reset-plugin/openedx_unit_reset/views.py
openedx-unit-reset-plugin/openedx_unit_reset/services.py
openedx-unit-reset-plugin/openedx_unit_reset/middleware.py
```

Thay đổi chính:

- Runtime iframe gọi API `problem_check` trực tiếp bằng `fetch`, không click Submit/Check button.
- Response quiz-session có thêm `server_now`.
- Sửa race condition cooldown 0 giây.

## Deploy Learning MFE patch

```bash
cd /opt/ai-server

cp frontend-app-learning-patch/src/courseware/course/sequence/unit-reset/UnitResetButton.jsx \
  /opt/openedx/frontend-app-learning/src/courseware/course/sequence/unit-reset/UnitResetButton.jsx

grep -n "AI_QUIZ_TIMEOUT_API_SUBMIT\|refreshTimerFromWallClock\|quiz-session-reset-start" \
  /opt/openedx/frontend-app-learning/src/courseware/course/sequence/unit-reset/UnitResetButton.jsx
```

Build MFE bằng Tutor:

```bash
source ~/tutor-venv/bin/activate
export NODE_OPTIONS="--max-old-space-size=4096"

docker buildx use mfe-builder-6g
tutor images build mfe

tutor local stop mfe
tutor local start -d mfe
```

## Deploy openedx-unit-reset-plugin

Bản này có sửa runtime trong plugin LMS, nên cần cập nhật plugin và rebuild image Open edX/LMS theo quy trình đang dùng trên server.

Sau khi deploy, kiểm tra runtime mới:

```bash
curl -k https://cms-test.poly.edu.vn/api/unit-reset/v1/quiz-session/runtime.js | grep "AI_QUIZ_TIMEOUT_API_SUBMIT"
```

Nếu không thấy chuỗi trên, LMS vẫn đang chạy plugin cũ.

## Test

1. Mở quiz lần đầu, không F5. Kỳ vọng thấy câu hỏi ngay.
2. Chuyển tab 20–30 giây rồi quay lại. Kỳ vọng timer tự sync đúng với server.
3. Chọn đáp án, chờ hết giờ. Network trong iframe phải có request `problem_check`; không cần click Submit/Check button.
4. Hết cooldown, bấm Làm lại bài. Không được hiện `Bạn cần chờ thêm 0 giây`.
5. Sau reset, iframe có `unit_reset_nonce` và câu hỏi render lại.
