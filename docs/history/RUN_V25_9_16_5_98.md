## Data Cache Invalidation

Đã thêm cơ chế xóa cache báo cáo giáo viên khi dữ liệu lớp thay đổi:

```text
Cập nhật điểm        → invalidate teacher report cache cùng term/branch/campus
Đồng bộ full CMS     → invalidate teacher report cache cùng term/branch/campus
Đổi Course mapping   → xóa snapshot học tập cũ của lớp + invalidate teacher report cache
Tắt Course mapping   → xóa snapshot học tập cũ của lớp + invalidate teacher report cache
```

Lý do: tránh Teacher Management đọc cache cũ sau khi lớp vừa cập nhật điểm hoặc đổi Course CMS.
