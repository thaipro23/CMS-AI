# v25.9.16.3.2 — Auto Create CMS Users + Teacher Course Staff

## Mục tiêu

Khi lớp AP đã map được Course CMS:

1. Kiểm tra đồng bộ CMS sẽ tự tạo tài khoản CMS/Open edX nếu chưa có.
2. Sinh viên đã map/đã tạo sẽ được enroll vào Course CMS.
3. Giảng viên AP sẽ được tạo tài khoản nếu thiếu và được gán Course Staff cho Course CMS.

## Quy tắc tạo tài khoản

### Sinh viên

- username = AP username
- email = AP email, nếu thiếu mới fallback `username@fpt.edu.vn`
- full name = AP full_name/name
- first_name/last_name được tách từ full name

### Giảng viên

AP chỉ có dạng:

```json
{"teacher": "ngocnb61"}
```

Hệ thống tạo:

```text
username: ngocnb61
email: ngocnb61@fpt.edu.vn
first_name: ngocnb61
last_name: ngocnb61
```

## Cấu hình

AI Server `.env.production`:

```env
OPENEDX_STUDENT_INSIGHT_BASE_URL=https://cms-test.poly.edu.vn
OPENEDX_STUDENT_INSIGHT_USERS_RESOLVE_ENDPOINT=/api/ai-student-insight/v1/users/resolve
OPENEDX_STUDENT_INSIGHT_ENROLLMENT_ENROLL_ENDPOINT=/api/ai-student-insight/v1/course-enrollment/enroll
OPENEDX_STUDENT_INSIGHT_SHARED_SECRET=<same-secret>
ACADEMIC_AUTO_ENROLL_AFTER_CMS_SYNC=true
ACADEMIC_AUTO_CREATE_CMS_USERS=true
ACADEMIC_AUTO_ADD_TEACHERS_TO_COURSE=true
```

Open edX plugin:

```env
AI_STUDENT_INSIGHT_SHARED_SECRET=<same-secret>
```

## Deploy AI Server

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Deploy plugin

Cập nhật lại `openedx_ai_connector` vào Tutor/Open edX rồi restart LMS/CMS.

## Test

```text
/student-management
→ chọn môn
→ Xem lớp
→ Chi tiết lớp
→ Kiểm tra đồng bộ CMS
```

Kỳ vọng:

- Sinh viên thiếu tài khoản CMS được tạo.
- Sinh viên được enroll vào Course CMS nếu môn đã map course.

- Giảng viên được gán Course Staff vào Course CMS.
