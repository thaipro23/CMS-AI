# v25.9.16.5.71 — AP CMS Subject Endpoint Query Template Compatibility

## Mục tiêu

Cho phép `ACADEMIC_AP_CMS_GET_SUBJECT_ENDPOINT` cấu hình được cả dạng endpoint trơn và dạng query template tạm thời.

Các dạng env được hỗ trợ:

```env
ACADEMIC_AP_CMS_GET_SUBJECT_ENDPOINT=/api/cms/get-subject-cms
ACADEMIC_AP_CMS_GET_SUBJECT_ENDPOINT=/api/cms/get-subject-cms?term_name=
ACADEMIC_AP_CMS_GET_SUBJECT_ENDPOINT=/api/cms/get-subject-cms?campus_code=ph&term_name=
```

Khi chạy với kỳ `Summer 2026`, backend sẽ gọi tương ứng:

```text
/api/cms/get-subject-cms?term_name=Summer+2026
/api/cms/get-subject-cms?campus_code=ph&term_name=Summer+2026
```

Không tạo query trùng kiểu:

```text
term_name=&term_name=Summer+2026
```

## Luồng AP không đổi

1. Đồng bộ cơ sở vào `/premises`:
   - Poly -> `/api/cms/get-campus?product=POLY`
   - PTCĐ -> `/api/cms/get-campus?product=POLY9`

2. Lấy danh sách môn triển khai theo kỳ:
   - dùng `ACADEMIC_AP_CMS_GET_SUBJECT_ENDPOINT`
   - backend tự merge `term_name`

3. Với từng cơ sở + từng môn:
   - giữ legacy `/get-data-cms` để lấy lớp, giảng viên, sinh viên

## Env tạm thời theo yêu cầu

```env
ACADEMIC_AP_CMS_GET_SUBJECT_ENDPOINT=/api/cms/get-subject-cms?campus_code=ph&term_name=
```

Sau này khi AP bỏ yêu cầu `campus_code=ph`, chỉ cần đổi env về:

```env
ACADEMIC_AP_CMS_GET_SUBJECT_ENDPOINT=/api/cms/get-subject-cms?term_name=
```

hoặc:

```env
ACADEMIC_AP_CMS_GET_SUBJECT_ENDPOINT=/api/cms/get-subject-cms
```

cả hai đều chạy bình thường.
