# v25.9.16.4.1 — Student Progress N/A + Academic Query Hotfix

## Mục tiêu

Bản này là hotfix sau v25.9.16.4.0.

## Thay đổi

1. UI Student Progress
   - Nếu Open edX/CMS chưa có progress/grade/component grade, frontend hiển thị `N/A` thay vì để trống hoặc dùng dấu gạch.
   - Màn môn `/student-management` hiển thị thêm `Điểm TP` từ component/subsection summary.
   - Màn lớp `/student-management/subjects/{subjectId}/classes` cũng hiển thị `Điểm TP`.
   - Chi tiết lớp luôn hiện khối `Điểm thành phần của lớp`; nếu chưa có dữ liệu thì hiện `N/A`.
   - Từng sinh viên không có điểm thành phần sẽ hiện `N/A`.

2. Backend summary
   - Thêm `learning_component_summaries` vào response cấp môn và cấp lớp.
   - Không gọi CMS/Open edX khi F5; dữ liệu lấy từ snapshot AI Server.

3. Academic query production hotfix
   - Sửa migration revision IDs dài hơn 32 ký tự gây lỗi `value too long for type character varying(32)` khi chạy Alembic.
   - Giữ fix `list_subjects`: không dùng `DISTINCT` trên row có JSON.
   - Giữ fix `list_teacher_classes`: không dùng `DISTINCT ON` sai thứ tự `ORDER BY`.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend \
  alembic -c alembic.ini upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Test

- `/student-management`: kiểm tra cột `Học tập CMS` có `Điểm TP`, thiếu dữ liệu hiện `N/A`.
- `/student-management/subjects/{subjectId}/classes`: kiểm tra từng lớp có `Điểm TP`, thiếu dữ liệu hiện `N/A`.
- `/student-management/classes/{classId}`: kiểm tra khối `Điểm thành phần của lớp` và cột `Điểm thành phần` từng sinh viên.
- Chạy `docker compose logs --tail=200 backend` để chắc chắn không còn lỗi JSON DISTINCT / DISTINCT ON / Alembic version dài.
