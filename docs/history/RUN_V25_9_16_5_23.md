# v25.9.16.5.23 — Frontend UX Cleanup & Design System Hardening

## Mục tiêu

Chuẩn hóa giao diện AI Server để người dùng nghiệp vụ dễ dùng hơn, giảm thuật ngữ kỹ thuật, đồng bộ UI/UX và cải thiện responsive/accessibility/performance ở frontend.

## Thay đổi chính

### 1. Dọn route frontend cũ không còn là luồng chính

Các trang legacy được chuyển hướng về luồng hiện tại để tránh người dùng đi nhầm:

- `/generate` → `/bank`
- `/workflow` → `/bank`
- `/question-bank` → `/bank`
- `/review` → `/bank`
- `/export` → `/bank/quiz`
- `/sync` → `/ap-sync`

### 2. Chuẩn hóa câu chữ

Đổi nhiều thuật ngữ kỹ thuật sang từ dễ hiểu hơn:

- `Dashboard` → `Tổng quan`
- `Release` → `Bộ đề`
- `Publish` → `Đưa lên CMS`
- `Rollback` → `Khôi phục`
- `Job` → `Việc xử lý`
- `Scope` → `Phạm vi`
- `Version môn` → `Phiên bản môn`
- `Quiz Open edX` → `Quiz trên CMS`

### 3. Design system dùng custom tokens

Bổ sung token thống nhất trong `frontend/app/globals.css`:

- màu sắc semantic: primary/success/warning/danger
- spacing scale
- border radius
- shadow
- focus ring
- typography base

Các biến legacy như `--bg`, `--card`, `--text`, `--primary` được map về token mới để không phá CSS cũ.

### 4. Responsive/mobile-first

Bổ sung breakpoint cho mobile/tablet:

- sidebar chuyển thành block trên mobile
- content padding giảm theo màn hình
- grid 2/3/6 cột tự co về 1–2 cột
- modal co theo viewport
- bảng giữ horizontal scroll an toàn
- button row chuyển thành full-width trên mobile

### 5. Accessibility

- Skip link đã có và được style rõ khi focus.
- Thêm focus-visible ring thống nhất.
- Modal có `aria-label`.
- Search input dùng `aria-label` ở component dùng chung.
- Nút menu hành động có label rõ hơn.
- Hỗ trợ `prefers-reduced-motion`.

### 6. Performance/Core Web Vitals

- Các route legacy nặng được redirect nhẹ thay vì render UI cũ.
- CSS dùng token/override, không thêm thư viện UI mới nên không tăng bundle dependency.
- Không thêm ảnh/font bên ngoài.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

Nếu triển khai cùng backend/worker:

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Kiểm tra sau deploy

1. Mở `/bank`, `/bank/departments`, `/bank/quiz`, `/jobs`, `/users` trên desktop.
2. Dùng DevTools responsive kiểm tra 390px, 768px, 1024px.
3. Tab keyboard qua menu, form, modal, nút hành động.
4. Kiểm tra route cũ `/generate`, `/review`, `/question-bank` đã chuyển về `/bank`.
5. Build production frontend phải qua `npm ci && npm run typecheck && npm run build` trong container/frontend image.
