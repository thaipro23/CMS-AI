# v25.9.16.5.73 — Course Home Progress Route Resolver Fix

## Mục tiêu

Sửa tình trạng màn chi tiết lớp vẫn hiển thị:

```text
Hoàn thành khóa học: N/A
```

trong khi Open edX Ulmo đã trả tiến độ thật tại:

```text
/api/course_home/progress/{course_id}
```

## Nguyên nhân

Các bản trước đoán tên view class của Course Home Progress. Trên Ulmo/FPT, route browser dùng có thể được đăng ký bởi view/callback khác tên, nên connector không gọi được payload `completion_summary`.

## Cách sửa

Connector giờ gọi đúng route đã đăng ký trong LMS:

```python
resolve('/api/course_home/progress/<course_id>')
```

và force-auth request bằng từng learner. Khi route trả:

```json
{
  "completion_summary": {
    "complete_count": 1,
    "incomplete_count": 7
  }
}
```

thì tính:

```text
complete_count / (complete_count + incomplete_count)
```

## Deploy

Không có migration.

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Nếu connector plugin cài tách trong LMS/Tutor, phải update/reinstall plugin LMS, rồi chạy lại **Đồng bộ full CMS** cho lớp.
