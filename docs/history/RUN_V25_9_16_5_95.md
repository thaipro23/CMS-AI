## Kiểm tra API mới

### Class sync jobs gần đây

```bash
curl -s "$AI_API/api/academic/sync/class-jobs?status=all&limit=20" \
  -H "Authorization: Bearer $TOKEN" | jq '.[0:3]'
```

### Teacher report jobs gần đây

```bash
curl -s "$AI_API/api/academic/training/teachers/report-jobs?status=all&limit=20" \
  -H "Authorization: Bearer $TOKEN" | jq '.[0:3]'
```

## Kiểm tra UI

1. Vào `/jobs`.
2. Chọn `Đang chạy` để xem việc active.
3. Chọn nhóm:
   - `Đồng bộ lớp/CMS`
   - `Đồng bộ AP`
   - `Báo cáo giáo viên`
   - `Bank / Quiz`
4. Kiểm tra job `Cập nhật điểm` và `Đồng bộ full CMS` có hiện ngắn gọn.
5. Vào `/audit`, kiểm tra chỉ còn nhật ký thao tác. Raw action/target id chỉ hiện khi thêm `?debug=1`.
