# RUN v25.9.16.7.2.23 — Sticky Student Identity Columns

## Mục tiêu

Sửa lỗi bảng danh sách sinh viên khi cuộn ngang: `STT` và `Sinh viên` phải dính với nhau thành 2 cột cố định. Không để cột `Sinh viên` bị cuộn đi hoặc đè lên `STT`.

## Deploy

```bash
cd /opt/ai-server

unzip -o ai-server-openedx-v25.9.16.7.2.23-sticky-student-identity-columns.zip -d /tmp/ai-server-v25.9.16.7.2.23

rsync -a --delete /tmp/ai-server-v25.9.16.7.2.23/ai_server_openedx_v25_9_16_7_2_23/ /opt/ai-server/

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

## Cập nhật version

```env
APP_VERSION=25.9.16.7.2.23
```

## Test tay

1. Mở `/student-management/classes/<class_id>`.
2. Cuộn ngang bảng sinh viên.
3. Kiểm tra `STT` và `Sinh viên` vẫn đứng bên trái, không tách rời, không đè nhau.
4. Mở `/analytics/learning`, chọn lớp, cuộn ngang bảng kết quả sinh viên.
5. Kiểm tra `STT` và `Sinh viên` vẫn dính với nhau.

Không có migration.
