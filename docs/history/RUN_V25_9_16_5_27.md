# v25.9.16.5.27 — Bank Hierarchy Refresh + Status Color UX Hotfix

## Mục tiêu

Sửa các lỗi UX trong Bank hierarchy:

1. Tạo môn mới trong `/bank/departments/{departmentId}/subjects` báo thành công nhưng danh sách chưa hiện ngay, phải F5 nhiều lần.
2. Message lỗi upload tài liệu chưa thân thiện, đặc biệt lỗi định dạng file không hỗ trợ.
3. Màu trạng thái ở các “cục” trong `/bank` chưa rõ nghĩa và chưa nhất quán giữa Bộ môn → Môn → Phiên bản môn → Bài.

## Thay đổi chính

### Backend

- Khi tạo/sửa/xóa Bộ môn, Môn, Phiên bản môn, Bài: tự invalidate cache dashboard/summary Redis.
- Tránh việc FE lấy lại summary cũ trong TTL cache, gây cảm giác “đã thêm nhưng chưa thấy”.
- Upload tài liệu có preflight định dạng rõ hơn:
  - Không hỗ trợ `.doc/.xls/.ppt` Office cũ.
  - Không hỗ trợ file lạ ngoài danh sách được phép.
  - Message trả về tiếng Việt rõ để hiển thị ngay trong popup.

### Frontend

- Sau khi thêm Bộ môn/Môn/Phiên bản môn/Bài, FE thêm item mới vào danh sách ngay theo kiểu optimistic update, rồi vẫn refresh lại từ server sau đó.
- Chuẩn hóa message lỗi API:
  - File quá lớn.
  - Định dạng file không hỗ trợ.
  - Office cũ cần chuyển sang DOCX/XLSX/PPTX hoặc PDF.
- Thêm kiểm tra định dạng file phía FE trước khi upload tài liệu để báo lỗi ngay trong popup.
- Chuẩn hóa màu trạng thái trên các card hierarchy:
  - Xám: Chưa làm.
  - Vàng: Chưa làm hết.
  - Xanh: Đã public thư viện.
- Thêm chú giải trạng thái trong các trang:
  - `/bank/departments`
  - `/bank/departments/{departmentId}/subjects`
  - `/bank/subjects/{subjectId}/versions`
  - `/bank/subject-versions/{versionId}/chapters`

## Deploy

Bản này sửa AI Server backend + frontend, không phải Open edX MFE.

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Không cần rebuild Learning MFE cho bản này.

## Test nhanh

### Test tạo môn mới

1. Vào `/bank/departments/{departmentId}/subjects`.
2. Bấm `+ Thêm môn`.
3. Nhập mã/tên môn rồi lưu.
4. Kỳ vọng: môn mới hiện ngay trong danh sách, không cần F5.
5. F5 lại trang, môn vẫn còn.

### Test message định dạng file

1. Vào một bài trong `/bank/chapters/{chapterId}`.
2. Mở popup `Tài liệu`.
3. Upload file `.doc`, `.xls`, `.exe` hoặc file không có đuôi.
4. Kỳ vọng: popup hiện lỗi rõ ràng kiểu `Định dạng file ... chưa được hỗ trợ`.

### Test màu trạng thái

- Card xám: chưa có dữ liệu/chưa làm.
- Card vàng: có dữ liệu nhưng chưa hoàn tất/chưa public đủ.
- Card xanh: đã public thư viện.
