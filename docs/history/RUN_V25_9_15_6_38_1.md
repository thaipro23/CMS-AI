# v25.9.15.6.38.1 — Published Lock + Stats Accuracy Hotfix

Bản này sửa đúng lỗi phát hiện sau khi deploy `.38`:

1. Các card bộ môn/môn/version/bài có thể hiển thị số liệu không chính xác nếu bảng `ai_bank_chapter_stats` chưa được rebuild sau migration/import dữ liệu cũ.
2. Bài đã publish vẫn còn hiện các nút thao tác như tạo câu hỏi, gắn/xóa tài liệu, duyệt câu hỏi, kiểm tra thay đổi.

## Thay đổi chính

- Summary engine tự auto-heal các chapter stats bị thiếu/stale trong scope đang mở, có giới hạn 500 chapter/lần để không làm treo production lớn.
- Status summary hỗ trợ trạng thái `published` xuyên suốt: chapter → version môn → môn → bộ môn.
- FE hiển thị rõ `Đã publish` và `Đã khóa chỉnh sửa`.
- Workspace bài đã publish chuyển sang chế độ chỉ xem:
  - Ẩn `Tạo câu hỏi`.
  - Ẩn `Kiểm tra thay đổi`.
  - Ẩn `Chốt bộ đề` / `Publish Library`.
  - Ẩn `Duyệt hết câu chờ`.
  - Ẩn các nút `Sửa`, `Duyệt`, `Bỏ`, `Hoàn tác` trên từng câu.
  - Popup tài liệu chỉ cho xem, không cho gắn/xóa.
- Backend khóa cứng mutating actions trên Bank Version đã publish để không phụ thuộc vào FE:
  - upload/delete material
  - generate questions
  - edit/review/bulk review questions
  - mark document diff resolved
  - create release again

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Cập nhật `.env.production`:

```env
APP_VERSION=25.9.15.6.38.1-published-lock-stats-hotfix
```

## Kiểm tra sau deploy

Mở lại:

```text
/bank/departments
/bank/departments/{department_id}/subjects
/bank/subjects/{subject_id}/versions
/bank/subject-versions/{version_id}/chapters
/bank/chapters/{chapter_id}
```

Với bài đã publish, kỳ vọng:

- Card bài/version hiển thị `Đã publish`.
- Workspace bài hiện thông báo đã khóa chỉnh sửa.
- Chỉ còn xem tài liệu/câu hỏi; không còn các nút tạo/sửa/duyệt/publish lại.
- Nếu stats trước đó là 0/stale, mở lại page scope sẽ tự rebuild missing stats nếu scope nhỏ hơn 500 chapter.

Nếu toàn hệ thống vẫn còn nhiều stats thiếu, chạy rebuild thủ công:

```bash
curl -X POST "http://api-ai.cms-test.poly.edu.vn/api/question-bank-v2/admin/stats/rebuild" \
  -H "Authorization: Bearer <AI_ADMIN_TOKEN>"
```
