# v25.9.16.5.1 — Map Course Before CMS User Hotfix

## Mục tiêu

Sửa lại thứ tự nghiệp vụ của `Đồng bộ full CMS`:

1. Map/auto-map Course CMS trước.
2. Nếu chưa map được Course CMS thì dừng, không tạo tài khoản CMS.
3. Chỉ sau khi đã có Course CMS mới tạo/kiểm tra CMS user theo AP username.
4. Sau đó mới enroll sinh viên, gán giáo viên Course Staff và lấy progress/grade/component grades.

## Lý do

Theo nghiệp vụ vận hành, không được tạo tài khoản CMS hàng loạt khi lớp chưa xác định đúng Course CMS. Việc này tránh tạo user rác khi map course sai/chưa có.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Không cần migration.

## Test

1. Chọn lớp chưa map Course CMS.
2. Bấm `Đồng bộ full CMS`.
3. Kỳ vọng: job dừng ở `mapping_required_no_cms_user_created`, không tạo user CMS.
4. Map Course CMS cho lớp/môn.
5. Bấm lại `Đồng bộ full CMS`.
6. Kỳ vọng: tạo/kiểm tra user CMS, enroll, kéo điểm/progress.
