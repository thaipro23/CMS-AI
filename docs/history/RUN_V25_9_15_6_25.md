# v25.9.15.6.25 - Force Save Quiz Timer Config After Quiz Create

## Mục tiêu

Fix lỗi Quiz đã tạo đúng nhưng Learning MFE không hiện đồng hồ vì bảng `UnitQuizTimerConfig` trong LMS trống (`ALL CONFIG COUNT: 0`).

Bản này bắt buộc AI Server ghi timer config sau khi Open edX trả về đúng `sequence_usage_key` và `unit_usage_key` thật của Subsection/Unit.

## Thay đổi chính

- AI Server gọi thêm LMS endpoint sau khi tạo Quiz node:
  - `POST /api/unit-reset/v1/quiz-config/upsert`
- Endpoint này dùng HMAC server-to-server, không cần browser CSRF.
- Nếu bật timer mà lưu config thất bại, backend báo lỗi rõ thay vì im lặng tạo Quiz không có timer.
- `openedx_unit_reset` nâng lên `0.4.2`, cho phép upsert timer config bằng HMAC hoặc staff.

## Deploy AI Server

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build --no-cache backend worker

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker
```

## Deploy openedx_unit_reset plugin

Copy plugin `openedx-unit-reset-plugin/openedx_unit_reset` vào nơi Open edX đang dùng, rồi restart/migrate:

```bash
tutor local run lms ./manage.py lms migrate openedx_unit_reset

tutor local restart lms lms-worker cms cms-worker
```

## Bắt buộc cấu hình HMAC trong LMS/CMS

AI Server ký request bằng `.env.production`:

```env
OPENEDX_CONNECTOR_HMAC_SECRET=your_shared_secret
```

LMS/CMS cũng phải có cùng secret:

```env
AI_CONNECTOR_HMAC_SECRET=your_shared_secret
```

Nếu LMS không có secret này, `/api/unit-reset/v1/quiz-config/upsert` sẽ trả 403 và AI Server sẽ báo timer chưa lưu được.

## Test

Sau khi tạo Quiz mới, kiểm tra config:

```bash
tutor local run lms ./manage.py lms shell -c "
from openedx_unit_reset.models import UnitQuizTimerConfig
print('ALL CONFIG COUNT:', UnitQuizTimerConfig.objects.count())
for x in UnitQuizTimerConfig.objects.values('course_id','sequence_usage_key','unit_usage_key','duration_seconds','cooldown_seconds')[:20]:
    print(x)
"
```

Kỳ vọng có ít nhất 1 dòng config với `duration_seconds` và `cooldown_seconds` đúng với setup trên `/bank/quiz`.
