# v25.9.16.5.51 — CMS-only Quiz Columns + Auto Deadline Calculation

## Mục tiêu

Sửa lại đúng yêu cầu: AP sync không có `Số Quiz`, `quiz_count`, `Deadline Quiz1...Deadline Quiz35`. Vì vậy hệ thống không được mở cột Quiz hoặc tính deadline từ AP metadata.

Nguồn đúng:

```text
Quiz columns = CMS/Open edX Detailed grades hoặc CMS course outline
Deadline = tự tính từ số Quiz CMS trả về + ngày bắt đầu block/lớp
```

## Thay đổi chính

### Backend

File:

```text
backend/app/services/academic_service.py
```

Đã sửa:

- Không dùng metadata AP để lấy số quiz.
- `_planned_quiz_components_for_class()` không còn tạo Quiz giả từ AP metadata.
- Component parser chỉ giữ planned component từ CMS/Open edX `course_outline`.
- Deadline quiz count lấy từ CMS component labels/order:
  - `Quiz 1`, `Quiz 2`, `Learning Check 1`, `LC 1`
  - hoặc thứ tự component nếu course outline trả component quiz có `order` nhưng label không có số.
- Deadline tự tính theo block:
  - 6 tuần đầu là tuần Quiz
  - từ Thứ 2 đến Thứ 7
  - tuần 7 là Ôn+Thi
  - quiz dư dồn vào các tuần đầu

### AP sync

File:

```text
backend/app/services/ap_academic_sync.py
```

Đã sửa:

- Bỏ logic đọc `Số Quiz`, `quiz_count`, `Deadline Quiz...` từ AP/import-like payload.
- Không ghi `quiz_count` hoặc `quiz_deadlines` vào `AcademicSubject.metadata_json` / `AcademicClass.metadata_json`.

### Connector plugin

Giữ hướng v50:

```text
openedx-connector-plugin/openedx_ai_connector/student_insight.py
```

Connector vẫn đọc CMS/Open edX:

- PersistentSubsectionGrade
- StudentModule fallback
- Course outline fallback

Mục tiêu là Course CMS có gì thì AI Server mở cột theo đó; không lấy kế hoạch quiz từ AP.

## Cách deploy

Bản này sửa backend, worker, frontend và connector plugin source. Không có Alembic migration.

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Nếu `openedx-connector-plugin` đang cài tách trên LMS, cần update/reinstall plugin LMS theo quy trình hiện tại, rồi chạy lại:

```text
Đồng bộ full CMS
```

## Kiểm tra sau deploy

```text
/student-management/classes/{classId}
→ Đồng bộ full CMS
→ Các đầu điểm CMS phải xuất hiện nếu CMS/Open edX trả Detailed grades/course outline
→ Deadline tính theo số quiz từ CMS, không lấy từ AP
```
