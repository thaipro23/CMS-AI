# v25.9.15.6.36 - Lightweight Question DTO + Keyset Browser

## Mục tiêu

Bước này triển khai đúng kế hoạch `Lightweight Question DTO + Keyset Browser`:

- List câu hỏi trong Bank/Chapter không trả full payload nặng.
- Card view chỉ nhận preview đủ để duyệt nhanh.
- Click `Sửa` hoặc `Bỏ` mới tải full detail của câu hỏi.
- Trang chapter dùng cursor/keyset và nút `Tải thêm 100 câu`, không kéo toàn bộ bank vào browser.

## API thay đổi

### List nhẹ

```http
GET /api/question-bank-v2/bank-versions/{bank_version_id}/questions?limit=100
```

Response vẫn là cursor page nhưng item là DTO nhẹ:

```json
{
  "items": [
    {
      "id": "...",
      "question_text_preview": "...",
      "option_a_preview": "...",
      "option_b_preview": "...",
      "option_c_preview": "...",
      "option_d_preview": "...",
      "difficulty": "medium",
      "status": "pending_review",
      "correct_answer": "A",
      "quality_score": 0.92
    }
  ],
  "limit": 100,
  "has_next": true,
  "next_cursor": {"created_at": "...", "id": "..."},
  "total": null
}
```

### Detail đầy đủ

```http
GET /api/question-bank-v2/bank-versions/{bank_version_id}/questions/{question_id}
```

Dùng khi mở modal sửa/bỏ câu hỏi.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Cập nhật `.env.production`:

```env
APP_VERSION=25.9.15.6.36-lightweight-question-dto-keyset-browser
```

## Test nhanh

```bash
curl -s "http://api-ai.cms-test.poly.edu.vn/api/question-bank-v2/bank-versions/<BANK_VERSION_ID>/questions?limit=100" \
  -H "Authorization: Bearer <AI_TOKEN>" | python3 -m json.tool
```

Kỳ vọng item có `question_text_preview`, không phải full `source_evidence/source_excerpt/explanation`.

```bash
curl -s "http://api-ai.cms-test.poly.edu.vn/api/question-bank-v2/bank-versions/<BANK_VERSION_ID>/questions/<QUESTION_ID>" \
  -H "Authorization: Bearer <AI_TOKEN>" | python3 -m json.tool
```

Kỳ vọng trả full question detail.
