# RUN v25.9.16.6.4 — Student List UX Compact + Học online Minimal UI

## Nội dung chính

- Thu gọn bảng `Danh sách sinh viên` ở `/student-management/classes/{classId}`.
- Gộp `Username`, `Email`, `Số lần học lại` vào cột `Sinh viên`.
- Gộp trạng thái `Đồng bộ CMS` và `Đã enroll` vào cột `Tiến độ học` bằng một cảnh báo ngắn: `Hãy bấm Đồng bộ full CMS` khi dữ liệu chưa kiểm tra/chưa cập nhật/chưa đồng bộ.
- Bỏ 2 cột riêng `Đồng bộ CMS`, `Đã enroll` để giảm rối.
- Thêm card `Học online` tối thiểu từ API Learning Analytics v6.3.
- Thêm cột `Học online` trong bảng sinh viên với nhãn mềm, không kết luận vi phạm.
- Click nhãn `Học online` mở modal chi tiết ngắn: nhận định, độ tin cậy, điểm học thật, điểm treo máy, điểm bất thường, lý do, hành động đề xuất.
- Sửa vùng cuộn ngang: chỉ bảng sinh viên di chuyển, các thẻ khác giữ nguyên; vùng bảng bắt được cuộn ngang khi con trỏ ở giữa bảng.

## Không đổi

- Không thêm migration.
- Không đổi Course completion.
- Không đổi connector contract v25.9.16.5.98.
- Không đổi ingest/parser/classifier backend v25.9.16.6.3.
- Không hiển thị từ `gian lận`/`cheating` trên UI.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

Nếu bạn muốn build chắc cả stack:

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Kiểm tra nhanh sau deploy

1. Mở:

```text
/student-management/classes/{classId}
```

2. Bảng `Danh sách sinh viên` phải còn các cột chính:

```text
Sinh viên
Tiến độ học
Học online
Điều kiện thi
Quiz ...
```

3. Cột `Sinh viên` phải có:

```text
Mã sinh viên
Họ tên
Username
Email
Học lại
```

4. Cột `Tiến độ học` chỉ hiển thị ngắn:

```text
Hoàn thành khóa học: ...
Điểm tổng: ...
Điểm thấp / Đang học / Hoàn thành tốt / ...
Hãy bấm Đồng bộ full CMS    # chỉ khi cần xử lý
```

5. Card/cột `Học online` chỉ dùng nhãn mềm:

```text
Có dấu hiệu học thật
Có khả năng treo máy
Dấu hiệu bất thường cần kiểm tra
Chưa đủ dữ liệu
Chưa thấy bất thường rõ
```

6. Không được xuất hiện trên UI:

```text
gian lận
cheating
không học thật
treo máy chắc chắn
vi phạm chắc chắn
```

## Nếu Học online đang 0 dữ liệu

Chạy ingest/recalculate theo v6.3:

```bash
curl -X POST "$API_BASE/api/analytics/ingest/run" \
  -H "Authorization: Bearer $TOKEN"
```

Sau đó trên UI bấm `Tính lại học online` trong card `Học online`.
