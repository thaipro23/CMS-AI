# v25.9.16.3.5 — Chapter Delete Tombstone + Popup Error Cache Hotfix

## What changed

- Fix `/bank/subject-versions/{id}/chapters` delete behavior when UI shows `Tài liệu = 0` but backend still has a soft-deleted material tombstone.
- Backend ignores `status=deleted` materials as real child content and deletes non-content tombstones/placeholders before deleting the chapter.
- Bank hierarchy summary GET requests now add cache-busting and `cache: no-store`.
- Delete failure opens in app popup modal.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend
```

No migration is required.

## Test

```text
/bank/subject-versions/{versionId}/chapters
→ delete a newly-created empty chapter
→ delete a chapter whose material was already deleted from workspace
```

Expected: empty chapters delete successfully, real child content still blocks deletion.
