# v25.9.16.5.69 — AP CMS Subject Catalog Term Scope Fix

## Mục tiêu

Sửa lại định nghĩa API AP CMS `get-subject-cms`: endpoint này dùng toàn hệ cao đẳng theo kỳ, không dùng `campus_code`.

## Thay đổi chính

### 1. Subject catalog gọi theo `term_name`

Sai ở v68:

```text
GET {ACADEMIC_AP_CMS_API_BASE_URL}/api/cms/get-subject-cms?campus_code=ph
```

Đúng từ v69:

```text
GET {ACADEMIC_AP_CMS_API_BASE_URL}/api/cms/get-subject-cms?term_name=Summer%202026
```

Không gửi `campus_code` query param.
Không gửi `campus` header cho request `get-subject-cms`.

### 2. Cache danh sách môn theo kỳ

Cache subject catalog đổi từ campus-scoped sang term-scoped:

```text
branch + term_name + ACADEMIC_AP_CMS_API_BASE_URL
```

Danh sách môn triển khai của một kỳ được dùng lại cho từng cơ sở khi chạy sync toàn bộ.

### 3. Luồng đồng bộ AP sau sửa

```text
1. Đồng bộ cơ sở:
   Poly  -> GET /api/cms/get-campus?product=POLY
   PTCĐ  -> GET /api/cms/get-campus?product=POLY9

2. Lấy danh sách môn triển khai theo kỳ:
   GET /api/cms/get-subject-cms?term_name=<term_name>

3. Với từng cơ sở + từng môn trong danh sách đó:
   POST legacy /get-data-cms
```

`/get-data-cms` vẫn dùng base URL legacy `ACADEMIC_AP_API_BASE_URL` vì chưa có endpoint thay thế cho dữ liệu lớp/giảng viên/sinh viên.
