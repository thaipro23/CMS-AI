# RUN v25.9.16.7.2.22 — Scope Navigation Audit + Real Totals

## Mục tiêu

Bản này xử lý lỗi production khi đi từ danh sách lớp vào chi tiết lớp rồi quay lại bị mất phạm vi `Tất cả cơ sở`, dẫn tới môn COM1071 từ 29 lớp còn 8 lớp. ## Deploy

```bash
cd /opt/ai-server

unzip -o ai-server-openedx-v25.9.16.7.2.22-scope-navigation-real-totals.zip -d /tmp/ai-server-v25.9.16.7.2.22

rsync -a --delete /tmp/ai-server-v25.9.16.7.2.22/ai_server_openedx_v25_9_16_7_2_22/ /opt/ai-server/

docker compose -f docker-compose.prod.yml --env-file .env.production build backend frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend
```

## Kiểm tra lỗi COM1071

1. Mở URL danh sách lớp môn COM1071 ở phạm vi tất cả cơ sở:

```text
/student-management/subjects/<SUBJECT_ID>/classes?term_id=<TERM_ID>&branch=poly&term_name=Summer+2026&subject_code=COM1071&subject_name=Tin+học
```

2. Kỳ vọng thấy đủ 29 lớp.
3. Bấm `Chi tiết lớp` vào một lớp bất kỳ.
4. Bấm `Quay lại danh sách lớp`.
5. Kỳ vọng vẫn là `Tất cả cơ sở` và vẫn thấy 29 lớp, không tự rơi về `campus=ps` hoặc campus của lớp vừa xem.

## Kiểm tra teacher-management

1. Mở `/teacher-management?term_id=<TERM_ID>&branch=poly`.
2. Cơ sở phải là `Tất cả cơ sở`, không tự chọn campus đầu tiên.
3. Ghi lại `Tổng số lớp`.
4. Mở `/teacher-management?term_id=<TERM_ID>&branch=poly&campus=ph`.
5. `Tổng số lớp` của `PH` không được lớn hơn tổng `Tất cả cơ sở`.
