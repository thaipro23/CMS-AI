# v25.9.16.5.0 — Student Progress CMS Sync Full Production Flow

## Mục tiêu

Bản này hoàn thiện luồng production cho Student Progress: AP roster → CMS user → Course CMS enrollment → progress/grade/component grades.

## Env khuyến nghị

```env
ACADEMIC_AUTO_CREATE_CMS_USERS=true
ACADEMIC_AUTO_ENROLL_AFTER_CMS_SYNC=true
ACADEMIC_AUTO_ADD_TEACHERS_TO_COURSE=true
ACADEMIC_AUTO_MAP_COURSE_BEFORE_CMS_SYNC=true
ACADEMIC_FULL_SYNC_LEARNING_AFTER_ENROLLMENT=true
OPENEDX_STUDENT_INSIGHT_DEFAULT_ENROLLMENT_MODE=audit
```

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Không cần migration.

## Test nhanh

1. Mở `/student-management/classes/{classId}`.
2. Bấm **Đồng bộ full CMS**.
3. Theo dõi job trong UI hoặc log worker.
4. Kỳ vọng:
   - User CMS được tạo/khớp theo AP username nếu thiếu.
   - Nếu Course CMS exact match tồn tại, hệ thống tự map an toàn.
   - Sinh viên được enroll, giáo viên được gán Course Staff.
   - Progress/grade/component grades được kéo về snapshot.

## Lưu ý

Nếu chưa tìm thấy đúng một Course CMS khớp `course-v1:FPT+{SUBJECT}+{TERM_RUN}`, full flow vẫn tạo/kiểm tra user CMS và dừng ở trạng thái `cms_users_synced_mapping_required`; quản trị cần map Course CMS rồi chạy lại.
