# RUN v25.9.16.5.32 — Full Frontend Cockpit Theme + Timed Quiz Mandatory Autosubmit

## 1. Mục tiêu

- Sửa dark mode AI Server bị lỗi giao diện.
- Thêm nút chuyển Sáng/Tối ở góc phải màn hình.
- Làm lại lớp frontend theo phong cách dashboard tối: font system/Inter-like, bo góc lớn, nền tối sâu, card tím-xanh, glow nhẹ.
- Tự nộp khi hết giờ và khóa sau hết giờ là chính sách mặc định khi tạo Quiz có timer; không để người dùng quên tích checkbox.
- Cải thiện runtime auto-submit qua API `problem_check`, không click nút.

## 2. Deploy AI Server

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## 3. Deploy MFE patch trên nhánh mfe-unit-reset

```bash
cd /opt/openedx/frontend-app-learning
git checkout mfe-unit-reset

cd /opt/ai-server
cp frontend-app-learning-patch/src/courseware/course/sequence/unit-reset/UnitResetButton.jsx \
  /opt/openedx/frontend-app-learning/src/courseware/course/sequence/unit-reset/UnitResetButton.jsx
cp frontend-app-learning-patch/src/courseware/course/sequence/unit-reset/UnitResetButton.scss \
  /opt/openedx/frontend-app-learning/src/courseware/course/sequence/unit-reset/UnitResetButton.scss

source ~/tutor-venv/bin/activate
export NODE_OPTIONS="--max-old-space-size=4096"
docker buildx use mfe-builder-6g
tutor images build mfe
tutor local stop mfe
tutor local start -d mfe
```

## 4. Deploy LMS plugin/runtime nếu auto-submit cũ chưa hoạt động

Cập nhật `openedx-unit-reset-plugin` vào Open edX image rồi kiểm tra runtime:

```bash
curl -k https://cms-test.poly.edu.vn/api/unit-reset/v1/quiz-session/runtime.js | grep "AI_QUIZ_TIMEOUT_API_SUBMIT"
```

Nếu không thấy chuỗi trên, LMS vẫn đang chạy plugin cũ.
