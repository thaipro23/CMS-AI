# RUN v25.9.16.6.3 — Learning Behavior Analytics Core Phase 0–4

## 1. Deploy

```bash
cd /opt/ai-server

# Lấy đúng đường dẫn Tutor root trên server
TUTOR_ROOT=$(tutor config printroot)
echo "Tutor root: $TUTOR_ROOT"
ls -lah "$TUTOR_ROOT/data/lms/logs/tracking.log"

# Cập nhật env production
cat >> .env.production <<EOF
OPENEDX_TRACKING_LOG_HOST_DIR=$TUTOR_ROOT/data/lms/logs
OPENEDX_TRACKING_LOG_PATH=/openedx-data/lms/logs/tracking.log
ANALYTICS_INGEST_ENABLED=true
ANALYTICS_INGEST_INTERVAL_SECONDS=60
ANALYTICS_MAX_LINES_PER_RUN=50000
ANALYTICS_VIDEO_COMPLETE_THRESHOLD=0.9
ANALYTICS_SUSPICIOUS_WATCH_RATIO=0.25
ANALYTICS_MAX_PASSIVE_SEGMENT_SECONDS=600
ANALYTICS_ENABLE_PROBLEM_CORRELATION=true
EOF

# Build/recreate backend + worker + frontend do có migration/env/version/router mới
docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Không dùng `down -v`. Không xóa volume.

## 2. Migration

Container backend tự chạy:

```bash
alembic -c alembic.ini upgrade head
```

Kiểm tra thủ công nếu cần:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend alembic -c alembic.ini current
```

Cần thấy revision:

```text
0049_v25_9_16_6_3
```

## 3. Kiểm tra tracking log mount

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend sh -lc '
  echo $OPENEDX_TRACKING_LOG_PATH
  ls -lah /openedx-data/lms/logs/tracking.log
  tail -n 3 /openedx-data/lms/logs/tracking.log
'
```

Nếu file chưa có hoặc path khác, sửa `OPENEDX_TRACKING_LOG_HOST_DIR` bằng:

```bash
tutor config printroot
```

và mount:

```text
$(tutor config printroot)/data/lms/logs:/openedx-data/lms/logs:ro
```
