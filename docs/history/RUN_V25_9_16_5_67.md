# v25.9.16.5.67 — Student Learning Cell Copy + CourseHome Completion Formula

## Mục tiêu

Sửa đúng yêu cầu hiển thị trong màn chi tiết lớp:

- Ô `Tiến độ học` chỉ còn 3 dòng: `Hoàn thành khóa học`, `Điểm tổng`, trạng thái học tập.
- Dòng cập nhật chuyển lên đầu card `Danh sách sinh viên`.
- Không để dòng mô tả dài làm rối màn hình.
- Course completion đọc đúng công thức Ulmo Course Home `completion_summary`.

## Hiển thị mới

Trong từng dòng sinh viên:

```text
Hoàn thành khóa học: N/A
Điểm tổng: 2/10
Điểm thấp.
```

Phần tiêu đề card:

```text
Danh sách sinh viên
Cập nhật: 09:45:51 29/06/2026
```

## Nguồn Course completion Ulmo 3

Nguồn chuẩn:

```text
/api/course_home/progress/{course_id}
```

Công thức:

```text
complete_count / (complete_count + incomplete_count)
```

Không lấy từ `course_grade.percent`, `final_grades`, `StudentModule` hoặc `BlockCompletion` suy diễn.

## Deploy

Không có Alembic migration.

Frontend-only nếu chỉ cần thay UI:

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

Đầy đủ nếu muốn lấy lại Course completion theo exact source:

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Nếu connector Open edX cài tách trong LMS/Tutor, update/reinstall plugin rồi chạy lại `Đồng bộ full CMS`.
