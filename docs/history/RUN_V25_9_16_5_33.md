# v25.9.16.5.33 — Frontend Hard Rebuild Clean Shell

## Mục tiêu

Bản này đập lại lớp giao diện AI Server frontend để loại bỏ các lớp CSS chồng chéo gây vỡ dark mode, chữ mờ, nền trắng lẫn nền tối và layout không đồng nhất.

## Phạm vi chính

- Rebuild lại `frontend/components/layout/AppShell.tsx` theo shell mới sạch hơn.
- Rebuild lại `frontend/app/globals.css` từ nền design system thống nhất, không giữ các lớp patch CSS cũ gây xung đột.
- Giữ nguyên logic backend, bank workflow, timer/reset/MFE logic.
- Giữ nút chuyển sáng/tối ở góc phải.
- Theme lưu trong `localStorage` với key `ai-server-theme`.

## Thiết kế

- Dark theme: nền sâu, surface tím đen, card bo lớn, border mảnh, glow nhẹ.
- Light theme: nền trắng xanh nhạt, card sạch, text rõ.
- Font: system/Inter-like.
- Sidebar giống control dashboard, không còn kiểu trắng mờ.
- Card, bảng, popup, form, trạng thái, dashboard đều dùng chung token.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

Nếu muốn deploy toàn bộ:

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Kiểm tra sau deploy

- Mở `/bank`: sidebar, topbar, dashboard phải cùng theme.
- Bấm nút `Sáng/Tối`: đổi theme ngay và F5 vẫn giữ.
- Mở các trang: `/bank/departments`, `/bank/quiz`, `/jobs`, `/student-management`, `/settings`.
- Kiểm tra popup, table, card, form không còn chữ trắng trên nền trắng hoặc chữ mờ không đọc được.
