# Run v25.9.15.6.11

## Build đồng bộ

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build --no-cache backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Nếu chỉ muốn test frontend nhanh

Bản này có sửa backend API mới, nên vẫn nên build backend + frontend. Không chỉ rebuild frontend.

## Xem log realtime

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production logs backend -f --tail=300
```

## Test thủ công

1. Vào `/bank/quiz`.
2. Dán Course ID, ví dụ `course-v1:FPT+WEB107+SU25`.
3. Bấm `Tự tìm version và Section`.
4. Kiểm tra hệ thống tìm đúng version môn và map đúng các Section cùng tên với Bài.
5. Bấm `Lưu mapping tự động`.
6. Bấm `Tạo Quiz` theo từng bài hoặc `Tạo Quiz cho tất cả bài đã map`.
7. Kiểm tra lịch sử Quiz bên dưới.
