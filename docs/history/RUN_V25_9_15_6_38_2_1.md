# v25.9.15.6.38.2.1 — RBAC Summary Visibility Hotfix

## Mục tiêu

Sửa lỗi sau `.38.2`:

- User đã được gán RBAC scope nhưng màn `/bank/departments` không hiển thị dữ liệu.
- API `GET /api/question-bank-v2/departments/summary` trả `500 Internal Server Error`.
- Cập nhật kế hoạch Dashboard: bỏ Export Excel/PDF khỏi phạm vi version dashboard kế tiếp.

## Nguyên nhân chính

Trong `backend/app/services/bank_dashboard_stats.py`, hàm `department_summary_map()` trả field:

```python
'published_version_count': published_versions
```

nhưng biến `published_versions` không tồn tại trong scope hàm. Khi frontend gọi `/departments/summary`, backend ném exception và Caddy/Uvicorn trả `500`.

## Sửa trong bản này

- Đổi sang biến đúng đã tính trong hàm: `published_subjects`.
- Giữ nguyên server-side RBAC filtering của `.38.2`.
- Thêm migration marker `0023_v25_9_15_6_38_2_1`.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Cập nhật `.env.production`:

```env
APP_VERSION=25.9.15.6.38.2.1-rbac-summary-visibility-hotfix
```

## Test nhanh

```bash
curl -s "http://api-ai.cms-test.poly.edu.vn/api/question-bank-v2/departments/summary" \
  -H "Authorization: Bearer <TOKEN>" | python3 -m json.tool
```

Kỳ vọng:

- Không còn 500.
- SYSTEM_ADMIN thấy toàn bộ bộ môn.
- DEPARTMENT_HEAD chỉ thấy bộ môn được giao.
- SUBJECT_OWNER thấy bộ môn cha và môn được giao.
- QUESTION_REVIEWER thấy bộ môn/môn/version cha và chapter được giao.
