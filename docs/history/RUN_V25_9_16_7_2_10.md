# RUN v25.9.16.7.2.10 — AP Subject CMS Replaces Get-Course Cleanup

## Mục tiêu

Bản này làm rõ và cố định luồng AP subject discovery: dùng `https://apitest.poly.edu.vn/api/cms/get-subject-cms`, không dùng `/get-course` cho danh sách môn.

Payload đã được hỗ trợ:

```json
{
  "status": 1,
  "code": 200,
  "message": 200,
  "data": [
    {
      "subject_code": "ACC106",
      "skill_code": "ACC106",
      "subject_name": "Quản trị tài chính nhà hàng khách sạn",
      "subject_name_en": "Hotel & Restaurant Financial Administration"
    }
  ]
}
```

## Deploy

```bash
cd /opt/ai-server

unzip -o ai-server-openedx-v25.9.16.7.2.10-ap-subject-cms-replaces-get-course.zip -d /tmp/ai-server-v25.9.16.7.2.10

rsync -a --delete /tmp/ai-server-v25.9.16.7.2.10/ai_server_openedx_v25_9_16_7_2_10/ /opt/ai-server/

docker compose -f docker-compose.prod.yml --env-file .env.production build backend frontend worker beat
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend worker beat
```

## Env khuyến nghị

```env
APP_VERSION=25.9.16.7.2.10
ACADEMIC_AP_CMS_API_BASE_URL=https://apitest.poly.edu.vn
ACADEMIC_AP_CMS_GET_SUBJECT_ENDPOINT=/api/cms/get-subject-cms
ACADEMIC_AP_SUBJECT_CMS_FILE_CACHE_ENABLED=true
ACADEMIC_AP_SUBJECT_CMS_FILE_CACHE_DIR=/tmp/ai-server-ap-cache/get-subject-cms
ACADEMIC_AP_SUBJECT_CMS_FILE_CACHE_TTL_SECONDS=86400
ACADEMIC_AP_SUBJECT_CMS_FILE_CACHE_REFRESH=false
```

Các biến cũ `ACADEMIC_AP_GET_COURSE_FILE_CACHE_*` vẫn được đọc để tương thích, nhưng không nên dùng mới nữa.

## Test nhanh sau deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production exec backend python - <<'PY'

PY
```

Kỳ vọng: in ra danh sách môn từ `/api/cms/get-subject-cms`, không gọi `/get-course`.
