# v25.9.16.3.4 — Bank Chapter Delete + Popup Polish

## Fixes

- Empty chapter deletion no longer fails just because a shell v1.0 bank version exists.
- App-style edit/delete modals replace native browser prompt/confirm in Bank hierarchy pages.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

No migration is required.

## Test

1. Create a new chapter in `/bank/subject-versions/{id}/chapters`.
2. Open the chapter workspace once so the empty v1.0 bank version is created.
3. Return to the chapter list and delete that chapter.
4. Expected: delete succeeds and shows the app popup, not browser confirm.
