# v25.9.16.4.0 — Student Progress Dashboard Hardening

## Mục tiêu

Bản này harden luồng theo dõi học tập thật sau khi AP ↔ CMS/Open edX đã có:

- Màn Môn: hiển thị trạng thái học tập tổng hợp theo môn.
- Màn Lớp: hiển thị trạng thái học tập tổng hợp theo từng lớp.
- Chi tiết Lớp: hiển thị từng sinh viên, trạng thái học tập, điểm tổng và điểm thành phần.
- Không gọi CMS/Open edX khi chỉ F5/mở trang; dữ liệu được đọc từ snapshot trong AI Server.
- Chỉ gọi CMS/Open edX khi người dùng bấm **Cập nhật tiến độ/điểm CMS**.

## Điểm mới

### Backend

- Mở rộng `/api/academic/subjects` để trả summary học tập cấp môn:
  - `learning_enrolled_count`
  - `learning_synced_count`
  - `learning_not_enrolled_count`
  - `learning_avg_progress_percent`
  - `learning_avg_grade_percent`
  - `learning_last_synced_at`
  - `learning_alerts`
- Mở rộng `/api/academic/classes` để trả summary học tập cấp lớp.
- Mở rộng `/api/academic/classes/{class_id}/students`:
  - thêm filter `learning_status`
  - thêm `learning_status`
  - thêm `learning_component_scores`
- Mở rộng `/api/academic/classes/{class_id}/learning-summary`:
  - thêm `component_summaries`
  - thêm `status_counts`
  - thêm `alert_counts`

### Open edX plugin

- `POST /api/ai-student-insight/v1/class-analytics` trả thêm điểm thành phần best-effort từ `PersistentSubsectionGrade` nếu Open edX có dữ liệu.
- Nếu Open edX không có subsection grade persisted, API vẫn trả điểm tổng/progress như trước, không làm lỗi cả lớp.

### Frontend

- `/student-management`: thêm cột **Học tập CMS**.
- `/student-management/subjects/{subjectId}/classes`: thêm cột **Học tập CMS**.
- `/student-management/classes/{classId}`:
  - thêm khối **Điểm thành phần của lớp**.
  - thêm filter trạng thái học tập.
  - bảng sinh viên có thêm cột **Điểm tổng** và **Điểm thành phần**.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Bản này **không có migration mới**. Nếu server chưa chạy migration `v25.9.16.3.6`, vẫn cần chạy:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend \
  alembic -c alembic.ini upgrade head
```

## Deploy plugin Open edX

Cần cập nhật lại `openedx_ai_connector` trong LMS/CMS image để endpoint `class-analytics` trả thêm điểm thành phần.

```env
AI_STUDENT_INSIGHT_SHARED_SECRET=<same-secret>
```

## Test

1. Vào `/student-management` kiểm tra cột học tập CMS cấp môn.
2. Bấm **Xem lớp** kiểm tra cột học tập CMS cấp lớp.
3. Vào chi tiết lớp.
4. Bấm **Cập nhật tiến độ/điểm CMS**.
5. Kiểm tra:
   - Tiến độ TB.
   - Điểm TB.
   - Điểm thành phần của lớp.
   - Cột điểm thành phần theo từng sinh viên.

## Lưu ý

Điểm thành phần phụ thuộc vào Open edX có lưu `PersistentSubsectionGrade`. Nếu course chưa có grade persisted cho subsection/component, dashboard vẫn hiển thị điểm tổng và progress; cột điểm thành phần sẽ báo chưa có dữ liệu.
