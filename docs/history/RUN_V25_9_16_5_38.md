Khôi phục giao diện AI Server về nền frontend v25.9.16.5.27 ổn định, sau đó chỉ thêm đúng các cải tiến UX nhỏ theo yêu cầu:

- Không dùng global loading overlay che toàn trang.
- Upload tài liệu chỉ hiện loading tại khu vực/nút tài liệu: `Đang up tài liệu`.
- Tạo câu hỏi chỉ hiện loading tại nút/khu vực tạo câu hỏi.
- Chốt bộ đề, kiểm tra thay đổi, public thư viện, duyệt hết câu chờ, xóa tài liệu dùng loading cục bộ ở chính nút đó.
- Banner tác vụ dài hạn tồn tại độc lập với popup, có `role="status"`, `aria-live="polite"`, progressbar indeterminate và step line.
- Copy trạng thái dùng công thức: Tác nhân → động từ chuyên môn → đối tượng → trấn an/ngữ cảnh tiếp theo.

## Deploy chỉ frontend AI Server

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

Sau deploy, hard refresh trình duyệt:

```text
Ctrl + F5
```

5. Kiểm tra thay đổi/chốt bộ đề/public: chỉ nút tương ứng loading.
