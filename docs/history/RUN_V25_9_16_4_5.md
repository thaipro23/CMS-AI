# v25.9.16.4.5 — Academic Async Sync Jobs + Open edX Connector Modular Split

## Mục tiêu

Bản này làm tiếp sau `v25.9.16.4.4` với 2 thay đổi lớn:

1. Tách `openedx_ai_connector/views.py` khỏi file đơn khối lớn.
2. Đổi thao tác sync lớp ở Student Management sang Celery async job có progress polling.

## Thay đổi chính

### 1. Open edX connector modular split

`openedx_ai_connector/views.py` hiện chỉ còn compatibility re-export mỏng.

Logic được tách ra:

```text
openedx_ai_connector/auth.py
- HMAC validation
- nonce replay protection
- request JSON/body limit
- SSRF/download URL guard
- connector require helpers

openedx_ai_connector/runtime.py
- lazy Open edX runtime imports

openedx_ai_connector/student_insight.py
- users/resolve
- courses/search
- class-analytics
- course-enrollment
- course-progress
- quiz-grades

openedx_ai_connector/studio.py
- course content/studio content
- session bridge
- quiz node / itembank
- library publish/import/verify/delete
```

URL contract giữ nguyên.

### 2. Class sync async job

Thêm bảng:

```text
academic_class_sync_jobs
```

Thêm endpoint queue job:

```http
POST /api/academic/classes/{class_id}/cms-sync-check/jobs
POST /api/academic/classes/{class_id}/cms-enrollment-sync/jobs
POST /api/academic/classes/{class_id}/learning-sync/jobs
```

Thêm endpoint polling:

```http
GET /api/academic/classes/{class_id}/sync-jobs/{job_id}
GET /api/academic/classes/{class_id}/sync-jobs?limit=10
```

Celery task mới:

```text
academic_class_sync_task
```

Job status:

```text
queued
running
completed
failed
```

### 3. Frontend Student Management

Ở `/student-management/classes/{classId}`:

- Nút Đồng bộ CMS tạo job thay vì chờ request trực tiếp.
- Nút Enrollment Course CMS tạo job.
- Nút Cập nhật tiến độ/điểm tạo job.
- UI poll `/sync-jobs/{job_id}` mỗi 1.5s.
- Có progress bar và progress label.
- Khi job xong, UI reload summary/students từ AI Server cache/database.

## Deploy

Bản này có migration DB mới.

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend \
  alembic -c alembic.ini upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Nếu dùng plugin Open edX, cần rebuild/redeploy `openedx_ai_connector` vào LMS/CMS image rồi restart LMS/CMS.

## Test checklist

Backend:

```bash
cd backend
python -m py_compile app/worker.py app/api/routes/academic.py app/models/academic.py app/schemas/academic.py
python -m pytest -q
```

Frontend:

```bash
cd frontend
npm install
npm run typecheck
npm run build
```

Open edX plugin:

```bash
python -m py_compile openedx_ai_connector/*.py
```

Manual QA:

1. Mở chi tiết lớp.
2. Bấm Đồng bộ CMS.
3. Kiểm tra UI hiện job queued/running/completed.
4. Bấm Enrollment Course CMS.
5. Bấm Cập nhật tiến độ/điểm.
6. Refresh trang: không gọi Open edX trực tiếp, chỉ đọc AI Server DB.
7. Kill worker thử: job nằm queued/running, không block Uvicorn request.
8. Restart worker: job mới chạy bình thường.
