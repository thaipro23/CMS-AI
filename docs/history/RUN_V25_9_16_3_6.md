# v25.9.16.3.6 — Bank Material Hard Delete + Garbage Cleanup Policy

## Mục tiêu

Bản này sửa chính sách xóa tài liệu trong Question Bank để tránh đầy dung lượng và tránh tombstone/placeholder làm sai logic xóa bài/chapter.

## Chính sách mới

1. Tài liệu chưa dùng thật sẽ xóa cứng ngay:
   - draft/failed/placeholder rỗng;
   - tài liệu đã upload nhưng chưa sinh câu hỏi/concept/diff;
   - tombstone `status=deleted` không còn phụ thuộc audit.

2. Tài liệu đã dùng thật sẽ xóa mềm nhẹ:
   - có câu hỏi liên kết;
   - có concept liên kết;
   - có diff item tài liệu.

3. Khi xóa mềm:
   - xóa file local nếu an toàn;
   - xóa chunks để giảm dung lượng;
   - giữ metadata row, `content_hash`, `file_name`, `deleted_at`, `deleted_by` để audit.

4. Khi xóa chapter:
   - tự dọn material tombstone/placeholder/unused;
   - tự dọn bank version rỗng;
   - vẫn chặn nếu còn dữ liệu thật: câu hỏi, concept, family, release, mapping, quiz.

## Migration mới

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend \
  alembic -c alembic.ini upgrade head
```

Migration thêm cột:

```text
ai_learning_material_versions.deleted_at
ai_learning_material_versions.deleted_by
```

## Env mới

```env
BANK_MATERIAL_DELETED_RETENTION_DAYS=30
BANK_MATERIAL_CLEANUP_DEFAULT_LIMIT=500
BANK_MATERIAL_HARD_DELETE_UNUSED_ENABLED=true
BANK_MATERIAL_PURGE_DELETED_FILES_ENABLED=true
```

## API admin mới

### Kiểm tra dung lượng/tombstone

```bash
curl -k -H "Authorization: Bearer <token>" \
  "https://api-ai.cms-test.poly.edu.vn/api/question-bank-v2/admin/material-cleanup/health"
```

### Dry-run purge

```bash
curl -k -X POST -H "Authorization: Bearer <token>" \
  "https://api-ai.cms-test.poly.edu.vn/api/question-bank-v2/admin/material-cleanup/purge?dry_run=true&retention_days=30&limit=500"
```

### Purge thật

```bash
curl -k -X POST -H "Authorization: Bearer <token>" \
  "https://api-ai.cms-test.poly.edu.vn/api/question-bank-v2/admin/material-cleanup/purge?dry_run=false&retention_days=30&limit=500"
```

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend \
  alembic -c alembic.ini upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```
