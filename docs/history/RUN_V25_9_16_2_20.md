# v25.9.16.2.20 — Subject → Class → Class Detail Student Management

## Scope

This version changes Student Management to the agreed hierarchy:

```text
/student-management                         # Màn Môn
/student-management/subjects/{subjectId}/classes  # Màn Lớp theo môn
/student-management/classes/{classId}       # Chi tiết lớp + sinh viên
```

## What changed

- Main `/student-management` now lists AP subjects by selected term, branch, campus, and search text.
- Subject list is permission-aware:
  - system admin sees all;
  - user with Bank RBAC subject/department scope sees matching AP subject codes;
  - AP teacher sees assigned classes/subjects only.
- Subject screen shows class count, campus count, teacher count, student count, CMS sync count, and Course CMS mapping status.
- Course mapping is subject/term/branch-level, not class-level.
- Auto map is allowed only when the suggested Course CMS ID has exactly one synced Open edX course match.
- Class screen lists classes for a selected subject.
- Class detail screen shows roster and the renamed button `Kiểm tra đồng bộ CMS`.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

No new migration is required. If the server has not reached the academic migrations from earlier builds, run:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend \
  alembic -c alembic.ini upgrade head
```

## Smoke test

Open:

```text
/student-management
/student-management/subjects/<subjectId>/classes
/student-management/classes/<classId>
```

Check:

- Non-admin users only see subjects/classes they are permitted to see by Bank RBAC or AP teacher assignment.
- Subject auto-map only maps when one exact Course CMS match exists.
- Class detail `Kiểm tra đồng bộ CMS` updates mapped/missing user status.
