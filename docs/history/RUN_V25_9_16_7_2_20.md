# v25.9.16.7.2.20 — Student Management Behavior Button + Bulk Auto Map Sync

## Mục tiêu

Bản này nâng cấp luồng quản lý cho giáo viên/quản lý tại `/student-management`:

1. Trang chi tiết lớp `/student-management/classes/{class_id}` có nút **Hành vi học** để mở trực tiếp màn phân tích hành vi học đúng kỳ, cơ sở, môn, lớp.
2. Trang `/student-management` có nút **Auto map tất cả** theo bộ lọc hiện tại.
3. Môn nào auto map được Course CMS sẽ tự đưa các lớp của môn đó vào hàng đợi **full CMS sync**: đồng bộ user CMS, enroll vào course, và đồng bộ dữ liệu học tập.

## Không thay đổi

- Không migration.
- Không reset DB.
- Không xóa dữ liệu ngân hàng câu hỏi.
- Không đọc raw tracking log ở màn danh sách.

## Deploy

```bash
cd /opt/ai-server

unzip -o ai-server-openedx-v25.9.16.7.2.20-student-behavior-bulk-sync.zip -d /tmp/ai-server-v25.9.16.7.2.20

rsync -a --delete /tmp/ai-server-v25.9.16.7.2.20/ai_server_openedx_v25_9_16_7_2_20/ /opt/ai-server/

docker compose -f docker-compose.prod.yml --env-file .env.production build backend frontend worker
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend worker
```

Cập nhật `.env.production`:

```env
APP_VERSION=25.9.16.7.2.20
```

## Test nhanh sau deploy

### 1. Kiểm tra API bulk auto map + queue sync

Dùng token thật của user có quyền đồng bộ học vụ:

```bash
curl -sS -X POST 'https://api-ai.cms-test.poly.edu.vn/api/academic/subjects/course-mapping/auto-all-sync/jobs' \
  -H 'Authorization: Bearer <TOKEN>' \
  -H 'Content-Type: application/json' \
  -d '{
    "term_id":"<TERM_UUID>",
    "branch":"poly",
    "campus":"ph",
    "learning_status":"all",
    "force":true,
    "limit":500,
    "sync_learning":true,
    "max_classes":3000
  }' | jq
```

Kỳ vọng trả về `jobs_queued`, `jobs_reused`, `subject_mapped`, `subject_failed`.

### 2. Kiểm tra job đang chạy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production exec -T postgres sh -lc 'psql -U "$POSTGRES_USER" -d "$POSTGRES_DB" <<SQL
SELECT status, job_type, COUNT(*)
FROM academic_class_sync_jobs
WHERE created_at > now() - interval '\''2 hours'\''
GROUP BY status, job_type
ORDER BY status, job_type;
SQL'
```

### 3. Kiểm tra nút Hành vi học

Mở một lớp:

```text
http://ai.cms-test.poly.edu.vn/student-management/classes/<CLASS_UUID>
```

Bấm **Hành vi học**. URL phải có dạng:

```text
/analytics/learning?branch=poly&term_id=...&campus=ph&subject_id=...&class_id=...&classification=all
```
