# v25.9.15.6.38 — Frontend Scale Redesign

Bản này thực hiện bước kế hoạch `v25.9.15.6.38 — Frontend Scale Redesign` sau các nền tảng scale backend từ `.32` đến `.37`.

## Mục tiêu

Không đổi nghiệp vụ chính. Mục tiêu là giảm rủi ro FE khi dữ liệu lớn và khi tiếp tục phát triển:

- Tách `frontend/app/bank/_components/BankPages.tsx` khỏi dạng god component gần 1.400 dòng.
- Tách từng màn Bank thành module riêng để sửa trang nào ít ảnh hưởng trang khác.
- Giữ wrapper `BankPages.tsx` cũ để các route hiện tại không cần đổi import.
- Giữ chapter workspace dùng cursor/keyset + DTO nhẹ từ `.36`.
- Giữ các thao tác nặng dùng job/polling từ `.37`.
- Thêm Alembic marker no-op để trace được release `.38` trong chuỗi deploy.

## Tương thích

Các route vẫn import từ `BankPages.tsx`, ví dụ:

```ts
import { BankDashboardPage } from './_components/BankPages'
```

Nên các route hiện tại không cần đổi.

## Kiểm tra đã chạy trong sandbox

```bash
cd frontend
npm ci --ignore-scripts --no-audit --no-fund
npm run typecheck
```

Kết quả: `PASS`.

```bash
python3 -m compileall -q backend/app backend/alembic
```

Kết quả: `PASS`.

Tôi có chạy `npm run build`; Next đã `Compiled successfully` và dừng do timeout ở bước `Collecting page data` trong sandbox. Vì vậy cần build Docker trên server để xác nhận production build cuối cùng.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Cập nhật `.env.production`:

```env
APP_VERSION=25.9.15.6.38-frontend-scale-redesign
```
