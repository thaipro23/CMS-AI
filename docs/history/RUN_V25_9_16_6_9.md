# v25.9.16.6.9 — Analytics Production Hardening Final

## Mục tiêu

Bản này là lớp khóa an toàn cuối cho Learning Analytics / Aspects-lite trước khi dùng production:

- Không tạo bảng mới.
- Không đổi Course completion.
- Không đổi connector contract.
- Không đổi classifier nhãn mềm.
- Không query raw tracking.log khi mở dashboard/health/readiness.
- Thêm production readiness gate rõ ràng.
- Chặn enqueue/backfill quá tay.
- Giới hạn export CSV để tránh kéo sập API.
- Smoke test có kiểm tra production readiness.

## API mới/được nâng cấp

```text
GET /api/analytics/ops/production-readiness
GET /api/analytics/ops/status
GET /api/health/analytics
```

`/api/analytics/ops/production-readiness` trả về:

```json
{
  "readiness": "PRODUCTION_READY | NOT_READY",
  "ready_for_production": true,
  "blocker_count": 0,
  "warning_count": 0,
  "issues": [],
  "checks": {
    "tracking_log_mounted": true,
    "ingest_enabled": true,
    "scheduler_enabled": true,
    "tracking_event_count": 12345,
    "behavior_snapshot_count": 500,
    "active_recalculate_jobs": 0
  },
  "safe_policy": "signals_only_not_violation"
}
```

## Cấu hình production mới

Thêm vào `.env.production` nếu muốn override:

```bash
ANALYTICS_BACKFILL_MAX_JOBS_PER_REQUEST=25
ANALYTICS_BACKFILL_MAX_ACTIVE_JOBS=20
ANALYTICS_RECALCULATE_ENQUEUE_COOLDOWN_SECONDS=300
ANALYTICS_INGEST_ENQUEUE_COOLDOWN_SECONDS=120
ANALYTICS_EXPORT_MAX_ROWS=50000
ANALYTICS_PRODUCTION_MIN_EVENTS=1
ANALYTICS_PRODUCTION_MIN_SNAPSHOTS=1
```

Khuyến nghị production:

```bash
ANALYTICS_INGEST_ENABLED=true
ANALYTICS_INGEST_SCHEDULER_ENABLED=true
ANALYTICS_INGEST_INTERVAL_SECONDS=60
OPENEDX_TRACKING_LOG_PATH=/openedx-data/lms/logs/tracking.log
OPENEDX_TRACKING_LOG_HOST_DIR=$(tutor config printroot)/data/lms/logs
```

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Nếu chưa chạy migration v6.3:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend alembic upgrade head
```

## Checklist production

1. `/api/health/analytics` trả `status=ok`.
2. `/api/analytics/ops/production-readiness` không có blocker.
3. `tracking_log_exists=true`.
4. `analytics_ingest_enabled=true`.
5. Production nên bật `analytics_ingest_scheduler_enabled=true`.
6. `tracking_event_count > 0` sau ingest.
7. `behavior_snapshot_count > 0` sau backfill.
8. Dashboard `/analytics/learning` hiện Production readiness.
9. Backfill không enqueue vượt `ANALYTICS_BACKFILL_MAX_JOBS_PER_REQUEST`.
10. Export CSV có disclaimer và bị giới hạn bởi `ANALYTICS_EXPORT_MAX_ROWS`.
