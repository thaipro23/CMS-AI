# v25.9.16.5.16 — Restore openedx_unit_reset v0.4.14 Plugin

Mục tiêu: đưa lại đúng plugin `openedx_unit_reset v0.4.14 — Submit Button Only No Save Hotfix` vào package AI Server hiện tại, tránh rollback về plugin cũ `0.4.2/0.3.0`.

## Điểm chính

- `openedx-unit-reset-plugin/setup.py` version = `0.4.14`.
- `openedx_unit_reset.__version__ = 0.4.14`.
- Runtime `/api/unit-reset/v1/quiz-session/runtime.js` chỉ click nút Submit/Check/Nộp bài/Kiểm tra.
- Runtime denylist rõ ràng Save/Lưu/problem_save, không click Save nữa.
- Giữ logic cooldown đúng từ v0.4.13: `reset_available_at = expires_at + cooldown_seconds`, không tính từ `lock_at`.
- Khi timeout, session đã lưu sẵn `reset_available_at` để không phụ thuộc browser có gọi `/lock` hay không.
- Thêm `tutor-plugins/openedx_unit_reset.py` để build/install đúng plugin từ `openedx-unit-reset-plugin`.

## Deploy Open edX plugin

```bash
source ~/tutor-venv/bin/activate
cd /opt/openedx/CMS-FPT

# Copy folder openedx-unit-reset-plugin và tutor-plugins/openedx_unit_reset.py từ artifact này vào repo CMS-FPT.
cp tutor-plugins/openedx_unit_reset.py "$(tutor plugins printroot)/openedx_unit_reset.py"

tutor plugins enable openedx_unit_reset
tutor config save

tutor images build openedx --no-cache
tutor local stop
tutor local start -d

tutor local run lms ./manage.py lms migrate openedx_unit_reset
```

## Production policy an toàn

Auto-submit DOM trong Open edX iframe không ổn định tuyệt đối. Nếu cần ổn định ngay:

```bash
tutor local run lms ./manage.py lms shell -c "
from openedx_unit_reset.models import UnitQuizTimerConfig
qs = UnitQuizTimerConfig.objects.all()
print('CONFIG COUNT:', qs.count())
print('UPDATED:', qs.update(auto_submit_on_timeout=False, lock_after_timeout=True))
"
tutor local restart lms lms-worker mfe
```
