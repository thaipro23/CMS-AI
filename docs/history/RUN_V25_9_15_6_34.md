# v25.9.15.6.34 — Dashboard Summary Engine

## Mục tiêu

Bản này thực hiện đúng bước kế hoạch `v25.9.15.6.34`: Bank Dashboard không được aggregate trực tiếp bảng `ai_questions` khi request dashboard chạy. Với mục tiêu 6 bộ môn, 300 môn, 1.500 phiên bản môn, 15.000 bài và 1.500.000 câu hỏi, dashboard phải đọc bảng summary nhẹ theo chapter.

## Thay đổi chính

- Thêm bảng `ai_bank_chapter_stats`.
- Thêm model `BankChapterStats`.
- Thêm service `backend/app/services/bank_dashboard_stats.py`.
- `dashboard_overview`, department/subject/offering/chapter summaries đọc `ai_bank_chapter_stats` + bảng hierarchy nhỏ.
- Thêm Redis cache ngắn hạn cho dashboard/summaries:
  - `bank_dashboard_overview:v1`
  - `bank_department_summary:v1`
  - `bank_subject_summary:{department_id}`
  - `bank_offering_summary:{subject_id}`
  - `bank_chapter_summary:{subject_offering_id}`
- Thêm admin endpoints:
  - `GET /api/question-bank-v2/admin/stats/health`
  - `POST /api/question-bank-v2/admin/stats/rebuild`
  - `POST /api/question-bank-v2/admin/stats/rebuild?chapter_id=<id>`
- Thêm best-effort realtime refresh sau các thao tác chính:
  - tạo/sửa chapter, tạo bank version
  - upload/xóa material
  - generate câu hỏi
  - edit/review/bulk review câu hỏi
  - carry-over/retire câu hỏi
  - create/cancel/publish release
- `dashboard_search` không search `ai_questions`; bản `.35` mới làm FTS/trigram search engine đầy đủ.

## Env mới

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Bước bắt buộc sau migration

Migration chỉ tạo bảng, không tự scan dữ liệu lớn. Sau deploy, chạy rebuild stats một lần trong giờ thấp tải:

```bash
curl -X POST "http://api-ai.cms-test.poly.edu.vn/api/question-bank-v2/admin/stats/rebuild" \
  -H "Authorization: Bearer <AI_ADMIN_TOKEN>"
```

Nếu chỉ muốn rebuild một bài:

```bash
curl -X POST "http://api-ai.cms-test.poly.edu.vn/api/question-bank-v2/admin/stats/rebuild?chapter_id=<CHAPTER_ID>" \
  -H "Authorization: Bearer <AI_ADMIN_TOKEN>"
```

## Kiểm tra health

```bash
curl -s "http://api-ai.cms-test.poly.edu.vn/api/question-bank-v2/admin/stats/health" \
  -H "Authorization: Bearer <AI_ADMIN_TOKEN>" | python3 -m json.tool
```

Kỳ vọng:

```json
{
  "ok": true,
  "summary_table": "ai_bank_chapter_stats",
  "missing_stats_count": 0,
  "dashboard_reads_questions_directly": false
}
```

## Definition of done

- `Bank Dashboard` không query `ai_questions` trực tiếp.
- Dashboard overview đọc `ai_bank_chapter_stats` và bảng hierarchy nhỏ.
- Có endpoint rebuild/health để vận hành stats.
- Có cache 30–60 giây qua Redis, default 45 giây.
- Khi dữ liệu cũ chưa rebuild, health báo `missing_stats_count` để admin biết phải rebuild.

## Chưa làm trong bản này

- Chưa làm Bank Search Engine FTS/trigram. Đó là bước `.35`.
- Chưa tách lightweight question DTO. Đó là bước `.36`.
- Chưa async upload/generate/publish. Đó là bước `.37`.
