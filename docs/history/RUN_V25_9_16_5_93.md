# RUN — v25.9.16.5.93 Class Detail Performance + Real Data QA

## Mục tiêu

Bản này rà và tối ưu màn chi tiết lớp sau khi Course completion đã lấy đúng:

- Không gọi lại overview/mapping/learning summary khi chỉ tìm kiếm, lọc trạng thái, hoặc chuyển trang sinh viên.
- Chỉ bảng `Danh sách sinh viên` reload theo filter/page.
- Assignment workflow vẫn lazy-load: chỉ gọi API khi bấm mở modal.
- Thông báo UI ngắn hơn, bỏ các mô tả kỹ thuật dài.
- Debug nguồn dữ liệu quiz chỉ hiện khi mở URL có `?debug=1`.
- Backend chỉ lấy điểm Assignment cho sinh viên của trang hiện tại khi render danh sách sinh viên.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Không có migration mới.

## Restart connector Open edX

Bản này bump connector version để kiểm tra đồng bộ package. Sau khi cập nhật plugin, restart:

```bash
tutor local restart lms cms lms-worker cms-worker
```

Kiểm tra:

```bash
tutor local run lms python - <<'PY'
import importlib
m = importlib.import_module('openedx_ai_connector.student_insight')
print('CONNECTOR_VERSION=', getattr(m, 'CONNECTOR_VERSION', None))
PY
```

Kỳ vọng:

```text
CONNECTOR_VERSION= 25.9.16.5.93
```

## QA nhanh

1. Mở chi tiết lớp.
2. Đổi trang sinh viên hoặc lọc `Chưa vào học` / `Điểm thấp`.
3. Kiểm tra Network: chỉ nên gọi `/academic/classes/{classId}/students?...`; không gọi lại `/mapping-summary` và `/learning-summary` nếu chỉ đổi filter/page.
4. Bấm `Cập nhật điểm`; sau khi job xong hệ thống refresh lại overview + trang sinh viên hiện tại.
5. Kiểm tra completion thật:
   - `duongddph69321`: 5/8 = 62.5% ≈ 63%.
   - sinh viên chỉ có itembank rows: 0/8 = 0%.
