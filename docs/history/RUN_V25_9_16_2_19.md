# v25.9.16.2.19 - Academic Modal Polish

This is a UI-only hotfix based on `v25.9.16.2.18`.

## Changes

- `/premises`
  - Add/edit popup fields are displayed vertically, one field per row.
  - Delete confirmation uses the same styled modal system as the rest of the app.

- `/semesters`
  - Delete confirmation uses the same styled modal system as the rest of the app.

- `/ap-sync`
  - AP sync confirmation uses a styled modal instead of browser confirm.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

No new migration is required. If the server has not yet applied the academic migrations, run:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend \
  alembic -c alembic.ini upgrade head
```
