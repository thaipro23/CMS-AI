# v25.9.16.7.2.19 — Learning Behavior Production Test Flow

## Mục tiêu

Bản này tiếp tục harden màn `/analytics/learning` để có thể test production theo đúng luồng giáo viên:

`Hệ → Học kỳ → Cơ sở → Môn → Danh sách lớp → Chi tiết lớp → Kết quả sinh viên → Lý do`

Màn chính vẫn chỉ hiện kết quả. Lý do/evidence chỉ mở khi giáo viên bấm vào pill kết quả của sinh viên.

## Thay đổi chính

1. `/analytics/learning` hỗ trợ mở trực tiếp bằng query params:
   - `branch`
   - `term_id`
   - `campus`
   - `subject_id`
   - `class_id`
   - `classification`

2. Từ `/teacher-management/teachers/{teacherId}/classes`, mỗi lớp có thêm nút `Hành vi học`.

3. Backend endpoint class overview nhận thêm `class_id`:

```http
GET /api/analytics/subjects/{subject_id}/classes/learning-behavior/overview?term_id=...&branch=poly&campus=ph&class_id=...
```

4. Class overview dùng page size 200 và có phân trang, tránh lặp lại lỗi validation hoặc request quá lớn.

5. Thêm script test production:

```bash
scripts/learning-behavior-production-verify.sh
```

Script kiểm tra:
- API môn dùng `page_size=200`.
- API danh sách lớp dùng `limit=200`.
- Không trả `422`.
- Có `safe_policy=signals_only_not_violation`.
- Không có wording khẳng định vi phạm như `gian lận`, `cheating`, `treo máy chắc chắn`.

## Deploy

```bash
cd /opt/ai-server

unzip -o ai-server-openedx-v25.9.16.7.2.19-learning-behavior-production-test-flow.zip -d /tmp/ai-server-v25.9.16.7.2.19

rsync -a --delete /tmp/ai-server-v25.9.16.7.2.19/ai_server_openedx_v25_9_16_7_2_19/ /opt/ai-server/

docker compose -f docker-compose.prod.yml --env-file .env.production build backend frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend
```

Cập nhật `.env.production`:

```env
APP_VERSION=25.9.16.7.2.19
```

## Test production learning behavior

Lấy `TERM_ID`, `SUBJECT_ID`, `CLASS_ID` từ UI hoặc DB, rồi chạy:

```bash
cd /opt/ai-server

AUTH_HEADER='Authorization: Bearer <TOKEN>' \
API_BASE_URL='https://api-ai.cms-test.poly.edu.vn' \
BRANCH='poly' \
TERM_ID='<TERM_UUID>' \
CAMPUS='ph' \
SUBJECT_ID='<SUBJECT_UUID>' \
CLASS_ID='<CLASS_UUID>' \
./scripts/learning-behavior-production-verify.sh
```

Có thể bỏ `CLASS_ID` để chỉ test danh sách lớp theo môn.
