# v25.9.15.6.31.1 - Build Fix for Bank Quiz Popup String

## Fix

Fixed frontend TypeScript compile error in:

- `frontend/app/bank/quiz/page.tsx`

Error fixed:

```text
TS1002: Unterminated string literal
TS1005: ',' expected
```

Cause: confirmation popup text used a broken multiline string separator.

Corrected to:

```ts
].join('\n')
```
