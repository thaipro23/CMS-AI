# v25.9.15.6.31 - Cohesive Bank Hierarchy + Chapter Workspace UX

## Mục tiêu

Làm các trang ngân hàng đề ăn khớp thành một luồng thống nhất:

- `/bank/departments`
- `/bank/departments/{departmentId}/subjects`
- `/bank/subjects/{subjectId}/versions`
- `/bank/subject-versions/{versionId}/chapters`
- `/bank/chapters/{chapterId}`

## Thay đổi chính

### 1. Bố cục thống nhất

Các trang Bộ môn → Môn → Version → Bài → Workspace có cùng ngôn ngữ UI:

- Breadcrumb rõ ràng.
- Flow tabs: `Bộ môn → Môn → Version → Bài → Câu hỏi → Release`.
- Card/list nhìn đồng bộ hơn, khoảng cách và hover state hiện đại hơn.

### 2. Workspace bài gọn hơn

Trang `/bank/chapters/{chapterId}` bỏ hai khối lớn đặt ngoài màn hình:

- `Tài liệu`
- `Tạo câu hỏi từ tài liệu`

Hai phần này chuyển thành nút ở thanh thao tác:

- `Tài liệu (n)` → mở popup quản lý tài liệu.
- `Tạo câu hỏi` → mở popup cấu hình/tính chi phí/tạo câu hỏi.

Màn hình chính tập trung vào việc giáo viên cần làm nhiều nhất: đọc, lọc, sửa, duyệt/bỏ câu hỏi.

### 3. Thêm filter câu hỏi

Trong workspace bài thêm thanh lọc:

- Lọc theo trạng thái:
  - Tất cả
  - Cần xử lý
  - Chờ duyệt
  - Câu lỗi
  - Đã duyệt
  - Đã bỏ
  - Đã publish
- Lọc theo độ khó:
  - Dễ
  - Trung bình
  - Khó
- Sắp xếp:
  - Cần xử lý trước
  - Theo độ khó
  - Điểm chất lượng thấp trước
  - Điểm chất lượng cao trước

## Deploy

Chỉ sửa frontend AI Server, không cần migrate DB.

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

Sau deploy vào các trang `/bank/...` và nhấn `Ctrl + F5`.
