# v25.9.15.6.35 - Bank Search Engine

## Mục tiêu

Bản này triển khai bước kế hoạch `v25.9.15.6.35 — Bank Search Engine`:

- Không search kiểu load toàn bộ hierarchy/question vào Python.
- Bật nền `pg_trgm`/`unaccent` cho PostgreSQL.
- Tạo bảng search nhẹ `ai_question_search_documents` với `search_text` và PostgreSQL generated `search_vector`.
- Search theo nhóm entity: department, subject, subject version, chapter, question.
- Quick search `/bank` dùng engine mới nhưng không phá UI cũ.
- Có endpoint admin rebuild/health cho search index.

## Lưu ý quan trọng

Migration **không tự backfill** toàn bộ câu hỏi để tránh deploy production bị treo khi sau này có 1.500.000 câu. Với database test hiện chỉ khoảng 200 câu, bạn có thể rebuild toàn bộ ngay sau deploy bằng endpoint admin.

## Env mới

```env
APP_VERSION=25.9.15.6.35-bank-search-engine
BANK_SEARCH_MAX_RESULTS=50
```

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Rebuild search index sau deploy

Vì database test hiện khoảng 200 câu, rebuild toàn bộ là ổn:

```bash
curl -X POST "http://api-ai.cms-test.poly.edu.vn/api/question-bank-v2/admin/search/rebuild" \
  -H "Authorization: Bearer <AI_ADMIN_TOKEN>"
```

Nếu sau này dữ liệu lớn, rebuild theo scope:

```bash
curl -X POST "http://api-ai.cms-test.poly.edu.vn/api/question-bank-v2/admin/search/rebuild?chapter_id=<CHAPTER_ID>" \
  -H "Authorization: Bearer <AI_ADMIN_TOKEN>"

curl -X POST "http://api-ai.cms-test.poly.edu.vn/api/question-bank-v2/admin/search/rebuild?bank_version_id=<BANK_VERSION_ID>" \
  -H "Authorization: Bearer <AI_ADMIN_TOKEN>"
```

## Kiểm tra health

```bash
curl -s "http://api-ai.cms-test.poly.edu.vn/api/question-bank-v2/admin/search/health" \
  -H "Authorization: Bearer <AI_ADMIN_TOKEN>" | python3 -m json.tool
```

Kỳ vọng:

```json
{
  "ok": true,
  "missing_or_unindexed_count": 0,
  "stale_document_count": 0
}
```
