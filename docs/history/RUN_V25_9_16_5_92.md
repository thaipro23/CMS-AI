# v25.9.16.5.92 — Class Detail Student Progress Text + Native Student Table Scroll

## Mục tiêu

- Cột **Tiến độ học** chỉ hiển thị 3 dòng cần dùng:
  - `Hoàn thành khóa học: ...`
  - `Điểm tổng: ...`
  - trạng thái, ví dụ `Điểm thấp`
- Không thêm dấu chấm sau trạng thái.
- Chỉ **Danh sách sinh viên** có cuộn ngang khi có nhiều cột Quiz.
- Các thẻ khác trong chi tiết lớp giữ nguyên, không bị kéo ngang theo bảng.
- Bỏ custom kéo bảng bằng chuột / Shift-wheel logic để tránh cảm giác bảng bị kéo trực tiếp.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

Nếu muốn đồng bộ toàn bộ image theo thói quen deploy:

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```
