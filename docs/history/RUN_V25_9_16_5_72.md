# v25.9.16.5.72 — AP CMS Campus Sync 500 Hotfix

## Lý do

Màn `/ap-sync` gọi:

- `POST /api/academic/campuses/sync-from-ap?branch=poly`
- `POST /api/academic/campuses/sync-from-ap?branch=ptcd`

và có thể trả HTTP 500 ngay khi backend chưa gọi được AP CMS do `APAcademicClient` đang bắt buộc `ACADEMIC_AP_API_KEY` ngay cả với API master-data mới `get-campus`/`get-subject-cms`.

## Sửa

- `get-campus` và `get-subject-cms` không còn bắt buộc legacy `ACADEMIC_AP_API_KEY` lúc khởi tạo client.
- Header `Authorization: Bearer ...` chỉ được gửi khi env có API key.
- Legacy `/get-data-cms` vẫn bắt buộc `ACADEMIC_AP_API_KEY` vì đó là luồng lấy lớp/giảng viên/sinh viên cũ.
- Route `POST /api/academic/campuses/sync-from-ap` đã bắt lỗi và trả `502` kèm `detail` rõ ràng thay vì lỗi 500 trắng.

## Env khuyến nghị

```env
ACADEMIC_AP_CMS_API_BASE_URL=http://apitest.poly.edu.vn
ACADEMIC_AP_CMS_GET_CAMPUS_ENDPOINT=/api/cms/get-campus
ACADEMIC_AP_CMS_PRODUCT_POLY=POLY
ACADEMIC_AP_CMS_PRODUCT_PTCD=POLY9
ACADEMIC_AP_CMS_GET_SUBJECT_ENDPOINT=/api/cms/get-subject-cms?campus_code=ph&term_name=
```

Khi chạy đồng bộ full AP legacy `/get-data-cms`, vẫn cần:

```env
ACADEMIC_AP_API_BASE_URL=https://api_v2.poly.edu.vn
ACADEMIC_AP_API_KEY=...
```

## Deploy

Không có migration mới.

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Sau deploy, reload `/ap-sync` và bấm lại **Đồng bộ danh sách cơ sở**.

## Nếu vẫn lỗi

Lấy log backend:

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production logs -n 200 backend
```

Nếu thấy lỗi kiểu `relation academic_campuses does not exist`, chạy migration DB của AI Server trước khi test lại.
