# RUN v25.9.16.7.2.11 — AP Subject Endpoint Env Template Default

## Mục tiêu

Bản này sửa đúng thực tế AP hiện tại: endpoint danh sách môn phải gọi dạng:

```text
/api/cms/get-subject-cms?campus_code=ph&term_name=Summer+2026
```

Vì AP đang yêu cầu `campus_code=ph`, `.env.production` nên để query-template có sẵn `campus_code=ph&term_name=`. Khi AP về sau không cần campus nữa, chỉ đổi env thành `/api/cms/get-subject-cms?term_name=` là được.

## Env production cần dùng hiện tại

```env
APP_VERSION=25.9.16.7.2.11
ACADEMIC_AP_CMS_API_BASE_URL=https://apitest.poly.edu.vn
ACADEMIC_AP_CMS_GET_SUBJECT_ENDPOINT=/api/cms/get-subject-cms?campus_code=ph&term_name=
```

## Env tương lai khi AP bỏ campus_code

```env
ACADEMIC_AP_CMS_GET_SUBJECT_ENDPOINT=/api/cms/get-subject-cms?term_name=
```

## Deploy

```bash
cd /opt/ai-server

unzip -o ai-server-openedx-v25.9.16.7.2.11-ap-subject-env-template-default.zip -d /tmp/ai-server-v25.9.16.7.2.11

rsync -a --delete /tmp/ai-server-v25.9.16.7.2.11/ai_server_openedx_v25_9_16_7_2_11/ /opt/ai-server/

docker compose -f docker-compose.prod.yml --env-file .env.production build backend frontend worker beat
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend worker beat
```
