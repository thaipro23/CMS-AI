# v25.9.16.5.25 — Bank Chapter Persistent Operation UX Hotfix

## Mục tiêu

Sửa UX trang `/bank/chapters/{chapterId}` khi gắn tài liệu và tạo câu hỏi:

- Lỗi upload tài liệu hiển thị ngay trong popup tài liệu, không chỉ hiện ngoài trang.
- Sau khi bấm xác nhận tạo câu hỏi, trang hiển thị trạng thái `AI đang tạo {N} câu hỏi, vui lòng chờ...`.
- Khi gắn tài liệu, trang hiển thị trạng thái `Đang thêm tài liệu {file}, vui lòng chờ...`.
- Trạng thái job được lưu vào `localStorage`, F5 không mất trạng thái và không làm người dùng bấm lặp lại cùng một thao tác.
- Trang tự poll lại Operation Job sau F5; khi job xong thì tự refresh dữ liệu bài.
- Bỏ block `Bạn cần làm gì tiếp?` để giao diện gọn hơn.

## Thay đổi chính

### Frontend

- `frontend/app/bank/_components/pages/ChapterWorkspacePage.tsx`
  - Thêm persistent operation state theo chapter.
  - Thêm polling Operation Job sau khi enqueue generate/upload.
  - Lưu job đang chạy vào `localStorage` theo key `ai-bank-chapter-operation:{chapterId}`.
  - Hiển thị thông báo lỗi/thành công trong popup tài liệu và popup tạo câu hỏi.
  - Disable thao tác khi đang có job chạy để tránh bấm lặp.
  - Bỏ card `Bạn cần làm gì tiếp?`.

- `frontend/lib/api.ts`
  - Thêm `enqueueGenerateFromBankVersion`.
  - Thêm `enqueueBankMaterialUpload`.
  - Giữ lại API cũ `generateFromBankVersion` và `uploadBankMaterial` để không phá các màn khác.

- `frontend/app/globals.css`
  - Thêm style cho banner trạng thái job đang chạy.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

Nếu deploy full stack:

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend
docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Test nhanh

1. Vào `/bank/chapters/{chapterId}`.
2. Mở popup Tài liệu, upload file lỗi hoặc file không hợp lệ.
3. Kỳ vọng lỗi hiện ngay trong popup.
4. Upload tài liệu hợp lệ.
5. F5 trong lúc job đang chạy.
6. Kỳ vọng vẫn thấy trạng thái đang thêm tài liệu và trang tự cập nhật khi xong.
7. Bấm tạo câu hỏi, xác nhận tạo.
8. Kỳ vọng thấy `AI đang tạo N câu hỏi, vui lòng chờ...`; F5 vẫn còn trạng thái và không cần bấm lại.
