# v25.9.15.6.38.2 — RBAC Scope Enforcement Audit

Mục tiêu: siết lại phân quyền hiển thị và API theo đúng kiến trúc AI Question Bank.

## Nguyên tắc đã áp dụng

- AI Server là nguồn sự thật RBAC nghiệp vụ.
- Open edX chỉ giữ quyền kỹ thuật tối thiểu.
- Không tạo custom role nghiệp vụ trong Open edX.
- Role cao hơn kế thừa quyền role dưới nhưng không vượt scope được giao.
- User non-system chỉ thấy node cha hoặc node con trong nhánh được giao.
- FE chỉ ẩn nút; BE vẫn là lớp chặn quyền cuối.

## Hiển thị theo scope

- `DEPARTMENT_HEAD` tại department A: thấy department A, các môn/version/bài bên dưới A.
- `SUBJECT_OWNER` tại subject B: thấy department cha, subject B, version/bài bên dưới B.
- `SUBJECT_OWNER` tại subject version C: thấy department cha, subject cha, version C, bài bên dưới C.
- `QUESTION_REVIEWER` tại chapter D: thấy department cha, subject cha, version cha, chỉ chapter D.
- Không role nào thấy sibling branch ngoài scope, trừ `SYSTEM_ADMIN`.

## API được rà scope

- `/departments`, `/subjects`, `/subject-offerings`, `/chapters`
- `/bank-versions`, `/material-versions`, `/releases`
- `/course-mappings`, `/course-chapter-mappings`
- `/course-quiz-instances`, `/quiz-blueprints`
- `/dashboard/overview`, `/summary`, `/dashboard/search`, `/search`

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

`.env.production`:

```env
APP_VERSION=25.9.15.6.38.2-rbac-scope-enforcement-audit
```
