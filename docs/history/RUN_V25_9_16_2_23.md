# v25.9.16.2.23 — CMS Student Sync Check Real API

## Mục tiêu

Làm nút **Kiểm tra đồng bộ CMS** ở chi tiết lớp chạy thật bằng API Open edX/CMS thay vì nhập tay mapping.

## Điểm chính

- AI backend thêm endpoint nghiệp vụ:
  - `POST /api/academic/classes/{class_id}/cms-sync-check`
- Giữ alias cũ để không gãy client cũ:
  - `POST /api/academic/classes/{class_id}/resolve-openedx-users`
- Plugin `openedx_ai_connector` thêm:
  - `POST /api/ai-student-insight/v1/users/resolve`
  - `POST /api/ai-student-insight/v1/courses/search`
- Match sinh viên theo đúng quy tắc đã chốt:
  - `AP username = CMS/Open edX username`
- Không fuzzy match theo tên/email.
- Không có migration mới.

## Env cần có

```env
OPENEDX_STUDENT_INSIGHT_BASE_URL=https://cms-test.poly.edu.vn
OPENEDX_STUDENT_INSIGHT_USERS_RESOLVE_ENDPOINT=/api/ai-student-insight/v1/users/resolve
OPENEDX_STUDENT_INSIGHT_COURSE_SEARCH_ENDPOINT=/api/ai-student-insight/v1/courses/search
OPENEDX_STUDENT_INSIGHT_SHARED_SECRET=<giống OPENEDX_CONNECTOR_HMAC_SECRET>
OPENEDX_STUDENT_INSIGHT_MAX_BATCH_SIZE=100
```

Trong Open edX/Tutor connector plugin:

```env
AI_CONNECTOR_HMAC_SECRET=<giống OPENEDX_CONNECTOR_HMAC_SECRET>
# hoặc tách riêng:
AI_STUDENT_INSIGHT_SHARED_SECRET=<same as OPENEDX_STUDENT_INSIGHT_SHARED_SECRET>
AI_STUDENT_INSIGHT_MAX_BATCH_SIZE=5000
```

## Deploy AI Server

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Deploy plugin Open edX

Copy lại plugin `openedx-connector-plugin/openedx_ai_connector` vào môi trường Open edX đang dùng, rebuild/restart LMS/CMS theo cách hiện tại của anh. Ít nhất cần restart container có plugin chạy endpoint Student Insight.

Kiểm tra plugin:

```bash
curl -k -i https://cms-test.poly.edu.vn/api/ai-student-insight/v1/users/resolve
```

Không ký HMAC sẽ trả 403 là đúng.

## Test nghiệp vụ

1. Vào `/student-management`.
2. Chọn môn → Xem lớp.
3. Vào chi tiết lớp.
4. Bấm **Kiểm tra đồng bộ CMS**.
5. Bảng sinh viên phải cập nhật:
   - Đã đồng bộ CMS
   - Chưa có trên CMS
   - User CMS inactive nếu có

## Log cần xem nếu lỗi

```bash
docker logs ai-backend --tail=300
docker logs ai-frontend --tail=200
```

Nếu plugin báo 403, kiểm tra shared secret ở AI Server và Open edX có giống nhau không.
