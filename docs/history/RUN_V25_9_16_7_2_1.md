# RUN v25.9.16.7.2.1 — Alembic Revision Chain Hotfix

## Lỗi sửa trong bản này

Alembic fail khi upgrade vì migration `0049_v25_9_16_6_3_learning_analytics_core.py` trỏ `down_revision` sai:

```text
KeyError: '0048_v25_9_16_5_84'
```

Trong project, migration 0048 có revision id thật là:

```text
0048_v25_9_16_5_84_teacher_report_cache
```

Bản này sửa `down_revision` của 0049 về đúng revision id trên.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Chạy migration

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend alembic upgrade head
```

## Nếu muốn kiểm tra trong container trước khi upgrade

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend bash -lc \
"grep -R \"revision = '0048\|down_revision = '0048\" -n /app/alembic/versions/0048* /app/alembic/versions/0049*"
```

Kỳ vọng:

```text
0048: revision = '0048_v25_9_16_5_84_teacher_report_cache'
0049: down_revision = '0048_v25_9_16_5_84_teacher_report_cache'
```

## Lưu ý

Không sửa DB thủ công, không sửa bảng `alembic_version`, không dùng `down -v`, không xóa volume.
