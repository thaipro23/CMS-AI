# v25.9.16.5.66 — Course Completion Source Recovery

## Mục tiêu

Sửa lỗi màn chi tiết lớp hiển thị `Course completion: N/A` dù CMS/Open edX learner dashboard có Course completion.

## Nguyên nhân chính đã rà được

Các bản trước siết guard để không lấy nhầm tỷ lệ từ `StudentModule`/`BlockCompletion`, vì tỷ lệ tự suy diễn từng gây sai so với learner dashboard. Tuy nhiên connector Course Home chỉ thử một vài view/kwargs, nên trên Ulmo/Indigo dễ không gọi được đúng Course Home progress API và backend rơi về `N/A`.

## Thay đổi chính

### 1. Connector Open edX đọc Course completion mạnh hơn

File:

```text
openedx-connector-plugin/openedx_ai_connector/student_insight.py
```

Đã bổ sung:

- Gọi nhiều Course Home progress view variants:
  - `CourseProgressView`
  - `ProgressTabView`
  - `CourseHomeProgressView`
  - `CourseHomeProgressTabView`
- Thử nhiều signature khác nhau:
  - `course_id`
  - `course_key_string`
  - `course_key`
  - course key object
- Fallback sang `completion.api` nếu Course Home view không dùng được.
- Extract completion từ nhiều payload shape:
  - percent trực tiếp
  - completion percent
  - completed/total
  - complete/incomplete

### 2. Backend nhận diện thêm nguồn progress official

File:

```text
backend/app/services/academic_service.py
```

Backend giờ chấp nhận nguồn official:

```text
CourseHomeAPI:...
CompletionAPI:...
CourseProgressAPI
LearnerDashboard
official
```

Vẫn không lấy tỷ lệ tự suy diễn từ `StudentModule` / `BlockCompletion` nếu không có nguồn official.

### 3. UI hiển thị nguồn tiến độ

Trong `/student-management/classes/{classId}`, ô Tiến độ học giờ hiển thị thêm:

```text
Nguồn tiến độ: CourseHomeAPI:ProgressTabView
```

hoặc:

```text
Nguồn tiến độ: CompletionAPI:get_course_completion_summary
```

Nếu chỉ có diagnostic counts thì hiển thị `diagnostic_counts_only` và Course completion vẫn là N/A.

### 4. Connector diagnostics rõ hơn

Response connector `class-analytics` có thêm:

```json
{
  "course_home_progress_views": [],
  "completion_api_functions": []
}
```

Dùng để biết LMS đang expose Course Home/completion API nào.

## Deploy

Bản này không có Alembic migration.

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Nếu `openedx-connector-plugin` đang được cài tách trong LMS/Tutor, bắt buộc update/reinstall plugin LMS rồi chạy lại:

```text
Đồng bộ full CMS
```

Nếu không update plugin LMS thì Course completion vẫn có thể N/A vì backend không nhận được source official mới.

## Kiểm tra sau deploy

1. Vào chi tiết lớp.
2. Bấm `Đồng bộ full CMS`.
3. Kiểm tra ô `Course completion`.
4. Nếu vẫn N/A, nhìn dòng `Nguồn tiến độ`:
   - Nếu không có nguồn hoặc `diagnostic_counts_only`: connector LMS chưa lấy được Course Home/completion API.
   - Nếu có `CourseHomeAPI:*` hoặc `CompletionAPI:*` nhưng vẫn N/A: cần kiểm tra payload progress trả về.
