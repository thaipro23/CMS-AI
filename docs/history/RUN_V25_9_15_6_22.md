# v25.9.15.6.22 - Rename Chapter Release State Cleanup Hotfix

## Mục tiêu

Fix lỗi đổi tên Bài/Chapter sau khi publish Library thất bại vì trùng tên/key.

Ví dụ lỗi cũ:

```text
WEB107_FA26 / Bài 2.1 publish lỗi do trùng library
Sau đó đổi tên thành Bài 2.2
Publish lại vẫn dùng state/key cũ
=> LearningPackage matching query does not exist
```

## Đã sửa

- Khi sửa thông tin Chapter, các Release chưa publish thành công sẽ được kiểm tra lại library key theo tên Chapter hiện tại.
- Nếu key cũ khác key mới, backend clear `openedx_library_key`/component id cũ và đưa release về trạng thái `ready` để publish sạch.
- Khi publish, backend luôn so sánh expected library key hiện tại với key đang lưu. Nếu release chưa published và key lệch, tự reset state lỗi cũ.
- Nếu Open edX trả `LearningPackage matching query does not exist`, backend tự ensure/create Library lại, lấy canonical key, rồi retry import problem 1 lần.
- Connector canonicalize Library V2 key theo slug thật Open edX dùng để tránh lệch `FA26`/`fa26`.
- Thêm API hủy Release lỗi/chưa publish:

```http
DELETE /api/question-bank-v2/releases/{release_id}
```

API này không cho xóa Release đã published.

## Cách xử lý case đang lỗi

Sau deploy, với Chapter đã đổi từ `Bài 2.1` sang `Bài 2.2`:

1. Mở lại Chapter.
2. Publish Library lại.
3. Backend sẽ tự reset key cũ và tạo/import theo key mới.

Nếu Release lỗi vẫn bị kẹt, gọi API DELETE release hoặc tạo Release mới sau khi hủy release lỗi.
