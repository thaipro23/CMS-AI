# v25.9.16.7.2.25 — Analytics Learning 3-Step RBAC Flow

## Mục tiêu

`/analytics/learning` đi cùng luồng vận hành như `/student-management`:

1. Màn **Môn**
2. Màn **Lớp**
3. Màn **Xem kết quả**

Không còn một màn gom cả môn/lớp/kết quả gây rối cho giáo viên.

## Thay đổi chính

- `/analytics/learning` tách UI thành 3 màn thật bằng `step=subjects|classes|results`.
- Có `Tất cả cơ sở` như `/student-management`; không tự chọn cơ sở đầu tiên.
- URL giữ state để F5 không mất màn đang xem.
- Màn Môn chỉ liệt kê môn nằm trong quyền của người dùng.
- Màn Lớp chỉ liệt kê lớp trong quyền của người dùng.
- Màn Xem kết quả chỉ gọi API kết quả sau khi người dùng bấm `Xem kết quả`.
- Backend endpoint class overview trả thêm `permission_scope` để UI hiển thị rõ dữ liệu đã lọc theo phân quyền.
- Không thay đổi dữ liệu, không migration.

## Phân quyền được kiểm soát ở backend

- `SYSTEM_ADMIN`: xem toàn bộ.
- `CAMPUS_MANAGER`: chỉ xem campus được phân quyền.
- Giảng viên AP: chỉ xem lớp được AP phân công.
- Chủ môn/Trưởng bộ môn: chỉ xem môn/lớp thuộc subject code được map từ Bank RBAC.
- Người không có scope phù hợp: không thấy dữ liệu lớp/kết quả.

## Deploy

```bash
cd /opt/ai-server

unzip -o ai-server-openedx-v25.9.16.7.2.25-analytics-learning-3-step-rbac-flow.zip -d /tmp/ai-server-v25.9.16.7.2.25

rsync -a --delete /tmp/ai-server-v25.9.16.7.2.25/ai_server_openedx_v25_9_16_7_2_25/ /opt/ai-server/

docker compose -f docker-compose.prod.yml --env-file .env.production build backend frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend
```

Cập nhật `.env.production`:

```env
APP_VERSION=25.9.16.7.2.25
```

## Test production nhanh

1. Vào `/analytics/learning`.
2. Màn đầu tiên phải là **Môn**.
3. Chọn một môn → bấm **Xem lớp**.
4. Sang màn **Lớp**.
5. Chọn lớp → bấm **Xem kết quả**.
6. Sang màn kết quả sinh viên.
7. F5 ở từng màn vẫn giữ đúng màn.
8. Tài khoản giảng viên không được thấy lớp ngoài AP phân công.
9. Tài khoản quản lý cơ sở không được thấy campus ngoài quyền.
