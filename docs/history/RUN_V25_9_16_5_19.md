# v25.9.16.5.19 — Timed Quiz MFE Iframe Reload Hotfix

## Nội dung

Bản này gom lại:

- AI Server nền v25.9.16.5.18.1 Jobs Retry Build Hotfix.
- `openedx-connector-plugin` mới nhất trong gói AI Server hiện tại.
- `openedx-unit-reset-plugin` overlay bản v0.4.14.5 Clean Problem Submission Reset.
- Patch `frontend-app-learning/src/courseware/course/sequence/unit-reset/UnitResetButton.jsx`.

## Lỗi được sửa ở MFE

Log thực tế cho thấy iframe `/xblock/...` render trước khi `/api/unit-reset/v1/quiz-session/start` tạo ACTIVE session. Kết quả là problem HTML render Submit disabled; sau đó DB đã ACTIVE nhưng iframe không tự rebind lại CAPA JS.

Patch mới:

1. Sau `quiz-session/start` thành công, reload iframe `#unit-iframe` một lần với `unit_reset_nonce`.
2. Sau `quiz-session/reset` thành công, gọi lại `quiz-session/start`, rồi reload iframe.
3. Không force enable Submit/Check.
4. Không sửa `problem_policy`, không sửa `showanswer`, không đụng core Open edX.
