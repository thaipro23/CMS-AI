# v25.9.16.5.50 — Course Completion + Quiz Columns Visibility Fix

## Mục tiêu

Sửa tình trạng màn chi tiết lớp vẫn hiển thị `Course completion: N/A` và không mở cột Quiz/Detailed grades dù đã đồng bộ CMS.

## Nguyên nhân chính

1. `student_insight.py` trong connector có sử dụng các helper `_safe_str`, `_display_name`, `_block_type`, `_get_item_best_effort`, `_children_locations` nhưng chưa import/định nghĩa trong file này. Vì các đoạn lấy `PersistentSubsectionGrade`/`StudentModule` đang được bọc `try/except`, lỗi bị nuốt và kết quả là Detailed grades fallback luôn rỗng.
2. Fallback `StudentModule` chỉ import từ `courseware.models`, chưa thử đường dẫn `lms.djangoapps.courseware.models`.
3. Backend chỉ giữ component có điểm; các component kế hoạch từ CMS/Open edX course outline không có điểm nên bị loại, làm frontend không có cột để render.
4. `_component_scores_from_snapshot()` chưa dùng payload đã merge, nên một số snapshot cũ/pha trộn `learning_payload` + `enrollment_payload` vẫn không đọc được component scores.

## Thay đổi chính

### Connector plugin

File:

```text
openedx-connector-plugin/openedx_ai_connector/student_insight.py
```

Đã sửa:

- Import/fallback các helper đọc course outline.
- Thêm `_student_module_model()` để thử cả:
  - `courseware.models.StudentModule`
  - `lms.djangoapps.courseware.models.StudentModule`
- Thêm `_course_outline_quiz_components()` để lấy danh sách Quiz/graded component từ course outline kể cả khi chưa có điểm từng đầu điểm.
- Merge component kế hoạch vào `component_scores` theo từng user để AI Server có thể mở cột Quiz động.

### Backend AI Server

File:

```text
backend/app/services/academic_service.py
```

Đã sửa:

- Component parser giữ lại item `planned=true` hoặc `source=course_outline` dù chưa có percent/earned/possible.
- `_component_scores_from_snapshot()` dùng `_payload_from_snapshot()` để đọc payload đã merge.
- Course completion có fallback từ component progress khi Open edX completion app không có dữ liệu.
- Learning summary chỉ mở cột Quiz từ CMS/Open edX component scores/course outline; không sinh cột từ metadata AP.

### AP sync

Không dùng AP sync để mở cột Quiz hoặc deadline. Production AP API không có `Số Quiz`, `quiz_count` hoặc `Deadline Quiz1...Deadline Quiz35`; nguồn đúng là CMS/Open edX Detailed grades/course outline.

### Frontend

File:

```text
frontend/types/index.ts
```

Đã thêm type field:

- `AcademicLearningComponentScore.planned`
- `AcademicClass.quiz_count`

## Cách deploy

Bản này sửa backend, worker, frontend và connector plugin source.

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Bắt buộc sau deploy

Để thấy cột Quiz và completion tốt hơn, cần làm đủ hai bước:

1. Cập nhật/reinstall `openedx-connector-plugin` trên LMS nếu môi trường đang dùng source plugin tách khỏi AI Server image.
2. Vào màn chi tiết lớp và bấm `Đồng bộ full CMS` để lấy lại class analytics mới.

Nếu muốn lấy `quiz_count` từ AP/import payload thì chạy lại AP sync cho kỳ/môn/lớp tương ứng.
