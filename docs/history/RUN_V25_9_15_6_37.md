# v25.9.15.6.37 — Async Material / Generate / Publish / Quiz Jobs

## Mục tiêu

Bản này thực hiện bước kế hoạch `v25.9.15.6.37 — Async Material Upload / Extract / Generate / Publish`:

- Upload tài liệu không parse trong request path.
- Generate câu hỏi không block Uvicorn worker.
- Publish Bank Release sang Open edX chạy qua job có progress.
- Tạo Quiz Open edX chạy qua job có progress.
- Thêm guard chống file lớn/zip bomb khi extract PDF/PPTX/DOCX/XLSX/CSV.

## Migration mới

```bash
backend/alembic/versions/0019_v25_9_15_6_37_async_bank_operations.py
```

Tạo bảng:

```text
ai_bank_operation_jobs
```

Các trạng thái chính:

```text
queued | running | completed | failed | canceled
```

## Endpoint mới

### Theo dõi job

```http
GET  /api/question-bank-v2/operation-jobs
GET  /api/question-bank-v2/operation-jobs/{job_id}
POST /api/question-bank-v2/operation-jobs/{job_id}/cancel
```

### Upload/extract tài liệu

```http
POST /api/question-bank-v2/bank-versions/{bank_version_id}/materials/upload-job
```

### Generate câu hỏi

```http
POST /api/question-bank-v2/bank-versions/{bank_version_id}/generate-job
```

### Publish Open edX Library

```http
POST /api/question-bank-v2/releases/{release_id}/publish-openedx-job
```

### Create Quiz Open edX

```http
POST /api/question-bank-v2/releases/{release_id}/quiz/create-job
```

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Test nhanh

### Upload job

```bash
curl -X POST "http://api-ai.cms-test.poly.edu.vn/api/question-bank-v2/bank-versions/<BANK_VERSION_ID>/materials/upload-job" \
  -H "Authorization: Bearer <AI_TOKEN>" \
  -F "file=@/path/to/file.pdf" \
  -F "title=file.pdf" \
  -F "change_type=initial" | python3 -m json.tool
```

### Poll job

```bash
curl -s "http://api-ai.cms-test.poly.edu.vn/api/question-bank-v2/operation-jobs/<JOB_ID>" \
  -H "Authorization: Bearer <AI_TOKEN>" | python3 -m json.tool
```

### Generate job

```bash
curl -X POST "http://api-ai.cms-test.poly.edu.vn/api/question-bank-v2/bank-versions/<BANK_VERSION_ID>/generate-job" \
  -H "Authorization: Bearer <AI_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"question_count":10,"target_question_count":100,"difficulty_easy":50,"difficulty_medium":30,"difficulty_hard":20}' | python3 -m json.tool
```

## Ghi chú tương thích

Các endpoint sync cũ vẫn còn để tránh breaking change cho script cũ. Frontend chính đã chuyển sang endpoint job mới và poll trạng thái job.
