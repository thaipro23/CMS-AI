# v25.9.16.5.62 — Vietnam Timezone Normalization Hardening

## Mục tiêu

Bản này fix yêu cầu: nếu dữ liệu thời gian đến từ nơi khác không phải `Asia/Ho_Chi_Minh` thì phải quy đổi về giờ Việt Nam trước khi hiển thị, tính deadline, tính submitted_at, lọc ngày hoặc lưu cấu hình tuần học.

## Thay đổi chính

- Backend thêm `app.core.timezone` làm chuẩn chung.
- `/semesters` không dùng `toISOString()` nữa, tránh lệch ngày do timezone browser.
- Cấu hình tuần học gửi `yyyy-mm-ddT00:00:00+07:00` về backend.
- AP sync, AcademicService, TrainingPolicyService, Bank search đều parse timezone-aware datetime về Vietnam time.
- Open edX connector trả `submitted_at`, `modified`, `last_activity_at` dạng ISO đã quy đổi `+07:00` khi có thể.
- Frontend dùng `formatVNDate` / `formatVNDateTime` thay cho `new Date(...).toLocaleString()` trực tiếp ở các màn Bank/Users/Semesters/Class detail.

## Deploy

Không có Alembic migration.

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Nếu `openedx-connector-plugin` đang cài tách trong LMS/Tutor, cần update/reinstall plugin LMS rồi chạy lại `Đồng bộ full CMS` để timestamps/submitted_at từ Open edX trả về theo chuẩn mới.

## Kiểm tra sau deploy

1. Vào `/semesters`, mở popup sửa kỳ, kiểm tra tất cả ngày là `dd/mm/yyyy`.
2. Lưu `Cấu hình tuần học`, kiểm tra không lệch ngày sau F5.
3. Vào chi tiết lớp, bấm `Làm mới` hoặc `Đồng bộ full CMS`.
4. Kiểm tra deadline Quiz và ngày làm/nộp trong popup Quiz theo giờ Việt Nam.
5. Kiểm tra filter ngày ở Bank Dashboard/Search không lệch ngày.
