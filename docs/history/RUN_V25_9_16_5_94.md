# RUN — v25.9.16.5.94 Quiz Deadline Eligibility Audit + Class Detail Hot Path

## Nội dung chính

Bản này tập trung vào điều kiện quiz/deadline và hiệu năng màn chi tiết lớp.

### 1. Giữ đúng rule xét điều kiện quiz

- Quiz phải đạt 100%.
- Quiz phải làm/nộp trong khoảng hợp lệ và không sau deadline.
- Deadline ưu tiên cấu hình tuần học tại `/semesters`.
- Không dùng ngưỡng 50/80 để xét quiz.
- Final test vẫn chưa áp dụng rule chính thức.

### 2. Sửa case điểm quiz dưới 100 nhưng thiếu thời gian nộp

Trước đây nếu Detailed Grades trả `percent < 100` nhưng thiếu `submitted_at`, policy có thể đẩy vào `Chưa đủ dữ liệu`.

Từ v94:

```text
percent < 100 => Không được thi
```

Không cần chờ `submitted_at`, vì riêng việc chưa đạt 100% đã đủ để chặn điều kiện quiz.

### 3. Tối ưu hot path chi tiết lớp

Trong `/student-management/classes/{classId}`, backend không còn tính lại lịch deadline quiz cho từng sinh viên.

Từ v94:

```text
load page sinh viên
→ gom component scores của trang hiện tại
→ tính schedule deadline 1 lần
→ áp dụng cho từng sinh viên trên trang
```

Giảm lặp:

```text
/semesters week schedule
block lookup
quiz label parsing
component deadline mapping
```

### 4. Không tính itembank/problem/video vào Course completion

Giữ nguyên rule đã đúng từ v90-v93:

```text
Course completion fallback = StudentModule sequential có position / tổng reachable sequential
```

`itembank` chỉ là random selected state, không phải học thật.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Nếu cập nhật connector Open edX từ zip này:

```bash
tutor local restart lms cms lms-worker cms-worker
```

Kiểm tra connector version:

```bash
tutor local run lms python - <<'PY'
import importlib
m = importlib.import_module('openedx_ai_connector.student_insight')
print('CONNECTOR_VERSION=', getattr(m, 'CONNECTOR_VERSION', None))
PY
```

Kỳ vọng:

```text
CONNECTOR_VERSION= 25.9.16.5.94
```

## Kiểm tra sau deploy

1. Vào chi tiết lớp.
2. Bấm `Cập nhật điểm`.
3. Kiểm tra các nhóm:
   - Sinh viên học thật: completion khớp CMS, ví dụ 5/8 ≈ 63%.
   - Sinh viên chỉ có itembank rows: 0%.
   - Quiz dưới 100%: `Không được thi`, không phải `Chưa đủ dữ liệu`.
   - Quiz đạt 100% nhưng thiếu thời gian nộp: `Chưa đủ dữ liệu` để tránh xác nhận sai deadline.
