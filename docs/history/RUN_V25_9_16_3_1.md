# v25.9.16.3.1 — Auto Enrollment Mapped Students

## Mục tiêu

Tự enrollment sinh viên của lớp vào Course CMS khi:

1. Lớp kế thừa được Course CMS từ mapping cấp Môn/Kỳ/Hệ.
2. Sinh viên AP đã map được với user CMS/Open edX theo username.
3. User CMS/Open edX đang active.

Hệ thống không tạo user mới và không fuzzy match theo tên/email.

## Endpoint mới

AI Server:

```text
POST /api/academic/classes/{class_id}/cms-enrollment-sync
```

Plugin `openedx_ai_connector`:

```text
POST /api/ai-student-insight/v1/course-enrollment/enroll
```

## Cấu hình

```env
OPENEDX_STUDENT_INSIGHT_ENROLLMENT_ENROLL_ENDPOINT=/api/ai-student-insight/v1/course-enrollment/enroll
OPENEDX_STUDENT_INSIGHT_DEFAULT_ENROLLMENT_MODE=audit
ACADEMIC_AUTO_ENROLL_AFTER_CMS_SYNC=true
```

Bên Open edX plugin vẫn dùng chung HMAC secret:

```env
AI_STUDENT_INSIGHT_SHARED_SECRET=<same-secret>
```

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Không có migration mới.

Cần cập nhật lại plugin `openedx_ai_connector` vào LMS/CMS image rồi restart LMS/CMS.

## Test nghiệp vụ

```text
/student-management
→ chọn môn đã map Course CMS
→ Xem lớp
→ Chi tiết lớp
→ Kiểm tra đồng bộ CMS
```

Kỳ vọng:

- Sinh viên `Đã đồng bộ CMS` tự được enroll vào Course CMS.
- Cột `Học tập CMS` chuyển sang `Đã enroll` sau khi refresh.
- Sinh viên chưa có user CMS hoặc user inactive bị bỏ qua, không enroll nhầm.

Có thể chạy lại thủ công bằng nút `Enrollment vào Course CMS` trong chi tiết lớp.
