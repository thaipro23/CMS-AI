# RUN v25.9.16.5.31 — MFE Timer Visibility Guard

## Mục tiêu

Triển khai hotfix UI trên nhánh `mfe-unit-reset`: panel timer/làm lại bài chỉ hiển thị khi Unit/Quiz đã được LMS plugin xác nhận có timer (`timerEnabled=true`). Video/html/unit thường không được hiện nút “Làm lại bài”. Không đổi logic timer/reset.

## File thay đổi

```text
frontend-app-learning-patch/src/courseware/course/sequence/unit-reset/UnitResetButton.jsx
frontend-app-learning-patch/src/courseware/course/sequence/unit-reset/UnitResetButton.scss
```

## Điểm sửa chính

```text
Ẩn toàn bộ panel UnitResetButton nếu timerUnavailable hoặc timer?.timerEnabled chưa true.
Sửa normalize timer: rawRemaining phải khác cả null và undefined mới được coi là timer hợp lệ.
Không hiển thị “Quiz tự luyện”/“Làm lại bài” trong lúc chưa xác nhận cấu hình timer.
Giữ nguyên panel Indigo cho Unit có timer.
```

## Không thay đổi logic

Không đổi endpoint, không đổi backend plugin, không đổi các hàm timer/reset chính:

```text
normalizeTimerPayload
loadTimerStatus
handleTimeout
handleReset
reloadUnitIframeOnce
broadcastAutoSubmitToProblemFrames
```
