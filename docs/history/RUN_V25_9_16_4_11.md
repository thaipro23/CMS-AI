# v25.9.16.4.11 — Student Management Subjects Hotfix

Fix lỗi `/api/academic/teacher/subjects` trả 500 sau khi sync AP sạch.

## Lỗi

```text
NameError: name 'course_by_class' is not defined
File: backend/app/services/academic_service.py
Function: _learning_summary_by_subject_ids
```

## Sửa

`_learning_summary_by_subject_ids()` dùng đúng biến `course_by_subject` thay vì biến không tồn tại `course_by_class`.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker
```

Không cần migration.

## Test

```bash
curl -i 'http://api-ai.cms-test.poly.edu.vn/api/academic/teacher/subjects?branch=poly&page=1&page_size=50'
```

Kỳ vọng HTTP 200 và danh sách môn hiển thị ở `/student-management`.
