# v25.9.16.5.36 — AI Server Frontend v30 Only Rollback

## Mục tiêu

Chỉ rollback giao diện AI Server frontend về nền v25.9.16.5.30. Không rollback backend, worker, plugin Open edX, tutor plugin, scripts, infra.

## Quyết định kỹ thuật

- Lấy nguyên thư mục `frontend/` từ `v25.9.16.5.30`.
- Giữ các phần còn lại từ baseline `v25.9.16.5.34`.
- Không áp lại dark/cockpit rewrite của `v32/v33/v34` vào AI Server frontend.
- Không đổi logic timer/reset/auto-submit/Open edX plugin trong bản rollback UI này.

## Deploy chỉ frontend AI Server

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

## Nếu muốn deploy full theo package

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```
