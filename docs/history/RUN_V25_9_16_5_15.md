# v25.9.16.5.15 — Ulmo UserProfile Enrollment Hotfix

## Mục tiêu
Sửa lỗi Enrollment Course CMS trên Open edX Ulmo.3 khi user CMS đã tồn tại/đã được tạo nhưng thiếu `UserProfile`, dẫn tới lỗi LMS `User has no profile`.

## Nguyên nhân
Log LMS cho thấy request enrollment vào connector chạy được và trả HTTP 200, nhưng khi enroll thủ công qua Instructor API với user `datltph66643`, Open edX fail trong `EmailEnrollmentState` với lỗi `User has no profile`. Đây không phải lỗi chính ở `CourseEnrollment` import; lỗi chính là user được tạo thiếu bản ghi `UserProfile`.

## Thay đổi
- Thêm helper import release-safe `UserProfile`:
  - `common.djangoapps.student.models.UserProfile`
  - fallback `student.models.UserProfile`
- `users/resolve` giờ tạo/kiểm tra `UserProfile` cho cả user mới và user đã tồn tại.
- `course-enrollment/enroll` bắt buộc kiểm tra/tạo `UserProfile` trước khi enroll.
- Nếu không tạo được `UserProfile`, connector trả `user_profile_failed` rõ ràng thay vì để Open edX fail ngầm.
- Response trả thêm diagnostics:
  - `user_profile_ok`
  - `user_profile_created`
  - `user_profile_model_source`
  - `user_profile_message`

## File chính
- `openedx-connector-plugin/openedx_ai_connector/student_insight.py`

## Deploy
Bản này bắt buộc cập nhật `openedx_connector_plugin` vào LMS/CMS. Nếu plugin bake trong Open edX image, phải rebuild image rồi restart LMS/CMS.
