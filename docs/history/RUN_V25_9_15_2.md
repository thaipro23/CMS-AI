# Run v25.9.15.2 - Bank Material Upload + Generate

## Build an toàn

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production build --no-cache backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --no-deps backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production exec backend alembic upgrade head
```

## Clear DB AI Server khi test

Chỉ xóa DB AI Server, không đụng Open edX/Tutor:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec postgres \
psql -U ai_user -d ai_openedx -c "
DROP SCHEMA public CASCADE;
CREATE SCHEMA public;
GRANT ALL ON SCHEMA public TO ai_user;
GRANT ALL ON SCHEMA public TO public;
"

docker compose -f docker-compose.prod.yml --env-file .env.production exec backend alembic upgrade head
```

## Test nhanh

1. Mở `/bank`.
2. Tạo Bộ môn, Môn, Chapter.
3. Tạo Bank Version `v1.0`.
4. Upload tài liệu vào Bank Version.
5. Generate 3-5 câu trước.
6. Review/approve câu.
7. Tạo Bank Release và Publish Library.
