## Deploy

Bản này có Alembic migration.

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Nếu connector LMS đang cài tách, vẫn cần giữ bản connector từ v52+ để lấy đúng Course completion/Detailed grades.

## Kiểm tra sau deploy

1. Vào `/student-management/classes/{classId}`.
2. Chạy `Đồng bộ full CMS` nếu dữ liệu chưa mới.
3. Kiểm tra cột `Điều kiện thi`.
4. Click `Cấu hình deadline` và nhập deadline nếu block dài hơn 7 tuần.
5. Click `Nhập điểm Assignment`, nhập điểm bảo vệ, lưu lại.
6. Vào `/training-management`, lọc `Có SV không được thi`, xuất Excel.
