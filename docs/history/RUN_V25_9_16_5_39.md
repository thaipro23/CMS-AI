# v25.9.16.5.39 — AI Frontend v27 Base + Server-backed Operation Status

## Mục tiêu

Giữ nguyên giao diện AI Server nền v27 ổn định, chỉ sửa phần trạng thái tác vụ dài ở màn chapter:

- Không dùng `localStorage` để phục hồi trạng thái upload/generate.
- Khi F5 hoặc mở bằng máy/trình duyệt khác cùng tài khoản, frontend đọc lại job đang `queued`/`running` từ backend `BankOperationJob`.
- Loading vẫn cục bộ theo nút/khu vực để người dùng tiếp tục làm phần không xung đột.
- Không đổi MFE, timer/reset, LMS plugin.

## Thay đổi chính

- `frontend/lib/api.ts`
  - `getBankOperationJobs()` hỗ trợ thêm `targetType`, `targetId`.
- `frontend/app/bank/_components/pages/ChapterWorkspacePage.tsx`
  - Bỏ localStorage cho active operation.
  - Khi có `selectedBankVersion`, tự truy vấn:
    - `operation_type=material_extract` hoặc `bank_generate`
    - `target_type=bank_version`
    - `target_id=<bank_version_id>`
    - `status=queued|running`
  - Dựng lại status rail từ job backend.
  - Nút/khu vực upload/generate vẫn loading cục bộ.

## Deploy chỉ frontend AI Server

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

Sau deploy hard refresh trình duyệt:

```text
Ctrl + F5
```

## Kiểm thử

1. Mở `/bank/chapters/{id}`.
2. Upload tài liệu, thấy chỉ nút/khu vực tài liệu loading.
3. F5 trong lúc job đang chạy, status rail phải hiện lại từ backend.
4. Mở cùng tài khoản ở trình duyệt/máy khác, status rail cũng phải hiện nếu job vẫn queued/running.
5. Tạo câu hỏi, F5/mở máy khác, status rail phải hiện lại.
