# v25.9.15.6.38.4 — Dashboard Drilldown Filter Polish

## Mục tiêu

Hoàn thiện `/bank` thành dashboard hiện đại, có scope label, KPI cards, biểu đồ, alert panel, activity feed, filter thời gian và drill-down thật tới danh sách xử lý. Không làm Export Excel/PDF.

## Điểm chính

- Thêm endpoint `GET /api/question-bank-v2/dashboard/drilldown` để phục vụ drill-down scope-safe.
- Thêm route FE `/bank/search` để hiển thị danh sách câu hỏi sau khi click KPI/chart/alert/activity.
- `/bank/chapters/{chapter_id}` đọc query `status` / `difficulty` để mở đúng filter từ dashboard.
- Làm lại hero dashboard theo phong cách hiện đại/command center, hiển thị scope, cache và thời điểm cập nhật.
- Tất cả dữ liệu drill-down vẫn được backend lọc scope RBAC, không lọc ở client.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend
docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic heads
docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```
