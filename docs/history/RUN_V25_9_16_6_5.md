# RUN v25.9.16.6.5 — Online Learning Drawer + Existing Quiz Deadline Priority

## Mục tiêu

Bản này tiếp tục kế hoạch Learning Behavior Analytics sau Phase 0–4:

- Thêm chi tiết học online theo **Bài/Session → video → Quiz cuối Bài → Deadline**.
- Ưu tiên dùng deadline Quiz đã cấu hình trong `academic_quiz_deadline_overrides`.
- Chỉ suy luận deadline 6 tuần khi thật sự chưa có deadline Quiz/cấu hình tuần học.
- Không tạo bảng mới.
- Không kết luận vi phạm; chỉ hiển thị tín hiệu nghi vấn mềm.

## Điểm sửa chính

### 1. Backend analytics

- `GET /api/analytics/courses/{course_id}/session-structure?class_id=...` overlay deadline từ Quiz deadline đã cấu hình.
- `POST /api/analytics/classes/{class_id}/learning-behavior/recalculate?course_id=...` giờ tính thêm session progress.
- `GET /api/analytics/classes/{class_id}/students/{username}/learning-behavior?course_id=...` trả thêm:
  - behavior tổng quan
  - sessions theo Bài/Session
  - video progress
  - timeline 6 tuần
  - disclaimer
- Thêm audit khi mở chi tiết học online của sinh viên.

### 2. Deadline

Thứ tự ưu tiên:

```text
1. Deadline Quiz đã cấu hình trong academic_quiz_deadline_overrides
2. Cấu hình tuần học từ /semesters
3. Ngày block/lớp
4. Infer 6 tuần nếu thật sự thiếu
```

Nếu đã có deadline Quiz, UI không được báo “Cần chỉnh deadline tay”.

### 3. Frontend

Trong modal **Chi tiết học online** thêm tab/khu vực:

```text
Theo Bài / Deadline
```

Hiển thị mỗi tuần:

```text
Tuần 1: Bài 1, Bài 2
Tuần 2: Bài 3, Bài 4
...
```

Mỗi Bài hiển thị:

```text
Video đã hoàn thành / tổng video
Hoàn thành video trung bình
Thời gian xem ước tính
Quiz cuối Bài
Deadline
Nguồn deadline
Nhận định mềm theo Bài
```

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Migration

Không có migration mới ở v6.5.

Nếu server chưa chạy migration v6.3 thì chạy:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend alembic upgrade head
```

## Sau deploy

Chạy ingest log:

```bash
curl -X POST "https://api-ai.cms-test.poly.edu.vn/api/analytics/ingest/run" \
  -H "Content-Type: application/json"
```

Recalculate học online cho lớp:

```bash
curl -X POST "https://api-ai.cms-test.poly.edu.vn/api/analytics/classes/<CLASS_ID>/learning-behavior/recalculate?course_id=<COURSE_ID>"
```

Kiểm tra detail sinh viên:

```bash
curl "https://api-ai.cms-test.poly.edu.vn/api/analytics/classes/<CLASS_ID>/students/<USERNAME>/learning-behavior?course_id=<COURSE_ID>"
```
