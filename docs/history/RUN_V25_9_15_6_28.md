# v25.9.15.6.28 - Bank Quiz Clean Workbench UX

## Thay đổi chính

- `/bank/quiz` tự tìm version và Section sau khi người dùng nhập Course ID, bỏ nút `Tự tìm version và Section`.
- Hai thao tác chính `Lưu cấu hình` và `Tạo Quiz` được đưa lên ngay dưới Course ID để không phải kéo xuống đáy panel.
- Lịch sử Quiz chỉ hiển thị theo Course ID đang nhập, không load toàn bộ lịch sử gây rối.
- `Lưu mapping` đổi thành `Lưu cấu hình`.
- Bỏ các đoạn mô tả dài trong khối `Kết quả map` để màn hình gọn hơn.
- Nền chính chuyển về trắng, giữ cam nhạt cho border/active/action theo phong cách FPT.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

Sau đó vào `/bank/quiz` và nhấn Ctrl+F5.
