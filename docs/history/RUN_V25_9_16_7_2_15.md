# v25.9.16.7.2.15 — Management KPI Plain Labels + Dynamic Teacher Counts

## Mục tiêu

Bản này làm gọn `/student-management` và `/teacher-management` để người dùng nhìn KPI là hiểu ngay, không cần đọc giải thích dài.

## Thay đổi chính

### `/teacher-management`

- Bỏ nút `Tải lại báo cáo`.
- Bỏ nút `Tính lại báo cáo`.
- Bỏ notice `Báo cáo: Đang đọc cache...`.
- Bỏ notice `Cách đọc số liệu...`.
- Đổi tiêu đề thành `Quản lý giảng viên`.
- Đổi KPI:
  - `GV theo bộ lọc` -> `Tổng giảng viên`
  - `Lượt lớp phân công` -> `Tổng số lớp`
  - `Lượt SV theo phân công` -> `Tổng số sinh viên`
- API `/api/academic/training/teachers` gọi `training_teacher_report(..., use_cache=False)` để tránh UI đọc cache cũ sau khi đã bỏ thao tác tính lại cache.
- Giữ xuất Excel nền và xuất trực tiếp.

### `/student-management`

- Đổi KPI:
  - `Môn theo bộ lọc` -> `Tổng số môn`
  - `Lớp theo bộ lọc` -> `Tổng số lớp`
  - `Sinh viên theo bộ lọc` -> `Tổng số sinh viên theo bộ lọc`
  - `Cảnh báo theo bộ lọc` -> `Cần kiểm tra`
- Bỏ notice `Cách đọc số liệu...`.
- Giữ `Course CMS đã map`.

## Không thay đổi

- Không migration.
- Không reset DB.
- Không xóa volume.
- Không đổi secret.

## Deploy

```bash
cd /opt/ai-server

unzip -o ai-server-openedx-v25.9.16.7.2.15-management-kpi-plain-labels.zip -d /tmp/ai-server-v25.9.16.7.2.15

rsync -a --delete /tmp/ai-server-v25.9.16.7.2.15/ai_server_openedx_v25_9_16_7_2_15/ /opt/ai-server/

docker compose -f docker-compose.prod.yml --env-file .env.production build backend frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend
```

## Env

```env
APP_VERSION=25.9.16.7.2.15
```

## Verify nhanh

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production exec backend python -m py_compile app/api/routes/academic.py
```

- `/student-management`: KPI phải hiện `Tổng số môn`, `Tổng số lớp`, `Tổng số sinh viên theo bộ lọc`, `Course CMS đã map`, `Cần kiểm tra`.
- `/teacher-management`: không còn `Tải lại báo cáo`, `Tính lại báo cáo`, `Báo cáo:`, `Cách đọc số liệu`; KPI phải hiện `Tổng giảng viên`, `Tổng số lớp`, `Tổng số sinh viên`.
