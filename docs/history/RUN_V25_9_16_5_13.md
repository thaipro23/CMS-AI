# v25.9.16.5.13 — Enrollment Course CMS Verify Hardfail Hotfix

## Mục tiêu

Sửa lỗi nút **Enrollment Course CMS** báo thành công nhưng thực tế Open edX chưa có enrollment.

## Nguyên nhân

Ở các bản trước, connector có thể trả `status=created` sau khi gọi `CourseEnrollment.enroll()`, nhưng chưa xác minh lại bản ghi `CourseEnrollment` thật trong LMS DB. Vì vậy AI Server có thể ghi snapshot `enrolled` và UI báo thành công dù enrollment chưa thực sự tồn tại.

## Đã sửa

### Open edX connector plugin

- Sau khi gọi `CourseEnrollment.enroll()`, plugin bắt buộc query lại `CourseEnrollment.objects.filter(user=user, course_id=course_key).first()`.
- Chỉ trả thành công nếu bản ghi enrollment thật sự tồn tại và `is_active=True`.
- Nếu không thấy enrollment sau ghi, trả `status=enrollment_not_created`, `enrollment_status=failed`, `verified_after_write=false`.
- Gán Course Staff cho giảng viên cũng được verify lại bằng `CourseStaffRole.has_user(user)`.

### AI Server backend

- `sync_class_course_enrollment()` không còn coi “đã xử lý payload” là thành công.
- `updated` giờ là số sinh viên được Open edX xác nhận `enrolled`.
- Thêm `processed` và `verified` trong job result để phân biệt đã gọi connector với đã xác nhận thành công.
- Nếu class có sinh viên nhưng chưa có user CMS mapping chính xác, API báo lỗi rõ: cần chạy **Tạo/kiểm tra user CMS** trước.
- Nếu gọi connector xong mà không có sinh viên nào được xác nhận enrolled, job fail thay vì báo success giả.

### Frontend

- Message sau Enrollment Course CMS hiển thị số sinh viên `verified/enrolled` thay vì chỉ hiển thị số payload đã xử lý.

## Deploy AI Server

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Cập nhật Open edX plugin

Bản này sửa `openedx-connector-plugin/openedx_ai_connector/student_insight.py`, nên phải cập nhật plugin vào LMS/CMS. Nếu plugin bake vào Open edX image thì cần rebuild image rồi restart, không chỉ restart container.

## Test

1. Vào `/student-management/classes/{classId}`.
2. Đảm bảo lớp đã map Course CMS.
3. Bấm **Tạo/kiểm tra user CMS**.
4. Bấm **Enrollment Course CMS**.
5. Kỳ vọng message hiển thị `x/y sinh viên được Open edX xác nhận enrolled`.
6. Vào LMS/Admin DB kiểm tra `CourseEnrollment` thật sự có bản ghi active.
