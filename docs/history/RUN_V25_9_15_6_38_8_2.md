# v25.9.15.6.38.8.2 — Drilldown Table + Scope Count Fix

## Nội dung

- `/bank/search?entity=questions` đổi sang bảng dễ nhìn.
- Click KPI `Tổng câu hỏi`, `Đã duyệt`, `Bị từ chối`, `Đang chờ duyệt` giờ lấy dữ liệu trực tiếp từ `ai_questions` theo RBAC scope, không phụ thuộc search index.
- Trả thêm người duyệt/từ chối, thời điểm xử lý, lý do từ chối/ghi chú, môn và chapter.
- `total` là tổng thật trong phạm vi; `returned` là số dòng đang hiển thị.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic heads

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Cập nhật `.env.production`:

```env
APP_VERSION=25.9.15.6.38.8.2-drilldown-table-scope-count-fix
```
