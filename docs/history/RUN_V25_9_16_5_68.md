# v25.9.16.5.68 — AP CMS Campus + Subject Catalog Sync

## Mục tiêu

Bản này cập nhật luồng Đồng bộ AP theo API mới:

- Lấy danh sách cơ sở Poly bằng `GET /api/cms/get-campus?product=POLY`.
- Lấy danh sách cơ sở PTCĐ bằng `GET /api/cms/get-campus?product=POLY9`.
- Lấy danh sách môn theo cơ sở bằng `GET /api/cms/get-subject-cms?campus_code=<code>`.
- Không dùng legacy `GET /get-course?branch=poly&term_name=...` để lấy danh sách môn nữa.
- Base URL API mới được đặt trong env để sau này thay được không cần sửa code.

## Env mới

Thêm vào `.env.production`:

```env
ACADEMIC_AP_CMS_API_BASE_URL=http://apitest.poly.edu.vn
ACADEMIC_AP_CMS_GET_CAMPUS_ENDPOINT=/api/cms/get-campus
ACADEMIC_AP_CMS_GET_SUBJECT_ENDPOINT=/api/cms/get-subject-cms
ACADEMIC_AP_CMS_PRODUCT_POLY=POLY
ACADEMIC_AP_CMS_PRODUCT_PTCD=POLY9
```

Giữ nguyên env legacy nếu `/get-data-cms` vẫn nằm ở host cũ:

```env
ACADEMIC_AP_API_BASE_URL=https://api_v2.poly.edu.vn
ACADEMIC_AP_API_KEY=...
```

`ACADEMIC_AP_API_BASE_URL` hiện vẫn dùng cho `/get-data-cms` vì chưa có endpoint thay thế cho payload lớp/sinh viên/giảng viên.

## API backend mới

Đồng bộ danh sách cơ sở:

```http
POST /api/academic/campuses/sync-from-ap?branch=poly
POST /api/academic/campuses/sync-from-ap?branch=ptcd
```

Backend sẽ gọi:

```text
Poly: GET {ACADEMIC_AP_CMS_API_BASE_URL}/api/cms/get-campus?product=POLY
PTCĐ: GET {ACADEMIC_AP_CMS_API_BASE_URL}/api/cms/get-campus?product=POLY9
```

## UI

Trang `/ap-sync` có thêm nút:

```text
Đồng bộ danh sách cơ sở
```

Nút này đồng bộ cơ sở cho cả Poly và PTCĐ, sau đó reload lại dropdown cơ sở. Sau khi có cơ sở, chạy `Đồng bộ tất cả` hoặc `Đồng bộ theo hệ` như cũ.

## Luồng lấy môn mới

Khi chạy Đồng bộ AP, với từng cơ sở, backend gọi:

```text
GET {ACADEMIC_AP_CMS_API_BASE_URL}/api/cms/get-subject-cms?campus_code=<campus>
```

Response dạng:

```json
{
  "status": 1,
  "code": 200,
  "message": 200,
  "data": [
    {
      "subject_code": "ACC106",
      "skill_code": "ACC106",
      "subject_name": "Quản trị tài chính nhà hàng khách sạn",
      "subject_name_en": "Hotel & Restaurant Financial Administration"
    }
  ]
}
```

Backend lấy `subject_code`, `skill_code`, `subject_name`, `subject_name_en` để tạo danh sách môn cần gọi `/get-data-cms`.

## Deploy

Không có database migration.

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Kiểm tra sau deploy

Mở `/ap-sync`, bấm:

```text
Đồng bộ danh sách cơ sở
```

Kết quả mong muốn:

```text
Đã đồng bộ danh sách cơ sở từ AP. Poly: n cơ sở · PTCĐ: n cơ sở
```

Sau đó bấm:

```text
Đồng bộ tất cả
```

Trong tiến trình job, `plan` phải ghi:

```json
{
  "ap_campus_endpoint": "/api/cms/get-campus",
  "ap_subject_endpoint": "/api/cms/get-subject-cms",
  "ap_division_endpoint": "/get-data-cms"
}
```
