# RUN v25.9.16.7.1 — Production Production Acceptance Pack

## Mục tiêu

Bản này thêm lớp kiểm tra cuối để production production 1–3 lớp thật trước khi mở rộng Học online/Aspects-lite cho nhiều lớp.

Kết quả phân tích vẫn là **tín hiệu mềm từ log hệ thống**, không phải kết luận vi phạm.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Nếu đây là lần đầu triển khai analytics core:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend alembic upgrade head
```

## Biến môi trường cần kiểm tra

```bash
ANALYTICS_INGEST_ENABLED=true
ANALYTICS_INGEST_SCHEDULER_ENABLED=true
OPENEDX_TRACKING_LOG_PATH=/openedx-data/lms/logs/tracking.log
OPENEDX_TRACKING_LOG_HOST_DIR=/opt/openedx/data/lms/logs
```

Nếu Tutor root khác:

```bash
tutor config printroot
```

Sau đó set:

```bash
OPENEDX_TRACKING_LOG_HOST_DIR=$(tutor config printroot)/data/lms/logs
```

## API mới

```text
GET /api/analytics/ops/production-acceptance
```

Tham số tùy chọn:

```text
class_id
course_id
campus
branch
sample_limit=5
```

Endpoint này chỉ đọc metadata/snapshot, không scan raw tracking.log khi request.

## Chạy smoke test chuẩn

```bash
cd /opt/ai-server
chmod +x scripts/production-build-verify.sh scripts/smoke-test-prod.sh scripts/analytics-production-acceptance.sh

./scripts/production-build-verify.sh
./scripts/smoke-test-prod.sh
```

## Chạy production acceptance cho 1 lớp thật

```bash
API_BASE="https://api-ai.cms-test.poly.edu.vn/api" \
AUTH_HEADER="Authorization: Bearer <TOKEN_ADMIN_OR_MANAGER>" \
CLASS_ID="<class_id>" \
COURSE_ID="course-v1:FPT+COM1071+SU26" \
./scripts/analytics-production-acceptance.sh
```

Kết quả đạt tối thiểu:

```text
Production status: PASS hoặc PASS_WITH_WARNINGS
Ready for production: True
Blockers: 0
```

Nếu `FAIL`, xử lý theo `next_actions` trong JSON.

## Quy trình production 1–3 lớp

1. Kiểm tra tracking log đã mount.
2. Chạy ingest tracking log.
3. Rebuild session structure nếu thiếu mapping Bài/Session.
4. Backfill học online cho lớp production.
5. Mở `/analytics/learning` kiểm tra `Production acceptance`.
6. Đối chiếu 5 sinh viên mẫu với LMS/tracking log.
7. Chỉ mở rộng khi không còn blocker.

## Không đổi

- Không tạo migration mới.
- Không đổi Course completion.
- Không đổi connector contract.
- Không đổi classifier nhãn mềm.
- Không query raw tracking.log khi mở dashboard/health/production acceptance.

# v25.9.16.7.1 — Production Rollout Control + Monitoring Pack

Bản này bổ sung lớp kiểm soát rollout và monitoring trước khi mở rộng từ production sang production.

## Điểm mới

- API rollout control:
  - `GET /api/analytics/ops/rollout-control`
- API monitoring:
  - `GET /api/analytics/ops/monitoring`
- Health `/api/health/analytics` có thêm:
  - `rollout_status`
  - `rollout_mode`
  - `monitoring_status`
  - `stuck_analytics_job_count`
  - `stale_snapshot_count`
- Chặn backfill/export nếu rollout bị tắt theo env.
- Chặn job tính lại học online cho lớp ngoài phạm vi rollout.
- Không tạo bảng mới. Rollout dùng env allowlist + bảng AcademicClass/Job/Snapshot hiện có.

## Env rollout production

```bash
ANALYTICS_ROLLOUT_ENABLED=true
ANALYTICS_ROLLOUT_MODE=production
ANALYTICS_ROLLOUT_CAMPUSES=
ANALYTICS_ROLLOUT_BRANCHES=
ANALYTICS_ROLLOUT_CLASS_IDS=
ANALYTICS_ROLLOUT_COURSE_IDS=
ANALYTICS_ROLLOUT_ALLOW_BACKFILL=true
ANALYTICS_ROLLOUT_ALLOW_EXPORT=true
ANALYTICS_MONITORING_STALE_INGEST_SECONDS=900
ANALYTICS_MONITORING_STUCK_JOB_MINUTES=60
ANALYTICS_MONITORING_SNAPSHOT_STALE_HOURS=168
ANALYTICS_MONITORING_WARNING_ACTIVE_JOBS=10
```

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Điều kiện mở rộng production

- `rollout_status` là `READY` hoặc `READY_WITH_WARNINGS`.
- `monitoring_status` là `OK` hoặc `WARNING`.
- Không có `STUCK_ANALYTICS_JOBS`.
- Không có blocker trong `production-readiness`.
- Production 1–3 lớp đã đạt hoặc đạt có cảnh báo và được đối chiếu thủ công.

Lưu ý: mọi nhận định học online vẫn là tín hiệu mềm từ log hệ thống, không phải kết luận vi phạm.
