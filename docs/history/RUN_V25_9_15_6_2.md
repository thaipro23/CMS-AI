# v25.9.15.6.2 - Chapter Name Input Hotfix

Bản này sửa riêng phần thêm bài/chapter trong Bank UI.

## Thay đổi

- Popup thêm bài chỉ hỏi `Bài: {}`.
- Giáo viên nhập `1`, `2`, `1.1`, `1.2`.
- Hệ thống tự lưu tên hiển thị thành `Bài 1`, `Bài 2`, `Bài 1.1`, `Bài 1.2`.
- ID do hệ thống tự sinh.
- `chapter_no` chỉ còn là số thứ tự nội bộ để sắp xếp/unique, không hiện cho giáo viên.
- Danh sách bài, breadcrumb, workspace, release title, library key, quiz title ưu tiên dùng tên bài (`title`) thay vì ép `Bài {chapter_no}`.

## Build

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build --no-cache backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Check

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production ps
curl -i http://localhost:8000/api/health
```
