# v25.9.16.5.60 — Term-scoped Release + Quiz Schedule/Submission Time Fix

## Mục tiêu

Bản này sửa các lỗi người dùng báo sau v59:

1. Release/Library phải có mã kỳ, không dùng chung thư viện giữa các kỳ/course.
2. Không được sinh cột ảo `Quiz 14` từ usage key/problem-bank key.
3. Nếu CMS chỉ có 2 quiz thì mỗi quiz phải chiếm 3 tuần deadline trong 6 tuần học quiz.
4. Connector cần trả thêm thời gian làm/nộp bài nếu Open edX có dữ liệu (`submitted_at` best-effort).

## Thay đổi chính

### Release / Library

- Release code tự sinh bây giờ gồm term slug nếu lấy được:
  - Trước: `COM1071-bai-1-v1.0`
  - Sau: `COM1071-SU26-bai-1-v1.0`
- Library key cũng term-scoped:
  - `lib:FPT:com1071-SU26-bai-1-v1-0`
- Metadata release/publish:
  - `term_scoped_library=true`
  - `shared_across_terms=false`
  - `shared_across_courses=false`

### Quiz columns

- Backend/frontend không parse số quiz từ `key`/`usage_key` nữa.
- Các key kiểu `block@quiz-14-*` không còn tạo cột `Quiz 14`.
- Course outline ưu tiên `sequential`/`vertical` quiz container, tránh lấy các problem-bank child làm quiz column.

### Deadline schedule

- 6 tuần đầu block dùng cho quiz.
- Nếu số quiz <= 6, chia đều số tuần cho từng quiz.
- Ví dụ 2 quiz:
  - Quiz 1: tuần 1-3
  - Quiz 2: tuần 4-6
- Nếu số quiz > 6, vẫn chia số quiz theo tuần như cũ.

### Submitted time

Connector trả `submitted_at` best-effort:

- `PersistentSubsectionGrade.modified`
- `StudentModule.modified` mới nhất khi gom problem grade theo subsection

## Deploy

Không có Alembic migration.

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Nếu connector plugin đang cài tách trên LMS/Tutor, cần update/reinstall `openedx-connector-plugin`, sau đó bấm lại `Đồng bộ full CMS` ở lớp cần kiểm tra.

## Kiểm tra sau deploy

1. Tạo Release mới ở Bank chapter: mã release/library phải có mã kỳ.
2. Vào class detail: nếu CMS chỉ có 2 quiz thì chỉ hiện `Quiz 1`, `Quiz 2`; không còn `Quiz 14`.
3. Deadline 2 quiz phải chia đều 6 tuần: Quiz 1 hết tuần 3, Quiz 2 hết tuần 6.
4. Click ô Quiz kiểm tra popup có `Ngày làm/nộp` nếu Open edX trả được `submitted_at`.
