# RUN v25.9.15.6.38.5.2 — Shared Runtime Upload Job Hotfix

## Mục tiêu

Sửa lỗi upload tài liệu async báo:

```text
Không tìm thấy file tạm của job upload. Hãy upload lại tài liệu.
```

Nguyên nhân: backend tạo job và lưu file tạm ở `LOCAL_STORAGE_PATH`, nhưng Celery worker không nhìn thấy cùng thư mục đó nếu `LOCAL_STORAGE_PATH` đang trỏ về `/tmp/...` hoặc không được mount chung giữa container `backend` và `worker`.

## Thay đổi chính

- Default `LOCAL_STORAGE_PATH` đổi sang `/app/.runtime`.
- `docker-compose.prod.yml` ép `LOCAL_STORAGE_PATH=${LOCAL_STORAGE_PATH:-/app/.runtime}` cho cả `backend` và `worker`.
- `runtime_data:/app/.runtime` đã là shared Docker volume cho cả backend và worker.
- Message lỗi worker rõ nguyên nhân hơn nếu file tạm vẫn không tồn tại.

## Env production bắt buộc

```env
APP_VERSION=25.9.15.6.38.5.2-shared-runtime-upload-job-hotfix
LOCAL_STORAGE_PATH=/app/.runtime
```

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic heads

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Kiểm tra cấu hình runtime dùng chung

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend sh -lc 'echo backend:$LOCAL_STORAGE_PATH; df -h $LOCAL_STORAGE_PATH; touch $LOCAL_STORAGE_PATH/shared-test.txt'

docker compose -f docker-compose.prod.yml --env-file .env.production exec worker sh -lc 'echo worker:$LOCAL_STORAGE_PATH; ls -l $LOCAL_STORAGE_PATH/shared-test.txt'
```

Nếu worker nhìn thấy `shared-test.txt` thì upload async sẽ không còn mất file tạm.

## Lưu ý

Job upload đã failed trước bản này không tự chạy lại được vì file tạm cũ nằm trong container/path cũ. Hãy upload lại tài liệu sau khi deploy.
