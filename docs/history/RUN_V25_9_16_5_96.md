## Chạy build verification

```bash
cd /opt/ai-server
chmod +x scripts/production-build-verify.sh scripts/smoke-test-prod.sh

./scripts/production-build-verify.sh
```

Script sẽ kiểm tra:

```text
1. docker compose config
2. build backend/worker/frontend
3. up -d backend/worker/frontend
4. backend /api/health
5. /api/health/build
6. /api/health/db
7. /api/health/openedx-connector/config
8. docker compose ps
```

## Chạy smoke test sau deploy

```bash
cd /opt/ai-server
./scripts/smoke-test-prod.sh
```

Có thể test thêm API class detail nếu có token:

```bash
API_BASE_URL='https://api-ai.cms-test.poly.edu.vn' \
AUTH_HEADER='Authorization: Bearer <AI_TOKEN>' \

```
