# v25.9.16.5.5 — Student Management Course Mapping API-First Fix

## Mục tiêu

- Bỏ 2 nút topbar `Đồng bộ AP` và `Quản lý học kỳ` khỏi khu vực Student Management.
- Sửa auto-map Course CMS theo hướng API-first: khi bấm map, AI Server phải hỏi CMS/Open edX trước, không phụ thuộc cache local `CourseSyncState`.
- Không còn thông báo gây hiểu nhầm `dữ liệu local hoặc API`.
- Tăng khả năng tìm Course CMS khi run trong Open edX không đúng chính xác `SU26` nhưng vẫn là course duy nhất của mã môn/kỳ.

## Thay đổi chính

### Frontend

- `frontend/components/layout/AppShell.tsx`
  - Xóa cụm action topbar của Student Management.
  - Breadcrumb vẫn giữ trên topbar.
  - Sidebar menu `Đồng bộ AP` vẫn còn trong nhóm vận hành cho admin, vì đó là trang vận hành riêng.

### Backend

- `backend/app/services/academic_service.py`
  - `_find_exact_openedx_course_candidate()` đổi sang API-first khi `allow_external=True`.
  - Thêm `_find_openedx_course_candidate_for_scope()`:
    - thử exact suggested course ID trước;
    - nếu không thấy, search CMS/Open edX theo `subject_code`;
    - lọc course có course part khớp mã môn AP;
    - ưu tiên course có run khớp kỳ;
    - nếu chỉ có đúng 1 course an toàn thì auto-map;
    - nếu có nhiều course thì không đoán bừa, trả danh sách candidate để map thủ công.
  - Message lỗi đổi thành: `qua API CMS/Open edX`, không còn nói `dữ liệu local`.

- `backend/app/schemas/academic.py`
  - `AcademicSubjectCourseAutoMapOut` trả thêm:
    - `candidate_count`
    - `candidate_source`
    - `candidates`

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Không cần migration.

## Test nhanh kết nối Course CMS/Open edX

Sau deploy, vào `/student-management`, bấm `Auto map` ở một môn có Course CMS thật.

Nếu vẫn báo không tìm thấy, kiểm tra env:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend sh -lc '
echo "OPENEDX_STUDENT_INSIGHT_BASE_URL=$OPENEDX_STUDENT_INSIGHT_BASE_URL"
echo "OPENEDX_LMS_BASE_URL=$OPENEDX_LMS_BASE_URL"
echo "OPENEDX_CMS_BASE_URL=$OPENEDX_CMS_BASE_URL"
echo "OPENEDX_STUDENT_INSIGHT_SHARED_SECRET_LEN=${#OPENEDX_STUDENT_INSIGHT_SHARED_SECRET}"
echo "OPENEDX_CONNECTOR_HMAC_SECRET_LEN=${#OPENEDX_CONNECTOR_HMAC_SECRET}"
'
```

Test API course search trực tiếp từ backend:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec -T backend python - <<'PY'
from app.services.openedx_student_insight import OpenEdXStudentInsightClient

client = OpenEdXStudentInsightClient()
print('configured=', client.configured())
print('base_url=', client.base_url)
rows = client.search_courses(query='BUS2015', exact_course_id='course-v1:FPT+BUS2015+SU26', limit=20)
print('count=', len(rows))
for row in rows:
    print(row.get('course_id'), row.get('display_name'))
PY
```

Nếu `configured=False`, cần cấu hình HMAC/base URL trước khi auto-map hoạt động qua plugin.
