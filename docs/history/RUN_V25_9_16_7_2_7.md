# RUN v25.9.16.7.2.7 — Review Findings Full Fix

## Mục tiêu

Bản này sửa toàn bộ nhóm vấn đề đã review ở v25.9.16.7.2.6:

- Xóa chapter/bài trống không còn kẹt FK `BankVersionDiffItem`.
- Analytics ingest không nhận `file_path` tùy ý từ query string.
- Ingest tracking log có PostgreSQL advisory lock để beat/manual không overlap.
- Snapshot học online theo lớp không lẫn sinh viên lớp khác khi nhiều lớp dùng chung course CMS.
- Tối ưu tính learning behavior, bỏ N+1 theo từng sinh viên.
- FE sửa các điểm `any` đã review, đổi ingest API sang body JSON, sửa wording nút, focus state, STT sticky và dọn `!important` trong CSS.

## Deploy

```bash
cd /opt/ai-server

unzip -o ai-server-openedx-v25.9.16.7.2.7-review-findings-full-fix.zip -d /tmp/ai-server-v25.9.16.7.2.7

rsync -a --delete /tmp/ai-server-v25.9.16.7.2.7/ai_server_openedx_v25_9_16_7_2_7/ /opt/ai-server/

docker compose -f docker-compose.prod.yml --env-file .env.production build backend frontend worker beat

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend worker beat
```

## Kiểm tra sau deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production logs -n 200 backend

docker compose -f docker-compose.prod.yml --env-file .env.production logs -n 150 worker

docker compose -f docker-compose.prod.yml --env-file .env.production logs -n 100 beat
```

Kiểm tra API ingest không còn nhận path lạ:

```bash
curl -i -X POST https://api-ai.cms-test.poly.edu.vn/api/analytics/ingest/jobs \
  -H 'Content-Type: application/json' \
  -d '{"file_path":"/etc/passwd","max_lines":1000}'
```

Kỳ vọng: HTTP 422.

Kiểm tra ingest bình thường:

```bash
curl -i -X POST https://api-ai.cms-test.poly.edu.vn/api/analytics/ingest/jobs \
  -H 'Content-Type: application/json' \
  -d '{"max_lines":50000}'
```

Kỳ vọng: `status=queued` hoặc 409 nếu guard đang chặn job đang chạy.
