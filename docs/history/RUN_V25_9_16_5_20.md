# v25.9.16.5.20 — Operation Job Observability + Iframe Active Guard

Build target: incremental hardening on top of `v25.9.16.5.19`.

## Changes

- Backend Operation Jobs serialization now exposes enqueue metadata already persisted under `result_json.enqueue`:
  - `celery_task_id`
  - `task_name`
  - `enqueued_at`
  - `retry_token`
  - `enqueue_history`
- Frontend `/jobs` renders task/celery/enqueue metadata under the job message.
- MFE `UnitResetButton.jsx` reloads the LMS unit iframe only after `quiz-session/start` reports `ACTIVE` or `SUBMITTING`.

## Deploy

```bash
cd /opt/ai-server
docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

If deploying the MFE patch, copy `frontend-app-learning-patch/src/courseware/course/sequence/unit-reset/UnitResetButton.jsx` into the Learning MFE repo and rebuild/restart the MFE image using the existing server procedure.
