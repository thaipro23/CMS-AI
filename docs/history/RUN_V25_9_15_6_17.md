# v25.9.15.6.17 - Quiz Create Existing Mapping Guard Hotfix

## Fix

When `/bank/quiz` had already saved a chapter mapping, creating quiz from that mapping could fail with:

```text
Mapping không an toàn để tạo Quiz: Chapter này đã được map cho course. Không tạo trùng mapping.
```

That guard is correct when creating a new mapping, but not when creating quiz from the exact saved mapping row.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build --no-cache backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

No migration is added.
