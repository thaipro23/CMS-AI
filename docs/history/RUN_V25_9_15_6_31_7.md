# v25.9.15.6.31.7 - Merge Dashboard into Bank + Chart Overview

## Mục tiêu

Gộp `/dashboard` và `/bank` thành một màn hình tổng quan duy nhất theo luồng Bank/Quiz-first.

## Thay đổi

- `/bank` là dashboard chính cho ngân hàng đề và vận hành.
- `/dashboard` redirect về `/bank` để không còn 2 trang tổng quan trùng nhau.
- Sidebar bỏ mục `Tổng quan vận hành` khỏi nhóm Vận hành.
- `/bank` thêm biểu đồ:
  - Tình trạng câu hỏi.
  - Quy mô ngân hàng.
  - Quiz Open edX theo trạng thái.
  - Job generate theo trạng thái.
- `/bank` vẫn giữ:
  - Tìm nhanh.
  - Việc cần làm.
  - Hoạt động gần đây.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

Sau đó mở `/bank` và Ctrl+F5.
