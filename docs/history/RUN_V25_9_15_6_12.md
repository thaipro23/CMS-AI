# Run v25.9.15.6.12

## Build full AI Server

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build --no-cache backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Nếu chỉ muốn rebuild frontend + backend

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build --no-cache backend frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend
```

## Test nhanh

```bash
curl -i http://localhost:8000/api/health

docker compose -f docker-compose.prod.yml --env-file .env.production logs backend -f --tail=300
```
