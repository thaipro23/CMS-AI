# v25.9.16.4.9 — AP Sync DB Growth Guard

Mục tiêu: đồng bộ AP nhiều lần không làm phình DB khi AP trả rất nhiều môn/cơ sở/lớp rỗng.

## Thay đổi chính

- Mặc định bỏ qua lớp AP không có sinh viên hợp lệ.
- Lớp chỉ được import khi `student`/`students` có ít nhất một dòng có `username` hợp lệ.
- Nếu một payload `/get-data-cms` không có lớp hợp lệ, backend không tạo `academic_terms`, `academic_blocks`, `academic_subjects`, `academic_classes`, `academic_teachers` cho payload đó.
- Không import toàn bộ catalog môn từ `/get-course` vào DB theo mặc định; catalog chỉ dùng để tìm mã môn cần gọi `/get-data-cms`.
- Subject chỉ được lưu khi có lớp hợp lệ có sinh viên.
- Response counters có thêm `skipped_empty_classes` để biết số lớp rỗng đã bỏ qua.

## Env mới

```env
ACADEMIC_AP_SKIP_EMPTY_CLASSES=true
ACADEMIC_AP_IMPORT_CATALOG_SUBJECTS=false
```

Giữ `ACADEMIC_AP_IMPORT_CATALOG_SUBJECTS=false` ở production để tránh tạo hàng nghìn môn không có lớp/sinh viên.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker
```

Không cần migration.

## Kiểm tra sau sync

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend sh -lc '
python - <<PY
from sqlalchemy import text
from app.db.session import SessionLocal

term_id = "5ad7f095-113f-599c-a5a0-d720fe5f509e"
with SessionLocal() as db:
    print("classes", db.execute(text("SELECT count(*) FROM academic_classes WHERE term_id=:id"), {"id": term_id}).scalar())
    print("class_students", db.execute(text("""
        SELECT count(*)
        FROM academic_class_students cs
        JOIN academic_classes c ON c.id = cs.class_id
        WHERE c.term_id=:id
    """), {"id": term_id}).scalar())
    print("empty_classes", db.execute(text("""
        SELECT count(*)
        FROM academic_classes c
        WHERE c.term_id=:id
          AND NOT EXISTS (
              SELECT 1 FROM academic_class_students cs WHERE cs.class_id = c.id
          )
    """), {"id": term_id}).scalar())
PY
'
```
