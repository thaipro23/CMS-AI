# v25.9.16.4.2 — Student Progress Component Grade QA + Open edX Data Compatibility

## Mục tiêu

Bản này phát triển tiếp từ `v25.9.16.4.1-student-progress-na-query-hotfix` để harden Student Progress Dashboard trên Ulmo.3:

1. Không gọi CMS/Open edX khi chỉ F5/mở trang Student Management.
2. Điểm thành phần ưu tiên `PersistentSubsectionGrade`.
3. Nếu `PersistentSubsectionGrade` chưa có dữ liệu, plugin fallback sang `StudentModule.problem_grade`, group theo subsection/sequential gần nhất.
4. Thêm endpoint debug nguồn điểm cho admin để biết Open edX đang có dữ liệu ở bảng nào.
5. UI chi tiết lớp hiển thị `N/A` cho progress/grade/component score chưa có dữ liệu, không dùng dấu gạch dễ hiểu nhầm.

## Thay đổi chính

### Backend AI Server

- Thêm cấu hình:

```env
OPENEDX_STUDENT_INSIGHT_GRADE_DEBUG_ENDPOINT=/api/ai-student-insight/v1/grades/debug
```

- Thêm endpoint admin-only:

```http
POST /api/academic/classes/{class_id}/learning-debug
```

Payload:

```json
{"limit": 20}
```

Endpoint này gọi plugin Open edX để trả về số dòng/sample từ:

- `PersistentCourseGrade`
- `PersistentSubsectionGrade`
- `StudentModule.problem_grade`
- `BlockCompletion`

### Plugin Open edX `openedx_ai_connector`

- Thêm endpoint:

```http
POST /api/ai-student-insight/v1/grades/debug
```

- `class-analytics` vẫn trả `component_scores`, nhưng logic mới là:

```text
1. Ưu tiên PersistentSubsectionGrade
2. Nếu không có subsection grade cho user, fallback StudentModule problem grade
3. Nếu cả hai nguồn đều trống, trả [] để AI Server/UI hiển thị N/A
```

Fallback không fake điểm. Chỉ dùng dữ liệu đã có trong Open edX.

### Frontend

- Chi tiết lớp thêm nút:

```text
Debug nguồn điểm
```

- Nút này chỉ gọi Open edX khi người dùng bấm, không chạy khi F5.
- `percentLabel()` và điểm thành phần ở chi tiết lớp trả `N/A` khi thiếu dữ liệu.

## Deploy

Nếu chỉ cập nhật AI Server:

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Bản này không có migration DB mới.

Nếu dùng tính năng fallback/debug nguồn điểm, cần cập nhật plugin `openedx_ai_connector` vào LMS/CMS image rồi restart LMS/CMS.

## Test checklist

```bash
# Backend syntax/tests chính
docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend \
  python -m pytest -q app/tests/test_openedx_connector_auth.py app/tests/test_openedx_plugin_integration.py

# Frontend typecheck
docker compose -f docker-compose.prod.yml --env-file .env.production run --rm frontend \
  npm run typecheck
```

Manual QA:

1. Mở `/student-management`, F5 nhiều lần: không thấy request sang Open edX chỉ để dò course candidate.
2. Vào chi tiết lớp, chưa bấm sync: chỉ đọc dữ liệu local snapshot.
3. Bấm `Cập nhật tiến độ/điểm CMS`: plugin trả progress/grade/component scores.
4. Nếu `PersistentSubsectionGrade` rỗng nhưng `StudentModule` có grade problem: Điểm TP hiển thị source `StudentModule.problem_grade`.
5. Nếu cả hai nguồn trống: UI hiển thị `N/A`.
6. Bấm `Debug nguồn điểm`: admin thấy nguồn nào có dữ liệu, user thường bị 403.
