# Runbook v25.9.16.5.29 — Local Operation Feedback UX

## Mục tiêu

Bản này chuyển trạng thái xử lý trong Bank từ overlay khóa toàn trang sang loading cục bộ theo từng vùng/nút.

Các thao tác chính:

- Upload tài liệu: nút `Tài liệu (N)` đổi thành spinner + `Đang up tài liệu`.
- Tạo câu hỏi: nút `Tạo câu hỏi` đổi thành spinner + `Đang tạo câu hỏi`.
- Kiểm tra thay đổi: nút đổi thành `Đang kiểm tra`.
- Chốt bộ đề: nút đổi thành `Đang chốt`.
- Public thư viện: nút đổi thành `Đang public`.
- Duyệt hết câu chờ: nút đổi thành `Đang duyệt`.
- Xóa tài liệu: nút đổi thành `Đang xóa`.

Người dùng vẫn có thể làm việc với các vùng không xung đột trong trang. Không còn overlay phủ toàn bộ màn hình cho các tác vụ này.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Kiểm tra sau deploy

1. Vào `/bank/chapters/{chapterId}`.
2. Upload tài liệu. Nút `Tài liệu (N)` phải đổi thành `Đang up tài liệu` kèm spinner; danh sách câu hỏi/lọc/xem vẫn dùng được.
3. Bấm tạo câu hỏi. Nút `Tạo câu hỏi` phải đổi thành `Đang tạo câu hỏi`; người dùng vẫn xem/dọc/dọn câu hiện có được.
4. Bấm `Kiểm tra thay đổi`, `Chốt bộ đề`, `Public thư viện`: loading phải nằm trên đúng nút đó, không phủ trang.
5. F5 trong lúc upload/tạo câu hỏi: trạng thái dài hạn vẫn khôi phục từ localStorage, nhưng chỉ hiện tại nút/khu vực liên quan.
