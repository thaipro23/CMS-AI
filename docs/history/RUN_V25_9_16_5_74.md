# v25.9.16.5.74 — Training Management Initial Load Guard

## Mục tiêu

Sửa hiện tượng `/training-management` load rất lâu do frontend gọi báo cáo quản lý đào tạo khi chưa chọn được học kỳ (`term_id` rỗng), khiến backend quét toàn bộ dữ liệu theo nhiều kỳ trước khi request đúng kỳ được gửi tiếp.

## Thay đổi

- Frontend `/training-management` không gọi `/api/academic/training/teachers` khi `termId` chưa có.
- Frontend chỉ tải danh sách học kỳ khi đổi hệ `branch`, không refetch học kỳ mỗi lần `termId` tự set.
- Frontend chỉ tải cơ sở khi đổi `branch`, không refetch cơ sở mỗi lần chọn campus.
- Backend `training_teacher_report` trả rỗng ngay khi thiếu `term_id`, tránh query all-term nặng do request lỗi hoặc request khởi tạo.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend
```

Không có migration.
