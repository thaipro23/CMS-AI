# v25.9.16.7.2.16 — Learning Behavior Result Flow

## Mục tiêu

Làm lại `/analytics/learning` theo đúng luồng vận hành:

`Hệ → Học kỳ → Cơ sở → Môn → Lớp → Kết quả lớp`

Màn hình chính chỉ hiển thị kết quả. Lý do/evidence chỉ mở khi bấm vào kết quả của từng sinh viên.

## Thay đổi chính

- Bỏ các khối vận hành nặng khỏi màn chính: Pilot, Production readiness, Rollout, Monitoring, Backfill, Export CSV.
- Thêm selector phụ thuộc nhau:
  - Hệ
  - Học kỳ
  - Cơ sở
  - Môn
  - Lớp
  - Kết quả
- Khi chọn lớp, hệ thống gọi:
  - `GET /api/analytics/classes/{class_id}/learning-behavior/summary`
  - `GET /api/analytics/classes/{class_id}/learning-behavior`
- Bảng chính chỉ có:
  - STT
  - Sinh viên
  - Kết quả
  - Độ tin cậy
  - Lần học cuối
- Bấm vào pill kết quả sẽ gọi:
  - `GET /api/analytics/classes/{class_id}/students/{username}/learning-behavior`
- Drawer chi tiết hiển thị lý do rút gọn, điểm tín hiệu, tiến độ bài và video.

## Không thay đổi

- Không có migration.
- Không reset DB.
- Không đổi job ingest/backfill.
- Không đổi thuật toán phân loại backend.

## Deploy

```bash
cd /opt/ai-server

unzip -o ai-server-openedx-v25.9.16.7.2.16-learning-behavior-result-flow.zip -d /tmp/ai-server-v25.9.16.7.2.16

rsync -a --delete /tmp/ai-server-v25.9.16.7.2.16/ai_server_openedx_v25_9_16_7_2_16/ /opt/ai-server/

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

Cập nhật `.env.production`:

```env
APP_VERSION=25.9.16.7.2.16
```

## Kiểm tra sau deploy

1. Mở `/analytics/learning`.
2. Chọn Hệ → Học kỳ → Cơ sở → Môn → Lớp.
3. Bảng kết quả sinh viên hiện ngay trong trang.
4. Bấm vào pill kết quả của một sinh viên.
5. Drawer bên phải mở ra và hiển thị lý do ra kết quả.
