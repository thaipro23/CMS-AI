# v25.9.16.4.12 - Student Management Flow Hotfix

This is a backend-only hotfix for `/student-management` drill-down pages.

## Fixed

- `/api/academic/teacher/subjects` remains fixed from v25.9.16.4.11.
- `/api/academic/subjects/{subject_id}/classes` / subject classes page now uses `course_by_class` correctly in class-level learning summary.
- Prevents `NameError: name 'course_by_subject' is not defined` when opening `/student-management/subjects/{id}/classes`.

## Deploy

```bash
cd /opt/ai-server
docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker
```

No Alembic migration is required.

## Smoke test

After deploy, open these pages in order:

1. `/student-management`
2. `/student-management/subjects/<subjectId>/classes?term_id=<termId>&branch=poly&campus=`
3. `/student-management/classes/<classId>`
4. `/student-management/classes/<classId>/students` or class detail student table

Watch logs:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production logs -f --tail=0 backend
```

Expected: no `NameError: course_by_class` and no `NameError: course_by_subject`.
