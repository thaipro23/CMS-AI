# v25.9.15.6.38.2.2 — RBAC Summary NameError Hotfix

## Fix

Sửa lỗi 500 tại:

```text
GET /api/question-bank-v2/departments/summary
```

Nguyên nhân: `subject_summary_map()` vẫn ghi `published_subjects` trong field `published_version_count` dù biến đúng là `published_versions`. Khi FE mở `/bank/departments`, backend gọi summary map và phát sinh `NameError`, khiến user đã được phân quyền vẫn thấy rỗng.

## Deploy

```bash
cd /opt/ai-server
docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend
docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

`.env.production`:

```env
APP_VERSION=25.9.15.6.38.2.2-rbac-summary-nameerror-hotfix
```
