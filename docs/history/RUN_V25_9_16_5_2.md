# v25.9.16.5.2 — Student Management Topbar Cleanup

## Scope
- Cleaned duplicate Student Management page headers.
- Moved Student Management breadcrumb and actions into the global workspace topbar.
- Applied to:
  - `/student-management`
  - `/student-management/subjects/{subjectId}/classes`
  - `/student-management/classes/{classId}`

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

Backend/worker rebuild is not required for this UI-only hotfix unless deploying from a fully rebuilt package.

## Full rebuild option

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```
