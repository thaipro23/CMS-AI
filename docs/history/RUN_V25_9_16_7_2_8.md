# RUN v25.9.16.7.2.8 — Flexible Bank Quiz Scope

## Mục tiêu

Bản này mở lỏng luồng `/bank/quiz` để không mặc định mọi bài/chapter trong course đều phải tạo Quiz.

Thực tế course có thể có:

- Bài chỉ có nội dung học hoặc Assignment, không cần tạo Quiz.
- Bài cần tạo Quiz tự luyện như trước.
- `Final test` có thể tạo hoặc không; nếu tạo thì dùng cấu hình riêng khác Quiz.

## Thay đổi chính

- `/bank/quiz` cho chọn version/phiên bản môn ngay cả khi chưa phải tất cả bài đều có Release đã publish.
- Mỗi chapter có lựa chọn riêng:
  - `Tạo Quiz`
  - `Không tạo quiz`
  - `Assignment/nội dung`
  - `Tạo Final test`
- Chỉ dòng `Tạo Quiz` và `Tạo Final test` mới bắt buộc có Section mapping + Release publish.
- Dòng `Không tạo quiz` và `Assignment/nội dung` không tạo `EdxCourseChapterMapping` và không chặn lưu cấu hình.
- `Final test` dùng config riêng:
  - số câu riêng
  - tỉ lệ EASY/MEDIUM/HARD riêng
  - timer riêng
  - cooldown riêng
  - `assessment_type=final_test`
  - title/unit mặc định là `Final test`
  - metadata Open edX dùng `grade_as/format = Final Exam`
- `Quiz` vẫn giữ config riêng và metadata `assessment_type=quiz`.

## Deploy

```bash
cd /opt/ai-server

unzip -o ai-server-openedx-v25.9.16.7.2.8-flexible-bank-quiz-scope.zip -d /tmp/ai-server-v25.9.16.7.2.8

rsync -a --delete /tmp/ai-server-v25.9.16.7.2.8/ai_server_openedx_v25_9_16_7_2_8/ /opt/ai-server/

docker compose -f docker-compose.prod.yml --env-file .env.production build backend frontend worker beat

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend worker beat
```

Nên cập nhật `.env.production`:

```env
APP_VERSION=25.9.16.7.2.8
```

## Cách test trên UI

1. Vào `/bank/quiz`.
2. Dán Course ID Open edX.
3. Bấm `Phân tích course`.
4. Chọn đúng phiên bản môn/version nếu hệ thống gợi ý nhiều version.
5. Với từng bài/chapter:
   - Bài thường cần quiz → chọn `Tạo Quiz`.
   - Bài chỉ nội dung/Assignment → chọn `Assignment/nội dung` hoặc `Không tạo quiz`.
   - Bài Final test → chỉ chọn `Tạo Final test` nếu course cần tạo bài Final test thật.
6. Bấm `Lưu cấu hình mapping`.
7. Chỉ bấm tạo Quiz/Final test ở các dòng đã chọn tạo.

## Kiểm tra sau deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production logs -n 200 backend

docker compose -f docker-compose.prod.yml --env-file .env.production logs -n 150 frontend
```

Kiểm tra API preview/apply không bị chặn bởi chapter Assignment:

```bash
curl -i -X POST https://api-ai.cms-test.poly.edu.vn/api/question-bank-v2/quiz/auto-map/preview \
  -H 'Content-Type: application/json' \
  -d '{"openedx_course_id":"course-v1:FPT+WEB107+SU26","chapter_plan":[{"chapter_id":"CHAPTER_ID_ASSIGNMENT","action":"assignment"}]}'
```

Kỳ vọng:

- API không báo lỗi chỉ vì chapter Assignment không có Release.
- Response có mapping dòng đó với `skipped=true`, `requires_quiz=false`.
