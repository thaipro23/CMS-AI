# v25.9.16.5.3 — Student Management Content Header Scrub

## Mục tiêu

Topbar là nơi duy nhất hiển thị title, breadcrumb và 2 nút vận hành của luồng Student Management. Nội dung bên dưới không còn khối hero/header to lặp lại.

## Thay đổi

- Rà 3 route:
  - `/student-management`
  - `/student-management/subjects/{subjectId}/classes`
  - `/student-management/classes/{classId}`
- Không còn text/header lớn trong content như `Quản lý theo môn`, `Môn · Lớp · Sinh viên`, `hero-card`, `page-intro`, `compact-hero` trong các file route Student Management.
- Header/topbar giữ:
  - title `Môn · Lớp · SV`
  - breadcrumb `Student Management / Môn / ...`
  - 2 nút `Đồng bộ AP`, `Quản lý học kỳ`
- Làm gọn card nội dung: `Danh sách môn`, `Danh sách lớp`, `Danh sách sinh viên` là content card, không phải hero.
- Làm gọn action card chi tiết lớp thành action strip `Đồng bộ CMS`.

## Kiểm tra đã chạy

```bash
grep -R "Quản lý theo môn\|Môn · Lớp · Sinh viên\|student-page-hero\|compact-hero\|hero-card\|page-intro\|ops-hero" -n frontend/app/student-management frontend/components/layout/AppShell.tsx
```

Kết quả: không còn match trong route Student Management.

## Deploy

UI-only:

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```
