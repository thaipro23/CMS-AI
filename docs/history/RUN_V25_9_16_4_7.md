# v25.9.16.4.7 — AP TLS Chain-Only Compatibility Hotfix

## Purpose

Fix AP sync failures where Python/httpx rejects `https://api_v2.poly.edu.vn` with hostname mismatch even though curl may accept the wildcard certificate.

This release adds AP-only TLS modes:

```env
ACADEMIC_AP_TLS_MODE=strict
# strict     = verify CA chain + hostname, default
# chain_only = verify CA chain, skip hostname check
# off        = disable TLS verification entirely, UAT emergency fallback only
```

For the current UAT AP hostname, use:

```env
ACADEMIC_AP_TLS_MODE=chain_only
ACADEMIC_AP_API_BASE_URL=https://api_v2.poly.edu.vn
```

## Business rule included

`/get-course` subject discovery now always uses:

```text
branch=poly
```

The requested branch, for example `ptcd`, is not used for subject catalog discovery because it can return noisy/incorrect subjects. The requested branch is preserved as metadata and remains available to downstream sync logic.

## Deploy

No database migration is required.

```bash
cd /opt/ai-server

# Edit .env.production first
# ACADEMIC_AP_TLS_MODE=chain_only

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker
```

## Verify from backend container

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend sh -lc '
python - <<PY
import httpx, os, ssl
base=os.environ.get("ACADEMIC_AP_API_BASE_URL", "https://api_v2.poly.edu.vn").rstrip("/")
mode=os.environ.get("ACADEMIC_AP_TLS_MODE", "strict").lower()
key=os.environ.get("ACADEMIC_AP_API_KEY", "")
verify=True
if mode == "chain_only":
    ctx=ssl.create_default_context()
    ctx.check_hostname=False
    ctx.verify_mode=ssl.CERT_REQUIRED
    verify=ctx
elif mode == "off":
    verify=False
r=httpx.get(
    base + "/get-course",
    params={"branch":"poly", "term_name":"Summer 2026"},
    headers={"Authorization":f"Bearer {key}", "Content-Type":"application/json"},
    verify=verify,
    timeout=20,
)
print(r.status_code)
print(r.text[:1000])
PY
'
```

Expected result: HTTP 200 with AP subject data. If HTTP 401, network/TLS is fixed but `ACADEMIC_AP_API_KEY` is missing or wrong.
