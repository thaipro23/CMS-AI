# v25.9.16.5.24 — Timed Quiz Hard Iframe Remount Hotfix

Mục tiêu: sửa lỗi Submit/Check vẫn bị khóa dù `quiz-session/status` đang ACTIVE và còn thời gian.

## Thay đổi chính

- Không force enable nút Submit/Check.
- Sau `quiz-session/start` hoặc `reset -> start`, Learning MFE tìm iframe Unit linh hoạt hơn: `#unit-iframe`, iframe `/xblock/`, iframe chứa `block-v1`.
- Thay vì chỉ set `iframe.src`, patch clone iframe mới rồi gắn `unit_reset_nonce` để ép document LMS/XBlock render lại sạch.
- Retry 5 giây nếu iframe chưa mount kịp.
- Runtime plugin trong iframe hỗ trợ message `AI_QUIZ_ACTIVE_SESSION_READY_RELOAD` để tự reload iframe document khi DOM cũ đã bị khóa bởi timeout.

## Deploy MFE patch

```bash
cp frontend-app-learning-patch/src/courseware/course/sequence/unit-reset/UnitResetButton.jsx \
  /opt/openedx/frontend-app-learning/src/courseware/course/sequence/unit-reset/UnitResetButton.jsx

cd /opt/openedx/frontend-app-learning
git diff -- src/courseware/course/sequence/unit-reset/UnitResetButton.jsx
# build/restart MFE theo quy trình hiện tại
```

## Deploy openedx-unit-reset plugin

Copy `openedx-unit-reset-plugin` vào Open edX repo rồi rebuild openedx image/restart LMS. Runtime.js nằm ở LMS, nên chỉ rebuild MFE là chưa đủ nếu muốn dùng message tự reload iframe.
