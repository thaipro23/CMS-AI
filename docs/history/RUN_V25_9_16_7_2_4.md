# RUN v25.9.16.7.2.4 — Production Test Stabilization + UX Cleanup

## Mục tiêu

Bản này dùng file `docker-compose.prod.yml` hiện tại của server làm base chuẩn, tiếp tục chạy full test production nhưng xử lý các vấn đề phát hiện sau khi tracking log đã mount:

- Dashboard Học online không còn kẹt `Snapshot=0` chỉ vì thiếu mapping Bài/Session.
- Backfill được phép tạo snapshot `Chưa đủ dữ liệu` cho lớp đã map course và có sinh viên, kể cả khi session structure chưa rebuild.
- Resolve Course CMS dùng lại cả `AcademicClassCourseMapping` và mapping môn/kỳ/campus/branch hiện có.
- Bảng Danh sách sinh viên chỉ cuộn ngang trong vùng bảng, hạn chế tràn ngang toàn trang.
- Bỏ gạch chân/đường kẻ thô ở các bảng vận hành chính.
- Docker compose giữ base server: backend/worker/beat mount tracking log, beat có postgres dependency, worker/beat có healthcheck.

## Env bắt buộc

```env
APP_VERSION=25.9.16.7.2.4
OPENEDX_TRACKING_LOG_HOST_DIR=/home/thaitx3/.local/share/tutor/data/lms/logs
OPENEDX_TRACKING_LOG_PATH=/openedx-data/lms/logs/tracking.log
ANALYTICS_ROLLOUT_ENABLED=true
ANALYTICS_ROLLOUT_MODE=production
ANALYTICS_INGEST_ENABLED=true
ANALYTICS_INGEST_SCHEDULER_ENABLED=true
ANALYTICS_ROLLOUT_ALLOW_BACKFILL=true
ANALYTICS_ROLLOUT_ALLOW_EXPORT=true
```

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend beat
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend beat
```

Không có migration mới.

## Kiểm tra tracking log và scheduler

```bash
chmod +x scripts/analytics-tracking-log-doctor.sh scripts/production-test-verify.sh
./scripts/analytics-tracking-log-doctor.sh

docker compose -f docker-compose.prod.yml --env-file .env.production ps
docker compose -f docker-compose.prod.yml --env-file .env.production logs -n 100 beat
```

Kỳ vọng:

```text
HOST_TRACKING_OK
CONTAINER_TRACKING_OK
WORKER_TRACKING_OK
Scheduler: Sending due task analytics-ingest-openedx-tracking-log
```

## Tạo snapshot học online sau khi đã ingest event

Vào `/analytics/learning` bấm **Backfill học online**.

Bản này cho phép backfill lớp đã map course và có sinh viên dù chưa có mapping Bài/Session; kết quả ban đầu sẽ là `Chưa đủ dữ liệu` thay vì dashboard kẹt `Snapshot học online = 0`.

Sau đó rebuild/mapping Bài-Session để phân tích sâu hơn theo video/quiz/deadline.
