# v25.9.16.6.8 — Analytics Data Quality Guard + Backfill Tools

## Mục tiêu

Bản này đưa Learning Analytics / Học online tiến thêm một bước về production:

- Có kiểm tra chất lượng dữ liệu trước khi tin dashboard.
- Có kế hoạch backfill theo lớp/kỳ/cơ sở.
- Có thể đưa nhiều lớp vào hàng đợi tính lại học online bằng job nền.
- Không tạo bảng mới.
- Không query raw tracking log khi mở dashboard/health.
- Không đổi Course completion, connector contract, hoặc classifier nhãn mềm.

## API mới

### 1. Kiểm tra chất lượng dữ liệu

```bash
GET /api/analytics/ops/data-quality
GET /api/analytics/ops/data-quality?class_id=<CLASS_ID>&course_id=<COURSE_ID>
```

Trả về:

```text
readiness = READY | NEEDS_BACKFILL | CONFIG_NEEDED | NO_SCOPE
issues[]
next_actions[]
counts.tracking_events_inserted
counts.behavior_snapshot_count
counts.session_count
counts.missing_duration_count
ingest.file_exists
deadline_sources
safe_policy = signals_only_not_violation
```

### 2. Xem kế hoạch backfill

```bash
GET /api/analytics/backfill/plan?campus=<CAMPUS>&branch=<BRANCH>&limit=50
GET /api/analytics/backfill/plan?class_id=<CLASS_ID>&course_id=<COURSE_ID>
```

Trả về từng lớp:

```text
class_id
class_code
course_id
student_count
session_count
behavior_snapshot_count
can_enqueue
reasons
recommended_action
```

### 3. Đưa backfill vào hàng đợi

```bash
POST /api/analytics/backfill/jobs?campus=<CAMPUS>&branch=<BRANCH>&limit=20
POST /api/analytics/backfill/jobs?class_id=<CLASS_ID>&course_id=<COURSE_ID>
```

Backfill dùng lại bảng job hiện có:

```text
academic_class_sync_jobs.job_type = learning_analytics_recalculate
```

Không tạo bảng job mới.

## Cấu hình mới

Thêm vào `.env.production` nếu muốn đổi ngưỡng stale:

```bash
ANALYTICS_SNAPSHOT_STALE_HOURS=168
```

Mặc định 168 giờ = 7 ngày.

## Deploy

```bash
cd /opt/ai-server

# Không dùng down -v. Không xóa volume.
docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Nếu chưa chạy migration analytics core từ v6.3:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend alembic upgrade head
```

## Kiểm tra production

```bash
cd /opt/ai-server
chmod +x scripts/production-build-verify.sh scripts/smoke-test-prod.sh

./scripts/production-build-verify.sh
./scripts/smoke-test-prod.sh
```

Kiểm tra health:

```bash
curl -s http://127.0.0.1:8000/api/health/analytics | python -m json.tool
```

Kỳ vọng có:

```text
safe_policy = signals_only_not_violation
data_quality_readiness = READY | NEEDS_BACKFILL | CONFIG_NEEDED
```

Kiểm tra authenticated API:

```bash
curl -s -H "Authorization: Bearer <TOKEN>" \
  "https://<AI_API_HOST>/api/analytics/ops/data-quality?class_id=<CLASS_ID>&course_id=<COURSE_ID>" \
  | python -m json.tool
```

Backfill một lớp:

```bash
curl -X POST -H "Authorization: Bearer <TOKEN>" \
  "https://<AI_API_HOST>/api/analytics/backfill/jobs?class_id=<CLASS_ID>&course_id=<COURSE_ID>" \
  | python -m json.tool
```

Backfill theo cơ sở, tối đa 20 lớp/lần:

```bash
curl -X POST -H "Authorization: Bearer <TOKEN>" \
  "https://<AI_API_HOST>/api/analytics/backfill/jobs?campus=<CAMPUS>&branch=<BRANCH>&limit=20" \
  | python -m json.tool
```

Theo dõi job:

```bash
# UI: /jobs, filter nhóm Học online

docker compose -f docker-compose.prod.yml --env-file .env.production logs -f worker | grep -Ei "analytics|learning_analytics|học online"
```

## Kiểm tra tracking log mount

Nếu `/api/health/analytics` hoặc `/api/analytics/ops/data-quality` báo `TRACKING_LOG_NOT_MOUNTED`, kiểm tra path thật:

```bash
tutor config printroot
ls -lah $(tutor config printroot)/data/lms/logs
```

Trong `.env.production`, đặt đúng thư mục host:

```bash
OPENEDX_TRACKING_LOG_HOST_DIR=/opt/openedx/data/lms/logs
```

Trong container backend:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend \
  sh -lc 'ls -lah /openedx-data/lms/logs && test -f /openedx-data/lms/logs/tracking.log && echo OK'
```
