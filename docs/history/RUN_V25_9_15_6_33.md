# v25.9.15.6.33 — Pagination Contract toàn hệ thống Bank

## Mục tiêu

Bản này thực hiện đúng bước kế hoạch `v25.9.15.6.33 — Pagination Contract toàn hệ thống Bank` sau `v25.9.15.6.32 — Database Scale Foundation`.

Mục tiêu kỹ thuật:

- Không endpoint list lớn nào của Bank Manager trả toàn bộ bảng bằng `.all()` trực tiếp.
- Các list API dùng contract chuẩn:

```json
{
  "items": [],
  "total": 0,
  "page": 1,
  "page_size": 50,
  "total_pages": 0,
  "has_next": false
}
```

- Riêng danh sách câu hỏi trong một Bank Version dùng cursor/keyset để tránh offset sâu trên bảng `ai_questions`:

```json
{
  "items": [],
  "limit": 50,
  "has_next": false,
  "next_cursor": {
    "created_at": "2026-06-12T10:00:00",
    "id": "..."
  },
  "total": null
}
```

## API đã đổi sang pagination

Các endpoint sau trả `PaginatedOut`:

```text
GET /api/question-bank-v2/departments
GET /api/question-bank-v2/subjects
GET /api/question-bank-v2/subject-offerings
GET /api/question-bank-v2/subject-versions
GET /api/question-bank-v2/chapters
GET /api/question-bank-v2/bank-versions
GET /api/question-bank-v2/material-versions
GET /api/question-bank-v2/bank-versions/{bank_version_id}/material-chunks
GET /api/question-bank-v2/releases
GET /api/question-bank-v2/course-mappings
GET /api/question-bank-v2/course-chapter-mappings
GET /api/question-bank-v2/course-quiz-instances
GET /api/question-bank-v2/quiz-blueprints
```

Danh sách câu hỏi đổi sang cursor/keyset:

```text
GET /api/question-bank-v2/bank-versions/{bank_version_id}/questions
```

Query hỗ trợ:

```text
status_filter=pending_review|approved|rejected|draft_error
 difficulty=easy|medium|hard
 search=<text>
 limit=50         # max 100
 cursor_created_at=<ISO datetime>
 cursor_id=<question id>
 include_total=false
```

`include_total=true` vẫn có để debug/ops, nhưng mặc định tắt để tránh count nặng khi dữ liệu lớn.

## Frontend compatibility

`frontend/lib/api.ts` đã thêm wrapper tương thích:

- Backend mới trả `items/total/page/page_size`.
- Các màn hiện tại vẫn nhận array cũ nhờ `parsePageItems` / `parseCursorPageItems`.
- Wrapper có set `page_size=100` cho các list hierarchy để giảm vỡ UI trong khi chưa làm bản frontend scale `.38`.

Điều này giúp đổi backend contract trước nhưng không làm hỏng ngay các màn Bank hiện tại.

## Kiểm tra code nhanh

```bash
cd /opt/ai-server
python -m compileall backend/app backend/alembic

grep -n "response_model=list" backend/app/api/routes/question_bank_v2.py || true
grep -n "\.all()" backend/app/api/routes/question_bank_v2.py
```

Kỳ vọng `response_model=list` không còn trong `question_bank_v2.py`. `.all()` chỉ còn nằm trong helper `_paginate` và query keyset của questions.
