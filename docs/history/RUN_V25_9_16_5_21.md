# v25.9.16.5.21 — Bank Scale Runtime Hardening

## Mục tiêu

Bản này xử lý các phần scale còn lại, chưa bao gồm seed/load test 1.5M câu hỏi và chưa chạy EXPLAIN ANALYZE theo yêu cầu hiện tại.

## Thay đổi chính

1. Frontend Bank hierarchy không còn hard cap 100 bản ghi.
   - `getDepartments`, `getSubjects`, `getSubjectOfferings`, `getSubjectChapters` tự fetch nhiều page.
   - Các màn multipage cụ thể không load toàn bộ hierarchy nếu chỉ cần context hiện tại.

2. Thêm endpoint đọc trực tiếp entity theo id:
   - `GET /api/question-bank-v2/departments/{department_id}`
   - `GET /api/question-bank-v2/subjects/{subject_id}`
   - `GET /api/question-bank-v2/subject-versions/{subject_offering_id}`
   - `GET /api/question-bank-v2/chapters/{chapter_id}`

3. Dashboard summary không count trực tiếp `ai_questions` cho KPI câu hỏi lớn.
   - `bank_questions`, `retired_questions`, `carry_over_questions` đọc từ `ai_bank_chapter_stats`.
   - Thêm cột `carry_over_count` vào `ai_bank_chapter_stats`.

4. Tối ưu grouping dashboard:
   - Bỏ vòng lặp nested O(N×M) ở offering/subject/department summaries.
   - Dùng map grouping theo `subject_offering_id`, `subject_id`, `department_id`.

## Migration

```bash
cd /opt/ai-server
docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head
```

Sau migration nên rebuild stats để `carry_over_count` có số đúng:

```bash
curl -k -X POST "https://<AI_API_DOMAIN>/api/question-bank-v2/dashboard/stats/rebuild" \
  -H "Authorization: Bearer <TOKEN>"
```

Nếu endpoint rebuild dùng cookie SSO, chạy từ trình duyệt/admin UI hoặc dùng token admin tương ứng.

## Build/deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Kiểm tra nhanh

```bash
curl -k "https://<AI_API_DOMAIN>/api/question-bank-v2/summary"
curl -k "https://<AI_API_DOMAIN>/api/question-bank-v2/subjects?page=1&page_size=100"
curl -k "https://<AI_API_DOMAIN>/api/question-bank-v2/subject-versions?page=1&page_size=100"
curl -k "https://<AI_API_DOMAIN>/api/question-bank-v2/chapters?page=1&page_size=100"
```

Frontend cần kiểm tra:

- `/bank/departments`
- `/bank/departments/{id}/subjects`
- `/bank/subjects/{id}/versions`
- `/bank/versions/{id}/chapters`
- `/bank/chapters/{id}`
- `/users` nếu dùng phân quyền scope theo subject/version/chapter
