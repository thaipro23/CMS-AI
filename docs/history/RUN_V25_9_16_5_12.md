# v25.9.16.5.12 — JSON Serialization Final Guard

Hotfix dứt điểm lỗi job đồng bộ lớp thất bại với:

```text
Object of type datetime is not JSON serializable
```

## Nội dung sửa

- Thêm `app.core.json_safe` để chuẩn hoá giá trị trước khi ghi JSON DB/Celery result:
  - `datetime`, `date`, `time`
  - `Decimal`
  - `UUID`
  - `set`, `tuple`, `frozenset`
  - Open edX `CourseKey`, `UsageKey`, object Django lạ → `str(value)`
- Cấu hình SQLAlchemy `create_engine(..., json_serializer=json_dumps_safe)` để mọi cột `JSON` có lớp bảo vệ cuối cùng.
- Worker `academic_class_sync_task` sanitize `result` trước khi:
  - lưu `academic_class_sync_jobs.result_json`
  - ghi audit metadata
  - return Celery JSON result
- Error branch của worker cũng trả JSON-safe result và lưu message thật để debug.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Không cần migration.

## Lưu ý

Nếu lỗi phát sinh từ response plugin Open edX, vẫn cần cập nhật `openedx_connector_plugin` bản 5.10+ vào LMS/CMS. Bản 5.12 bảo vệ thêm phía AI Server và Celery để job không chết khi response có datetime/object lạ.
