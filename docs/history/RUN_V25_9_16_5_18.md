# v25.9.16.5.18 — Quiz Create Queue Recovery Hotfix

## Mục tiêu

Sửa lỗi job **Tạo Quiz** bị treo ở trạng thái `queued/Đang chờ` 0% khi Celery worker/Redis không xử lý hoặc bị lệch trong lúc deploy.

## Thay đổi chính

- Khi enqueue job, backend lưu `celery_task_id`, `task_name`, `enqueued_at` vào `result_json.enqueue` để nhìn được job đã được gửi vào broker hay chưa.
- Nếu enqueue vào Redis/Celery lỗi, job chuyển `failed` ngay thay vì treo `queued`.
- Thêm API:
  - `POST /api/question-bank-v2/operation-jobs/{job_id}/retry`
- Trang `/jobs` thêm nút **Chạy lại** cho job `queued`, `failed`, `canceled`.
- Tạo Quiz không tạo thêm job trùng nếu đã có job `quiz_create` cùng `release_id + course_chapter_mapping_id` đang queued/running; nếu job queued cũ tồn tại thì requeue job đó.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Kiểm tra worker

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production ps worker redis

docker compose -f docker-compose.prod.yml --env-file .env.production logs --tail=200 worker
```

## Xử lý job đang treo

Sau deploy, vào `/jobs`, tìm job **Tạo Quiz** đang `Đang chờ` rồi bấm **Chạy lại**.

Hoặc dùng API `POST /api/question-bank-v2/operation-jobs/{job_id}/retry`.

## Kiểm tra DB

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production exec -T backend python - <<'PY'
from sqlalchemy import text
from app.db.session import SessionLocal

with SessionLocal() as db:
    rows = db.execute(text('''
        SELECT id, operation_type, status, progress_current, progress_total,
               progress_label, result_json->'enqueue' AS enqueue, created_at, updated_at
        FROM ai_bank_operation_jobs
        WHERE operation_type='quiz_create'
        ORDER BY created_at DESC
        LIMIT 10
    ''')).mappings().all()
    for row in rows:
        print(dict(row))
PY
```
