# v25.9.16.5.42 — Premises-only AP campus planning + worker AP extra_host

## Mục tiêu

- Cơ sở của đồng bộ AP chỉ lấy từ `/premises` (`academic_campuses`), không lấy từ env `ACADEMIC_AP_CAMPUSES` và không cộng thêm campus từng xuất hiện trong lớp cũ.
- Số cơ sở trong popup `/ap-sync` phản ánh đúng số cơ sở đang bật theo từng hệ Poly/PTCĐ.
- Backend và worker dùng cùng `extra_hosts` để tránh lỗi backend gọi AP được nhưng Celery worker timeout.

## Env cần kiểm tra

```env
ACADEMIC_AP_API_EXTRA_HOST=api_v2.poly.edu.vn:10.2.1.35
```

`ACADEMIC_AP_CAMPUSES` đã deprecated, không dùng để tính cơ sở đồng bộ AP.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Không cần Alembic vì không thêm bảng/cột.

## Kiểm tra premises trong DB

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production exec postgres sh -lc '
psql -U "$POSTGRES_USER" -d "$POSTGRES_DB" -c "
select branch, campus_code, campus_name, active, sort_order, metadata_json
from academic_campuses
order by branch, sort_order, campus_code;
"
'
```

## Kiểm tra worker đã có hosts chưa

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production exec backend sh -lc 'getent hosts api_v2.poly.edu.vn'
docker compose -f docker-compose.prod.yml --env-file .env.production exec worker sh -lc 'getent hosts api_v2.poly.edu.vn'
```

Hai lệnh phải trả cùng IP nội bộ.

## Test AP từ worker

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production exec worker sh -lc '
python - << "PY"
import os, time, httpx
base=(os.environ.get("ACADEMIC_AP_API_BASE_URL") or "https://api_v2.poly.edu.vn").rstrip("/")
key=os.environ.get("ACADEMIC_AP_API_KEY", "")
timeout=int(os.environ.get("ACADEMIC_AP_REQUEST_TIMEOUT_SECONDS", "60"))
started=time.time()
r=httpx.get(f"{base}/get-course", params={"branch":"poly", "term_name":"Summer 2026"}, headers={"Authorization":f"Bearer {key}", "Content-Type":"application/json"}, timeout=timeout, verify=False)
print("status=", r.status_code)
print("elapsed=", round(time.time()-started, 2))
print(r.text[:300])
PY
'
```
