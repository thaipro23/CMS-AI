# RUN v25.9.16.7.2 — Full Test Rollout Default

Bản này chuyển cấu hình mặc định của Học online analytics từ pilot sang full rollout cho môi trường test ít dữ liệu.

## Mục tiêu

- Mở analytics cho toàn bộ lớp đang nhìn thấy theo RBAC.
- Không cần nhập allowlist class/campus/course khi chạy trên test ít dữ liệu.
- Vẫn giữ guard production: chống job trùng, giới hạn backfill, export limit, monitoring job treo, snapshot stale.
- Không tạo bảng mới.
- Không đổi classifier; mọi kết quả vẫn là tín hiệu mềm, không phải kết luận vi phạm.

## Cấu hình khuyến nghị trong `.env.production` cho môi trường test

```env
APP_VERSION=25.9.16.7.2
ANALYTICS_ROLLOUT_ENABLED=true
ANALYTICS_ROLLOUT_MODE=production
ANALYTICS_ROLLOUT_CAMPUSES=
ANALYTICS_ROLLOUT_BRANCHES=
ANALYTICS_ROLLOUT_CLASS_IDS=
ANALYTICS_ROLLOUT_COURSE_IDS=
ANALYTICS_ROLLOUT_ALLOW_BACKFILL=true
ANALYTICS_ROLLOUT_ALLOW_EXPORT=true
ANALYTICS_INGEST_ENABLED=true
ANALYTICS_INGEST_SCHEDULER_ENABLED=false
OPENEDX_TRACKING_LOG_PATH=/openedx-data/lms/logs/tracking.log
OPENEDX_TRACKING_LOG_HOST_DIR=/opt/openedx/data/lms/logs
ANALYTICS_MAX_LINES_PER_RUN=50000
ANALYTICS_BACKFILL_MAX_JOBS_PER_REQUEST=25
ANALYTICS_BACKFILL_MAX_ACTIVE_JOBS=20
ANALYTICS_EXPORT_MAX_ROWS=50000
```

`ANALYTICS_ROLLOUT_MODE=production` + scope rỗng nghĩa là: toàn bộ lớp trong phạm vi quyền của user được bật Học online.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Nếu nâng từ bản trước v6.3:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend alembic upgrade head
```

## Kiểm tra sau deploy

```bash
cd /opt/ai-server
chmod +x scripts/production-build-verify.sh scripts/smoke-test-prod.sh scripts/analytics-rollout-monitor.sh scripts/analytics-pilot-acceptance.sh

./scripts/production-build-verify.sh
./scripts/smoke-test-prod.sh
```

Kiểm tra rollout full:

```bash
API_BASE="https://api-ai.cms-test.poly.edu.vn/api" \
AUTH_HEADER="Authorization: Bearer <TOKEN_ADMIN_OR_MANAGER>" \
./scripts/analytics-rollout-monitor.sh
```

Kỳ vọng trong `/api/analytics/ops/rollout-control`:

```text
enabled = true
mode = PRODUCTION
out_of_rollout = 0 hoặc rất thấp nếu user bị giới hạn RBAC/filter
```

## Cách chạy dữ liệu

1. Vào `/analytics/learning`.
2. Kiểm tra `tracking.log` đã mount.
3. Chạy ingest hoặc enqueue ingest.
4. Bấm `Backfill học online`.
5. Vào `/jobs` theo dõi nhóm `Học online`.
6. Quay lại `/analytics/learning` kiểm tra readiness/monitoring.
