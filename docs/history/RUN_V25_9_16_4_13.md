# v25.9.16.4.13 — Student Management UX Polish + Breadcrumb + Dynamic Component Grades

## Scope

This version polishes the full Student Management flow:

- `/student-management`
- `/student-management/subjects/{subjectId}/classes`
- `/student-management/classes/{classId}`

## Main changes

1. Breadcrumb navigation
   - `Student Management / Môn`
   - `Student Management / Môn / {subject}`
   - `Student Management / Môn / {subject} / {class}`

2. Unified layout
   - Header, action bar, filter bar, summary strip, and table now read as one management flow.
   - Reduced useless empty boxes and decorative separation.

3. Better tables
   - More compact rows.
   - Clearer status badges.
   - Better hierarchy for subject, class, CMS sync, Course CMS, learning CMS.

4. Dynamic component grades
   - Class detail student table now renders dynamic columns from CMS/Open edX component data.
   - Examples: `Quiz 1`, `Quiz 2`, `Lab`, `Assignment`.
   - Columns are derived from class component summary first, then student component scores.
   - Missing values render as `N/A`.

5. Safer error states
   - API load failures show an inline message and retry button.
   - Avoids raw `Failed to fetch` as the only user feedback.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

No Alembic migration is required.

## QA checklist

1. Open `/student-management`.
   - The page should show synced subjects.
   - Breadcrumb should show `Student Management / Môn`.

2. Click `Xem lớp`.
   - The class list page should show subject context in the header.
   - Breadcrumb should allow returning to Student Management.

3. Click `Chi tiết lớp`.
   - The class detail page should show subject + class breadcrumb.
   - Back button should return to the class list for the same subject/term/branch/campus.

4. Run CMS/Enrollment/Learning sync if a Course CMS mapping exists.
   - The student table should render dynamic component columns if CMS returns component grades.
   - If not available, the UI should show N/A, not blank or 0.

## Notes

This version does not change AP ingestion logic or DB schema. It builds on v25.9.16.4.10/v4.12 behavior: no catalog bloat and no empty classes from AP sync.
