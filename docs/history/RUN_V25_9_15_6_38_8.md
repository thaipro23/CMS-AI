# Run v25.9.15.6.38.8 — Product UX/UI Redesign Foundation

## Mục tiêu

Bản này xây lại foundation giao diện AI Server theo chuẩn UX/UI hiện đại, sáng, dễ dùng cho nhân viên văn phòng, không đổi backend API và không đổi schema dữ liệu.

## Thay đổi chính

- Light enterprise app shell.
- Sidebar trắng, chia nhóm rõ: Công việc chính, Vận hành, Quản trị.
- Workspace topbar sticky cho ngữ cảnh trang.
- Session/token controls chuyển vào modal "Phiên làm việc" để giảm nhiễu.
- Design token mới cho màu, typography, spacing, radius, shadow, focus state.
- Button/input/card/table/modal/status được chuẩn hóa.
- Dashboard/jobs/audit/users nhận polish qua design foundation.
- Accessibility: skip link, focus ring, aria-current, reduced motion.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic heads

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```
