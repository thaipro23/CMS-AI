# v25.9.16.4.3 — Student Progress Filter + Alert Rules Completion

Bản này hoàn thiện checklist `v25.9.16.4.0 — Student Progress Dashboard Hardening` theo luồng:

```text
/student-management
→ Màn Môn
→ Xem lớp
→ Chi tiết lớp / Sinh viên
```

## Nội dung chính

### 1. Bỏ chức năng debug khỏi UI/API

- Xóa nút **Debug nguồn điểm** khỏi chi tiết lớp.
- Gỡ API AI Server `/api/academic/classes/{class_id}/learning-debug`.
- Gỡ route plugin `grades/debug`.
- Giữ fallback điểm thành phần production-safe trong `class-analytics`:
  1. ưu tiên `PersistentSubsectionGrade`,
  2. fallback `StudentModule.problem_grade` group theo subsection/sequential,
  3. không có dữ liệu thật thì trả rỗng để UI hiện `N/A`.

### 2. Màn Môn đủ filter học tập

`/student-management` có thêm filter:

```text
Tất cả môn
Chưa map course
Chưa đồng bộ CMS
Chưa có progress
Có cảnh báo
```

Cột **Học tập CMS** hiển thị rõ:

```text
Đã enroll / tổng sinh viên
Dữ liệu progress / tổng sinh viên
Đã học / tổng sinh viên
Tiến độ trung bình
Điểm tổng trung bình
Điểm thành phần
Cảnh báo
```

### 3. Màn Lớp đủ filter học tập

`/student-management/subjects/{subjectId}/classes` có thêm filter:

```text
Tất cả lớp
Lớp chưa đồng bộ CMS
Lớp chưa đủ enrollment
Lớp chưa có dữ liệu học tập
Lớp có điểm thấp
```

Cột **Sinh viên** tách rõ số AP và số đã đồng bộ CMS. Cột **Học tập CMS** tách rõ enroll, dữ liệu progress, đã học, tiến độ, điểm tổng, điểm thành phần và cảnh báo.

### 4. Chi tiết lớp gom nhóm thao tác

Chi tiết lớp không để nhiều nút rời trên header nữa. Các thao tác được gom vào card **Thao tác học tập CMS**:

```text
Đồng bộ CMS
Enrollment Course CMS
Cập nhật tiến độ/điểm
Làm mới dữ liệu
```

Chỉ các nút thao tác mới gọi CMS/Open edX. Mở trang hoặc F5 chỉ đọc dữ liệu cache/database trong AI Server.

### 5. Alert rules cấu hình được

Thêm env:

```env
ACADEMIC_LEARNING_LOW_PROGRESS_THRESHOLD_PERCENT=50
ACADEMIC_LEARNING_LOW_GRADE_THRESHOLD_PERCENT=50
```

Backend dùng cấu hình này để đánh dấu:

```text
Tiến độ thấp
Điểm thấp
Chưa map Course CMS
Chưa có dữ liệu học tập
Chưa có sinh viên vào học
Chưa đủ enrollment
```

### 6. GET/list không có side effect

Các API danh sách Student Management chỉ đọc dữ liệu local:

```text
GET /api/academic/teacher/subjects
GET /api/academic/teacher/classes
GET /api/academic/subjects/{subject_id}/classes
```

Không tự tạo mapping, không tự commit DB, không gọi Open edX khi F5. Auto-map chỉ chạy khi bấm nút `Auto map`.

## Deploy

Bản này không có migration DB mới.

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Nếu chưa cập nhật plugin từ `16.4.2`, vẫn nên cập nhật `openedx_ai_connector` để có fallback điểm thành phần từ `StudentModule.problem_grade`. Bản này không cần route debug trong plugin.

## Test checklist sau deploy

1. Mở `/student-management`, F5 nhiều lần và kiểm tra log: không có call Student Insight/Open edX nếu không bấm nút.
2. Filter màn môn:
   - Chưa map course,
   - Chưa đồng bộ CMS,
   - Chưa có progress,
   - Có cảnh báo.
3. Vào màn lớp và test filter:
   - Lớp chưa đồng bộ CMS,
   - Lớp chưa đủ enrollment,
   - Lớp chưa có dữ liệu học tập,
   - Lớp có điểm thấp.
4. Vào chi tiết lớp, bấm từng thao tác:
   - Đồng bộ CMS,
   - Enrollment Course CMS,
   - Cập nhật tiến độ/điểm,
   - Làm mới dữ liệu.
5. Xác nhận dữ liệu thiếu hiển thị `N/A`, không hiện trống hoặc hiểu nhầm thành `0`.
6. Kiểm tra giáo viên chỉ thấy lớp AP phân công; trưởng bộ môn/chủ môn/admin chỉ thấy phạm vi RBAC của mình.
