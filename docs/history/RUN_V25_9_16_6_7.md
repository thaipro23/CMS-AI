# v25.9.16.6.7 — Production Analytics Ops

## Mục tiêu

Bản này tiếp tục nâng cấp Learning Behavior Analytics theo hướng production:

- Ingest tracking log chạy nền qua Celery, không chặn HTTP request.
- Tính lại học online theo lớp chạy nền qua job table hiện có `academic_class_sync_jobs`, không tạo bảng job mới.
- Dashboard/export analytics được scope theo phân quyền lớp/campus/teacher.
- `/jobs` nhìn được nhóm việc Học online.
- Smoke test production kiểm tra thêm `/api/health/analytics` và `/api/analytics/ops/status`.
- Kết quả vẫn là tín hiệu mềm, không phải kết luận vi phạm.

## Không thay đổi

- Không tạo migration mới.
- Không đổi Course completion.
- Không đổi connector contract `25.9.16.5.98`.
- Không đọc raw tracking log khi mở dashboard.
- Không dùng từ “gian lận/cheating” trên UI.

## Deploy

```bash
cd /opt/ai-server

# nếu bản trước v6.3 chưa chạy migration analytics core thì chạy trước
# docker compose -f docker-compose.prod.yml --env-file .env.production exec backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Env khuyến nghị

```env
OPENEDX_TRACKING_LOG_HOST_DIR=/opt/openedx/data/lms/logs
OPENEDX_TRACKING_LOG_PATH=/openedx-data/lms/logs/tracking.log
ANALYTICS_INGEST_ENABLED=true
ANALYTICS_INGEST_SCHEDULER_ENABLED=false
ANALYTICS_INGEST_INTERVAL_SECONDS=60
ANALYTICS_MAX_LINES_PER_RUN=50000
ANALYTICS_VIDEO_COMPLETE_THRESHOLD=0.9
ANALYTICS_SUSPICIOUS_WATCH_RATIO=0.25
ANALYTICS_MAX_PASSIVE_SEGMENT_SECONDS=600
```

`ANALYTICS_INGEST_SCHEDULER_ENABLED=false` là mặc định an toàn. Khi đã xác nhận worker ổn và muốn dùng Celery Beat thì bật thành `true` và chạy beat đúng cách trong hạ tầng của bạn.

## Chạy ingest thủ công qua API

```bash
curl -X POST "$API_BASE_URL/api/analytics/ingest/jobs" \
  -H "$AUTH_HEADER"
```

Kiểm tra status:

```bash
curl -fsS "$API_BASE_URL/api/analytics/ops/status" \
  -H "$AUTH_HEADER" | python -m json.tool
```

## Tính lại học online cho lớp qua job nền

```bash
curl -X POST "$API_BASE_URL/api/analytics/classes/$CLASS_ID/learning-behavior/jobs?course_id=$COURSE_ID" \
  -H "$AUTH_HEADER"
```

Xem trong UI:

```text
/jobs → Nhóm việc → Học online
```

## Health check

```bash
curl -fsS http://127.0.0.1:8000/api/health/analytics | python -m json.tool
```
