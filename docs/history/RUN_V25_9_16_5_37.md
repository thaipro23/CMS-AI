# v25.9.16.5.37 — AI Server Frontend v29 Only Rollback

## Mục tiêu

Bản này chỉ rollback thư mục `frontend/` của AI Server về đúng giao diện v25.9.16.5.29.
Các phần khác giữ nguyên từ baseline v25.9.16.5.36/v34 để không lùi backend, worker, plugin, infra, scripts.

## Phạm vi thay đổi

- `frontend/`: lấy nguyên từ v25.9.16.5.29 — Local Operation Feedback UX.
- `backend/`, `openedx-unit-reset-plugin/`, `openedx-connector-plugin/`, `frontend-app-learning-patch/`, `infra/`, `scripts/`, `tutor-plugins/`: giữ nguyên từ baseline v36.
- Chỉ thêm tài liệu release/audit cho v37.

## Deploy chỉ AI Server frontend

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

Không cần rebuild LMS/MFE, không cần Alembic nếu chỉ đổi UI frontend.

## Kiểm tra sau deploy

1. Hard refresh trình duyệt: `Ctrl + F5`.
2. Vào `/bank`, `/bank/departments`, `/bank/.../chapters`.
3. Kiểm tra giao diện đã quay về kiểu v29: local operation feedback, không dùng cockpit/dark hard rebuild.
4. Kiểm tra upload tài liệu/tạo câu hỏi chỉ loading cục bộ ở nút/khu vực liên quan.
