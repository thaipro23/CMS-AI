# v25.9.16.5.8 — Unified Open edX Connector API

## Mục tiêu

Bản này thống nhất toàn bộ luồng Student Management dùng **openedx_connector_plugin** hiện có trên LMS Django, không còn coi `student insight` là plugin/secret/API tách riêng.

Luồng chuẩn:

```text
AI Server
  -> OPENEDX_CONNECTOR_BASE_URL=http(s)://cms-test.poly.edu.vn
  -> HMAC bằng OPENEDX_CONNECTOR_HMAC_SECRET
  -> openedx_connector_plugin trên LMS
  -> Open edX Django DB/APIs nội bộ
```

Không dùng MFE host `app.cms-test.poly.edu.vn` cho connector API.

## Env AI Server khuyến nghị

```env
OPENEDX_CONNECTOR_BASE_URL=https://cms-test.poly.edu.vn
OPENEDX_CONNECTOR_HMAC_SECRET=<same-secret-as-Tutor-AI_CONNECTOR_HMAC_SECRET>

OPENEDX_CONNECTOR_USERS_RESOLVE_ENDPOINT=/api/ai-connector/v1/users/resolve
OPENEDX_CONNECTOR_COURSE_SEARCH_ENDPOINT=/api/ai-connector/v1/courses/search
OPENEDX_CONNECTOR_CLASS_ANALYTICS_ENDPOINT=/api/ai-connector/v1/class-analytics
OPENEDX_CONNECTOR_ENROLLMENT_ENROLL_ENDPOINT=/api/ai-connector/v1/course-enrollment/enroll
OPENEDX_CONNECTOR_DEFAULT_ENROLLMENT_MODE=audit
OPENEDX_CONNECTOR_CLIENT_ID=ai-server
OPENEDX_CONNECTOR_TIMEOUT_SECONDS=30
OPENEDX_CONNECTOR_MAX_BATCH_SIZE=100

OPENEDX_LMS_BASE_URL=https://cms-test.poly.edu.vn
OPENEDX_CMS_BASE_URL=https://scms-test.poly.edu.vn
OPENEDX_MFE_BASE_URL=https://app.cms-test.poly.edu.vn
```

Các biến cũ vẫn được đọc để không vỡ deploy cũ, nhưng không nên dùng cho cấu hình mới:

```env
OPENEDX_STUDENT_INSIGHT_BASE_URL=
OPENEDX_STUDENT_INSIGHT_SHARED_SECRET=
```

## Deploy AI Server

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Không cần migration DB.

## Cập nhật Tutor/Open edX

```bash
cp /opt/ai-server/tutor-plugins/ai_learning_connector_env.py "$(tutor plugins printroot)/ai_learning_connector_env.py"

tutor plugins enable ai_learning_connector_env

tutor config save --set AI_CONNECTOR_HMAC_SECRET='<same-secret-as-AI-server>'

tutor local restart lms cms lms-worker cms-worker
```

Bản plugin settings mới inject `AI_CONNECTOR_HMAC_SECRET` vào cả LMS và CMS. Alias `AI_STUDENT_INSIGHT_SHARED_SECRET` được sinh từ cùng secret để các endpoint cũ vẫn chạy trong thời gian rolling upgrade.

## Lỗi thường gặp

### 403 Forbidden

Kiểm tra đúng một secret hai đầu:

```text
AI Server: OPENEDX_CONNECTOR_HMAC_SECRET
Tutor LMS/CMS: AI_CONNECTOR_HMAC_SECRET
```

Sau khi đổi Tutor config phải restart LMS/CMS.

### Gọi nhầm host

Sai:

```env
OPENEDX_CONNECTOR_BASE_URL=https://app.cms-test.poly.edu.vn
```

Đúng:

```env
OPENEDX_CONNECTOR_BASE_URL=https://cms-test.poly.edu.vn
```

`app.cms-test.poly.edu.vn` là MFE, không chứa Django connector API.
