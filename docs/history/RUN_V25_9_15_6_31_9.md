# v25.9.15.6.31.9 - Chapter quota backend + version capacity fix

Fixes bank-first question quota behavior:

- Stores the default question quota as `BudgetPolicy(scope='chapter', scope_id='default')` using existing table, no migration.
- Settings page now edits the Bank/Chapter default quota instead of the old current Course policy.
- Backend chapter summary uses the real configured chapter limit instead of hard-coded 100.
- Subject version cards show total capacity as `chapter_count * chapter_question_limit`, for example `70/400`, not `70/100`.
- Generate preview/create uses the current chapter limit instead of hard-coded `target_question_count: 100`.

Deploy:

```bash
cd /opt/ai-server
docker compose -f docker-compose.prod.yml --env-file .env.production build backend frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend
```

No DB migration required.
