# Runbook v25.9.16.5.28 — Full AI State Dark UX Design System

## Mục tiêu

Bản này là full code AI Server mới nhất sau v25.9.16.5.27. Trọng tâm:

- Dark UI theo design tokens thống nhất.
- Banner trạng thái hệ thống bền vững cho upload tài liệu và tạo câu hỏi.
- Copy trạng thái dạng `Hệ thống đang...` rõ nghĩa, không khoa trương.
- Lỗi upload tài liệu hiện trong popup và được chuẩn hóa.
- F5 không mất trạng thái operation đang chạy.
- Màu trạng thái Bank: xám = chưa làm, vàng = chưa làm hết, xanh = đã public thư viện.

## Deploy AI Server

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Không cần rebuild Learning MFE chỉ để nhận dark theme/status Bank của AI Server. Chỉ rebuild MFE Open edX nếu anh đang cập nhật phần timed quiz `UnitResetButton.jsx`.

## Test bắt buộc

### 1. Dark design system

Mở:

```text
http://ai.cms-test.poly.edu.vn/bank
http://ai.cms-test.poly.edu.vn/bank/departments
```

Kỳ vọng:

- Nền tối sâu, card tím-xanh đậm, border/glow nhẹ.
- Không còn cảm giác form admin trắng phẳng.
- Chữ đủ tương phản, input/button rõ focus.

### 2. Tạo môn mới

Mở một bộ môn:

```text
/bank/departments/{departmentId}/subjects
```

Tạo môn mới. Kỳ vọng:

- FE thấy môn mới ngay sau khi lưu.
- Không cần F5 nhiều lần.
- Nếu backend trả lỗi, message phải rõ trong popup/trang.

### 3. Màu trạng thái hierarchy

Kiểm tra 4 cấp:

```text
/bank/departments
/bank/departments/{departmentId}/subjects
/bank/subjects/{subjectId}/versions
/bank/subject-versions/{versionId}/chapters
```

Quy ước:

```text
Xám  = Chưa làm
Vàng = Chưa làm hết
Xanh = Đã public thư viện
```

### 4. Upload tài liệu lỗi

Trong `/bank/chapters/{chapterId}` thử upload:

- `.doc` hoặc `.xls`
- file không rõ đuôi
- file rỗng
- định dạng lạ

Kỳ vọng: popup báo rõ nguyên nhân và hướng xử lý, không chỉ báo lỗi chung chung.

### 5. Tạo câu hỏi / thêm tài liệu đang chạy

Khi bấm xác nhận tạo câu hỏi hoặc gắn tài liệu:

- Trang hiện status banner: `Hệ thống đang...`
- Có step rail/progress.
- F5 không mất trạng thái.
- Nút nguy hiểm bị disable để tránh thao tác lặp.
