## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend beat
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend beat
```

Không cần migration mới nếu bạn đã lên v6.3+ rồi. Nếu chưa chạy migration analytics core, chạy:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend alembic upgrade head
```

## Kiểm tra tracking log mount

```bash
cd /opt/ai-server
chmod +x scripts/analytics-tracking-log-doctor.sh scripts/production-test-verify.sh

./scripts/analytics-tracking-log-doctor.sh
```

Kỳ vọng:

```text
HOST_TRACKING_OK
CONTAINER_TRACKING_OK
WORKER_TRACKING_OK
```

Kiểm tra trực tiếp:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend bash -lc \
"ls -lah /openedx-data/lms/logs/tracking.log && tail -n 3 /openedx-data/lms/logs/tracking.log"
```

## Kiểm tra Celery Beat

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production ps

docker compose -f docker-compose.prod.yml --env-file .env.production logs -n 100 beat
```
