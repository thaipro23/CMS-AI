# v25.9.16.5.14 — Ulmo Enrollment Import + Grade Sync Verify Hotfix

## Mục tiêu

Bản này sửa dứt điểm lỗi Enrollment Course CMS trên Open edX Ulmo.3:

```text
Không import được CourseEnrollment
```

Nguyên nhân là plugin cũ import:

```python
from student.models import CourseEnrollment
```

Trên Ulmo.3 đường dẫn đúng là:

```python
from common.djangoapps.student.models import CourseEnrollment
```

## Thay đổi chính

- Connector ưu tiên `common.djangoapps.student.models.CourseEnrollment`.
- Giữ fallback `student.models.CourseEnrollment` cho môi trường cũ.
- Course Staff role ưu tiên `common.djangoapps.student.roles.CourseStaffRole`.
- Enrollment response có thêm `course_enrollment_model_source`.
- Nếu import fail, response trả diagnostics rõ ràng thay vì chỉ báo chung chung.
- Class analytics/lấy điểm trả thêm diagnostics model grade/enrollment.
- AI Server không báo thành công khi lấy điểm mà connector không xác nhận sinh viên nào enrolled.

## Deploy AI Server

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Cập nhật Open edX connector plugin

Bắt buộc cập nhật plugin vào LMS/CMS vì lỗi import nằm trong LMS plugin.

Các file quan trọng:

```text
openedx-connector-plugin/openedx_ai_connector/student_insight.py
openedx-connector-plugin/openedx_ai_connector/auth.py
```

Nếu plugin bake vào image Open edX thì phải rebuild image rồi restart LMS/CMS.
