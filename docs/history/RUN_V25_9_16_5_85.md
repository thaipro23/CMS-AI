# RUN v25.9.16.5.85 — Course Progress / Grade Sync Hardening

## Bản này sửa gì

Bản v85 làm chắc luồng cập nhật điểm CMS/Open edX sau v84:

- `Đồng bộ full CMS` vẫn là full flow:
  1. check/tạo tài khoản CMS
  2. check/enroll Course CMS
  3. lấy Course completion
  4. lấy điểm tổng + điểm thành phần
- `Cập nhật điểm` chỉ là read-only learning sync:
  - không tạo tài khoản CMS
  - không enroll
  - chỉ đọc Course Home Progress / grade / detailed grades từ Open edX Connector
- Course completion chỉ lấy từ source official như `CourseHomeProgressRoute:completion_summary`.
- Nếu connector không trả Course Home Progress official thì giữ `N/A`, không đoán từ quiz hoặc điểm tổng.
- UI chi tiết lớp có thêm box `Chẩn đoán điểm CMS` để biết vì sao completion/grade bị N/A.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Bản này không thêm migration DB mới.

Nếu server đang ở v84 và đã chạy migration v84 thì không cần `alembic upgrade head` cho v85. Nếu chưa chạy migration v84 thì vẫn cần:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend alembic upgrade head
```

## Test đúng nghiệp vụ

Mở chi tiết lớp:

```text
/student-management/classes/<classId>
```

hoặc từ luồng giáo viên:

```text
/teacher-management/classes/<classId>
```

### Test 1 — Đồng bộ full CMS

Bấm **Đồng bộ full CMS**.

Kỳ vọng:

- tạo/check user CMS
- enroll Course CMS
- lấy Course completion/grade
- message có user CMS, enroll, learned

### Test 2 — Cập nhật điểm

Bấm **Cập nhật điểm**.

Kỳ vọng:

- không tạo tài khoản CMS
- không enroll
- chỉ check progress/grade/component
- message có:
  - progress
  - điểm tổng
  - điểm thành phần
  - missing result
  - câu `Không tạo tài khoản và không enroll trong thao tác này`

### Test 3 — Chẩn đoán N/A

Nếu Course completion vẫn `N/A`, xem box **Chẩn đoán điểm CMS**:

- `Progress official` phải cho biết bao nhiêu SV có source official.
- `Source chính` phải hiện `CourseHomeProgressRoute:completion_summary` nếu plugin trả đúng.
- Nếu source official = 0, cần update/reinstall Open edX connector plugin bên LMS/CMS rồi chạy lại **Cập nhật điểm**.
