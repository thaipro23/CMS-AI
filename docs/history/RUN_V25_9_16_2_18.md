# v25.9.16.2.18 — Bank Quiz Summary Removal + AP Sync Compact Layout

Base: `v25.9.16.2.17-rebased-academic-ap-sync-latest-ui`.

## Thay đổi

### `/bank/quiz`

- Removed the five overview cards above the mapping result table:
  - Course
  - Version
  - Release
  - Section khớp
  - Sẵn sàng
- The page now goes directly from the settings panel to the empty/map result area.

### `/ap-sync`

- Removed the standalone **Phạm vi sẽ chạy** section.
- Removed the standalone **Chạy đồng bộ** section.
- Moved action buttons into **Thiết lập kỳ đồng bộ**:
  - `Đồng bộ tất cả`
  - `Đồng bộ theo hệ Poly/PTCĐ`
- Removed **Nhập kỳ nếu chưa có trong danh sách** because terms must be created from `/semesters` first.
- If no terms exist, the term dropdown now instructs the user to create a term at `/semesters` first.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

No new migration.

If the deployment has never applied Academic migrations, run once:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend \
  alembic -c alembic.ini upgrade head
```
