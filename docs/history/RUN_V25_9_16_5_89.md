# RUN v25.9.16.5.90 — CMS-Compatible StudentModule Completion Units

## Mục tiêu

Sửa tiếp lỗi Course completion fallback để khớp cách CMS/Course Home đang hiển thị.

Case thực tế:

```text
duongddph69321 = 5/8 = 62.5% ≈ 63%
```

Vì vậy AI Server/connector không được chia theo `70` và cũng không được đếm raw `StudentModule` rows. Fallback phải gom các row activity về **learning unit/subsection** mà learner nhìn thấy trong CMS.

## Đã sửa

- Connector version: `25.9.16.5.90`.
- StudentModule fallback denominator ưu tiên đếm reachable `sequential`/subsection:
  - `Phần 1`
  - `Phần 2`
  - `Quiz 1`
  - `Quiz 2`
  - ...
- Activity numerator không còn là raw activity row count.
- Activity numerator được gom về nearest parent subsection:

```text
video/problem/html row activity -> parent sequential/subsection
```

- Với course ảnh người dùng gửi, nếu LMS tree thấy 8 subsection/unit thật thì fallback sẽ ra:

```text
5 / 8 * 100 = 62.5%
```

- Diagnostics mới:
  - `student_module_subsection_total`
  - `student_module_leaf_eligible_total`
  - `student_module_raw_activity_rows`
  - `student_module_activity_unit_keys_sample`
  - `student_module_completion_unit_keys_sample`
  - `student_module_component_to_completion_unit_count`

## Deploy AI Server

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Bản này không thêm migration mới.

## Deploy / restart Open edX connector

Sau khi cập nhật connector plugin vào Tutor/LMS, bắt buộc restart LMS/CMS:

```bash
tutor local restart lms cms
```

Kiểm tra connector active:

```bash
tutor local run lms python - <<'PY'
import importlib
m = importlib.import_module('openedx_ai_connector.student_insight')
print('file=', getattr(m, '__file__', None))
print('CONNECTOR_VERSION=', getattr(m, 'CONNECTOR_VERSION', None))
PY
```

Kết quả bắt buộc:

```text
CONNECTOR_VERSION= 25.9.16.5.90
```

## Debug vì sao CMS là 5/8

Chạy trong LMS:

```bash
tutor local run lms python - <<'PY'
from opaque_keys.edx.keys import CourseKey
from openedx_ai_connector.student_insight import _completion_denominator_block_snapshot, CONNECTOR_VERSION

course_id='course-v1:FPT+COM1071+SU26'  # đổi course thật nếu khác
k=CourseKey.from_string(course_id)

print('connector=', CONNECTOR_VERSION)
s=_completion_denominator_block_snapshot(k)
for key in [
    'eligible_total',
    'subsection_total',
    'leaf_eligible_total',
    'raw_reachable_blocks',
    'breakdown_by_type',
    'completion_unit_keys_sample',
    'denominator_source',
    'denominator_rule',
]:
    print(key, '=', s.get(key))
PY
```

Kỳ vọng với ảnh hiện tại:

```text
subsection_total = 8
eligible_total = 8
```

Nếu vẫn không ra `8`, nghĩa là LMS modulestore/published course mà connector đang đọc vẫn khác màn Studio bạn nhìn thấy. Khi đó cần publish lại course, restart LMS/CMS, hoặc kiểm tra course branch/version mà LMS đang phục vụ.

2. Bấm **Cập nhật điểm**.
3. Kiểm tra user `duongddph69321`.
4. Kỳ vọng hiển thị khoảng:

```text
Hoàn thành khóa học: 62.5% hoặc 63%
Nguồn: StudentModule fallback
completed_blocks = 5
total_blocks = 8
```

Nếu Course Home official route hoạt động, nguồn tốt nhất vẫn là `CourseHomeProgressRoute:completion_summary`; StudentModule chỉ là fallback.
