# v25.9.15.6.38.2.3 — RBAC Department Summary NameError Hotfix

## Mục tiêu

Sửa lỗi `GET /api/question-bank-v2/departments/summary` vẫn trả 500 do `department_summary_map()` tham chiếu biến `published_versions` nhưng chưa khởi tạo.

## Lỗi gốc

```text
NameError: name 'published_versions' is not defined. Did you mean: 'published_releases'?
```

## Sửa

Trong `backend/app/services/bank_dashboard_stats.py`, `department_summary_map()` hiện tính rõ:

```python
published_versions = sum(int(s.get('published_version_count') or 0) for s in stats)
published_subjects = sum(1 for s in stats if s.get('is_published') or s.get('status') == 'published')
```

`published_version_count` ở cấp department dùng tổng `published_version_count` từ các subject con.
