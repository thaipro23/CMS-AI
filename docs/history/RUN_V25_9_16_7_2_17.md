# v25.9.16.7.2.17 — Learning Behavior Class Overview Flow

## Mục tiêu

Bản này tiếp tục làm gọn `/analytics/learning` theo luồng vận hành thật:

`Hệ → Học kỳ → Cơ sở → Môn → Danh sách lớp → Chi tiết lớp → Kết quả sinh viên`.

Màn chính không còn ép người dùng chọn lớp bằng dropdown dài. Sau khi chọn môn, hệ thống hiển thị bảng lớp kèm tổng kết quả học online; bấm **Xem kết quả** mới vào chi tiết lớp.

## Thay đổi chính

### 1. Backend: class overview theo môn

Thêm endpoint:

```http
GET /api/analytics/subjects/{subject_id}/classes/learning-behavior/overview
```

Query hỗ trợ:

- `term_id`
- `campus`
- `branch`
- `classification`
- `limit`
- `offset`

Endpoint chỉ đọc bảng snapshot/aggregate, không đọc raw `tracking.log`.

Response gồm:

- tổng lớp
- tổng sinh viên
- số sinh viên theo từng kết quả
- danh sách lớp
- kết quả chính của từng lớp
- số sinh viên đã có snapshot/kết quả trong lớp

### 2. Frontend: thêm bảng Danh sách lớp

`/analytics/learning` giờ có 2 tầng rõ:

1. **Danh sách lớp**: xem toàn bộ lớp của môn và kết quả chính.
2. **Chi tiết lớp**: xem từng sinh viên trong lớp đã chọn.

Bảng lớp có các cột:

- STT
- Lớp
- Kết quả chính
- Học thật
- Treo máy
- Bất thường
- Chưa đủ dữ liệu
- Thao tác

### 3. Kết quả vẫn chỉ mở lý do khi bấm vào pill

Chi tiết sinh viên vẫn giữ nguyên nguyên tắc:

- màn chính chỉ hiển thị kết quả
- bấm kết quả mới mở drawer lý do/evidence

## Migration

Không có migration.

## Deploy

```bash
cd /opt/ai-server

unzip -o ai-server-openedx-v25.9.16.7.2.17-learning-behavior-class-overview-flow.zip -d /tmp/ai-server-v25.9.16.7.2.17

rsync -a --delete /tmp/ai-server-v25.9.16.7.2.17/ai_server_openedx_v25_9_16_7_2_17/ /opt/ai-server/

docker compose -f docker-compose.prod.yml --env-file .env.production build backend frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend
```

Cập nhật:

```env
APP_VERSION=25.9.16.7.2.17
```

## Kiểm tra nhanh

1. Vào `/analytics/learning`.
2. Chọn Hệ, Học kỳ, Cơ sở, Môn.
3. Kiểm tra bảng **Danh sách lớp** xuất hiện.
4. Bấm **Xem kết quả** ở một lớp.
5. Kiểm tra **Chi tiết lớp** hiển thị sinh viên.
6. Bấm pill kết quả của sinh viên để xem lý do.
