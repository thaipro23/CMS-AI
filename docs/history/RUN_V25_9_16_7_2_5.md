# RUN v25.9.16.7.2.5 — Analytics Ops 500 + Fixed Sidebar + No Underlines

## Mục tiêu bản này

Fix nhanh đúng lỗi production test vừa báo:

1. `/api/analytics/ops/status` trả 500.
2. Các API ops liên quan trong `/analytics/learning` cũng 500: `production-readiness`, `pilot-acceptance`, `rollout-control`, `backfill/plan`.
3. Sidebar/sidepad không cố định khi cuộn trang.
4. Rà frontend và bỏ underline link toàn hệ thống.
5. Giữ dashboard học online hiển thị được phần còn tải được nếu một khối ops lỗi tạm thời.

## Nguyên nhân 500

Trong `backend/app/services/learning_analytics/analytics_core_service.py`, hàm `_course_for_class()` có fallback đọc mapping kế thừa từ `AcademicCourseMapping`, nhưng file service chưa import model này.

Khi lớp không có mapping riêng ở `AcademicClassCourseMapping`, backend đi vào fallback và phát sinh:

```text
NameError: name 'AcademicCourseMapping' is not defined
```

Vì các API ops đều gọi `_course_for_class()`, nên nhiều request cùng trả 500.

## Đã sửa

### Backend

- Import đúng `AcademicCourseMapping` trong `analytics_core_service.py`.
- Bump version service lên `25.9.16.7.2.5`.
- Thêm regression test để đảm bảo `_course_for_class()` có thể dùng fallback mapping kế thừa mà không còn NameError.
- Test static đảm bảo các route ops quan trọng vẫn tồn tại.

- Main content giữ đúng cột thứ 2, không bị chui dưới sidebar.
- Mobile/tablet vẫn để sidebar dạng static như trước.
- Bỏ underline toàn bộ thẻ `<a>` ở normal/hover/focus/visited.
- `/analytics/learning` chuyển các khối ops sang tải mềm: một khối lỗi không kéo sập cả màn hình.
- Footer version đổi sang `v25.9.16.7.2.5`.

## Deploy production

```bash
cd /opt/ai-server

unzip -o ai-server-openedx-v25.9.16.7.2.5-analytics-ops-status-sidebar-underline-fix.zip -d /tmp/ai-server-v25.9.16.7.2.5
rsync -a --delete /tmp/ai-server-v25.9.16.7.2.5/ai_server_openedx_v25_9_16_7_2_5/ /opt/ai-server/

# giữ nguyên .env.production thật nếu đang có secret production
# chỉ merge biến mới nếu cần, không copy đè secret

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend worker beat
```
