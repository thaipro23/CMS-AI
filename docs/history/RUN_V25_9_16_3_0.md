# v25.9.16.3.0 — LMS Student Insight MVP

Bản này tiếp tục sau v25.9.16.2.23, tập trung vào dữ liệu học tập thật từ CMS/Open edX cho luồng Student Management.

## Thay đổi chính

### 1. Plugin `openedx_ai_connector`

Thêm các endpoint HMAC server-to-server:

- `POST /api/ai-student-insight/v1/class-analytics`
- `POST /api/ai-student-insight/v1/course-enrollment/batch`
- `POST /api/ai-student-insight/v1/course-progress/batch`
- `POST /api/ai-student-insight/v1/quiz-grades/batch`

Endpoint chính AI Server dùng ở bản này là `class-analytics` để lấy trong một lần:

- user tồn tại/không tồn tại
- enrollment course
- completion/progress best-effort
- persistent course grade best-effort

### 2. AI Backend

Thêm bảng snapshot:

- `academic_student_learning_snapshots`

Thêm API:

- `GET /api/academic/classes/{class_id}/learning-summary`
- `POST /api/academic/classes/{class_id}/learning-sync`

Quyền truy cập vẫn theo rule cũ:

- admin xem/cập nhật tất cả
- người có quyền môn/bộ môn được xem môn/lớp thuộc quyền
- giáo viên chỉ thấy lớp AP phân công

### 3. Frontend

Trang chi tiết lớp có thêm:

- nút `Cập nhật tiến độ/điểm CMS`
- thống kê enrollment/progress/grade
- cột `Học tập CMS`
- cột `Điểm`

## Deploy AI Server

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend \
  alembic -c alembic.ini upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Deploy plugin Open edX

Cập nhật plugin `openedx_ai_connector` vào LMS/CMS image, sau đó restart LMS/CMS.

Cấu hình AI Server:

```env
OPENEDX_STUDENT_INSIGHT_BASE_URL=https://cms-test.poly.edu.vn
OPENEDX_STUDENT_INSIGHT_USERS_RESOLVE_ENDPOINT=/api/ai-student-insight/v1/users/resolve
OPENEDX_STUDENT_INSIGHT_COURSE_SEARCH_ENDPOINT=/api/ai-student-insight/v1/courses/search
OPENEDX_STUDENT_INSIGHT_CLASS_ANALYTICS_ENDPOINT=/api/ai-student-insight/v1/class-analytics
OPENEDX_STUDENT_INSIGHT_SHARED_SECRET=<same-secret>
OPENEDX_STUDENT_INSIGHT_MAX_BATCH_SIZE=100
```

Cấu hình Open edX plugin:

```env
AI_STUDENT_INSIGHT_SHARED_SECRET=<same-secret>
```

## Test

1. Vào `/student-management`.
2. Chọn môn đã auto map Course CMS.
3. Bấm `Xem lớp`.
4. Vào `Chi tiết lớp`.
5. Bấm `Kiểm tra đồng bộ CMS`.
6. Bấm `Cập nhật tiến độ/điểm CMS`.

Kỳ vọng:

- Cột `Đồng bộ CMS` hiển thị user tồn tại/chưa tồn tại.
- Cột `Học tập CMS` hiển thị enrollment/progress nếu Open edX có dữ liệu.
- Cột `Điểm` hiển thị persistent course grade nếu LMS đã ghi grade.

## Lưu ý

- Progress/grade là best-effort vì mỗi bản Open edX có module nội bộ khác nhau.
- Endpoint không fuzzy match tên/email, tránh map nhầm sinh viên.
- Nếu Open edX chưa có persistent grade hoặc completion, hệ thống vẫn lưu được enrollment/user status và để các trường progress/grade rỗng.
