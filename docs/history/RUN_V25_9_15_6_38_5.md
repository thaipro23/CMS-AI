# RUN v25.9.15.6.38.5 — RBAC Access Console + Excel Import + Audit Scope

## 1. Cập nhật env

```env
APP_VERSION=25.9.15.6.38.5-rbac-access-console-excel-import-audit-scope
```

## 2. Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic heads

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## 3. Test API template

```bash
curl -L "http://api-ai.cms-test.poly.edu.vn/api/rbac/assignments/import-template" \
  -H "Authorization: Bearer <TOKEN>" \
  -o rbac-template.xlsx
```

## 4. Test import dry-run

```bash
curl -X POST "http://api-ai.cms-test.poly.edu.vn/api/rbac/assignments/import?dry_run=true" \
  -H "Authorization: Bearer <TOKEN>" \
  -F "file=@rbac-template.xlsx" | python3 -m json.tool
```

## 5. Test audit không lộ dữ liệu

Đăng nhập user `DEPARTMENT_HEAD`, `SUBJECT_OWNER`, `QUESTION_REVIEWER` và gọi:

```bash
curl -s "http://api-ai.cms-test.poly.edu.vn/api/audit?page=1&page_size=20" \
  -H "Authorization: Bearer <TOKEN>" | python3 -m json.tool
```

Kỳ vọng: chỉ thấy audit của chính user hoặc audit trong scope được giao.
