# v25.9.15.6.31.8 - Bank Hierarchy Inline Section Headers

## Mục tiêu

Làm các trang phân cấp Ngân hàng đề gọn hơn: bỏ page header riêng ở đầu trang, đưa tiêu đề/mô tả vào `section-head` của card chính.

## Đã sửa

- `/bank/departments`
  - Bỏ page header lớn.
  - Giữ tiêu đề trong card: `Danh sách bộ môn`.

- `/bank/departments/{departmentId}/subjects`
  - Bỏ page header lớn.
  - Card chính hiển thị: `Danh sách môn trong {Bộ môn}`.

- `/bank/subjects/{subjectId}/versions`
  - Bỏ page header lớn.
  - Card chính hiển thị: `Danh sách version của {Môn}`.

- `/bank/subject-versions/{versionId}/chapters`
  - Bỏ page header lớn.
  - Card chính hiển thị: `Danh sách bài trong {Version}`.

- `/bank/chapters/{chapterId}`
  - Bỏ page header lớn `Workspace của bài`.
  - Giữ breadcrumb + các card thao tác/workspace hiện có.

- `/bank/history`
  - Bỏ page header lớn.
  - Đưa tiêu đề `Lịch sử Quiz` và nút `Tạo Quiz Open edX` vào section-head của bảng.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

Sau deploy vào các trang `/bank/...` và nhấn Ctrl + F5.
