# v25.9.16.5.43 — Chapter UI/Delete/Semester/Jobs Polish

## Mục tiêu

- Sửa popup sửa học kỳ `/semesters` fill sai ngày/block khi dữ liệu AP lưu theo UTC `17:00:00Z`.
- Xóa bài trống không còn bị chặn bởi bank version rỗng do job vận hành tạo ra.
- Bỏ chú giải trạng thái `Chưa làm / Chưa làm hết / Đã public thư viện` ở danh sách bài/version.
- Sửa màu viền card bài theo trạng thái, không bị xám toàn bộ.
- Giảm lỗi mất scrollbar do modal/popup khóa `body.overflow`.
- Tách `/jobs` khỏi `/audit`; `/jobs` hiển thị thêm job đồng bộ AP từ `academic_sync_runs`.
- Cho phép tạo/sửa chapter tên đặc biệt `Final test` và `Assignment`, ngoài định dạng `Bài x.x`.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Không cần Alembic.

## Kiểm tra nhanh

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend python -m compileall -q app
```

Frontend:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production build frontend
```
