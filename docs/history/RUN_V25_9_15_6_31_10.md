# v25.9.15.6.31.10 - Light/Dark Theme + Landing Page + Footer

## Nội dung

Bản này bổ sung:

1. Giao diện sáng/tối cho toàn app.
2. Nút đổi theme ở sidebar và landing page.
3. Footer cho app pages.
4. Trang landing page tại `/` (`http://ai.cms-test.poly.edu.vn/`).
5. Không tự redirect CMS session bridge ở `/`, để landing page hiển thị được.

## Deploy

Chỉ sửa frontend, không cần migrate DB:

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

## Kiểm tra

Mở các URL:

```text
http://ai.cms-test.poly.edu.vn/
http://ai.cms-test.poly.edu.vn/bank
http://ai.cms-test.poly.edu.vn/bank/quiz
http://ai.cms-test.poly.edu.vn/audit
```

Sau đó nhấn Ctrl + F5.

## Kỳ vọng

- `/` hiển thị landing page.
- Có nút chuyển Sáng/Tối.
- Sidebar app cũng có nút Sáng/Tối.
- Các trang app có footer.
- `/bank` vẫn là dashboard chính.
