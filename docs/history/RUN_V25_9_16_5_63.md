# v25.9.16.5.63 — Native Date Picker Vietnam Format Fix

## Mục tiêu

Sửa `/semesters` theo đúng yêu cầu: input ngày phải là native `type="date"`, không dùng text input, nhưng giao diện ưu tiên định dạng Việt Nam `dd/mm/yyyy`.

## Thay đổi chính

- `/semesters` đổi toàn bộ field ngày trong popup học kỳ và `Cấu hình tuần học` từ text input sang native date input:
  - Block start date
  - Block end date
  - Week start date
  - Week end/deadline date
- Set `lang="vi-VN"` trên date input và đổi root `<html lang="vi-VN">` để browser/date picker ưu tiên format Việt Nam.
- Form state dùng HTML date value `yyyy-mm-dd` đúng chuẩn native date input, nhưng mọi dữ liệu lưu backend vẫn chuyển thành `yyyy-mm-ddT00:00:00+07:00`.
- `Tự chia 6 tuần từ ngày bắt đầu` vẫn hoạt động với native date value và không lệch timezone.
- Nội dung hướng dẫn trong popup nói rõ ngày được chọn bằng date picker, hiển thị theo định dạng Việt Nam và lưu theo `+07:00`.

## Lưu ý kỹ thuật

Native `input[type=date]` bắt buộc value nội bộ là `yyyy-mm-dd`. Việc hiển thị `dd/mm/yyyy` do browser/locale quyết định. Bản này ép ngữ cảnh HTML/input về `vi-VN`; trên môi trường trình duyệt hỗ trợ locale Việt Nam sẽ hiển thị theo `dd/mm/yyyy`, đồng thời vẫn giữ date picker chuẩn.
