# v25.9.16.6.6 — Learning Analytics Dashboard + Export + Audit Polish

## Mục tiêu
Bản này nâng module Learning Behavior Analytics / Aspects-lite lên gần mức vận hành production hơn bằng cách thêm dashboard tổng hợp, export CSV an toàn và audit cho thao tác nhạy cảm. Không tạo migration mới, không đổi logic core Phase 0–4, không đọc raw tracking event trực tiếp cho dashboard.

## Nội dung chính

### Backend
- Thêm API dashboard:
  - `GET /api/analytics/learning/dashboard`
- Thêm export CSV:
  - `GET /api/analytics/learning/export.csv`
- Thêm API tổng quan video lớp:
  - `GET /api/analytics/classes/{class_id}/video-summary`
- Thêm API tiến độ theo Bài/Session của lớp:
  - `GET /api/analytics/classes/{class_id}/sessions/progress`
- Thêm API xem một video có sinh viên nào xem:
  - `GET /api/analytics/videos/{video_id}/students`
- Dashboard đọc từ `AnalyticsLearningBehaviorSnapshot`, không query raw tracking log cho màn tổng hợp.
- CSV chỉ xuất nhãn tiếng Việt mềm, không xuất nhãn kết luận vi phạm.
- Audit:
  - `analytics.learning_behavior.view_attention_list`
  - `analytics.learning_behavior.export_csv`

### Frontend
- Thêm route:
  - `/analytics/learning`
- Thêm menu AppShell: `Học online`.
- Dashboard gồm:
  - Tổng sinh viên
  - Có dấu hiệu học thật
  - Có khả năng treo máy
  - Dấu hiệu bất thường cần kiểm tra
  - Chưa đủ dữ liệu
  - Chưa thấy bất thường rõ
  - Lớp cần chú ý
  - Danh sách sinh viên cần giáo viên xem thêm
  - Deadline cần chú ý
- Có export CSV.
- UI chỉ dùng nhãn mềm.
- Có disclaimer: dữ liệu chỉ phản ánh tín hiệu từ log hệ thống, không phải kết luận vi phạm.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Không cần migration mới nếu bạn đã chạy migration v6.3:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend alembic upgrade head
```

## Kiểm tra sau deploy

### 1. Kiểm tra health

```bash
curl -k -s https://api-ai.cms-test.poly.edu.vn/api/health/build
```

### 2. Kiểm tra dashboard học online

```bash
curl -k -s "https://api-ai.cms-test.poly.edu.vn/api/analytics/learning/dashboard?limit=20"
```

### 3. Kiểm tra export CSV

```bash
curl -k -L "https://api-ai.cms-test.poly.edu.vn/api/analytics/learning/export.csv" -o learning-behavior-signals.csv
head -5 learning-behavior-signals.csv
```

Dòng đầu CSV phải có disclaimer.

### 4. Luồng vận hành chuẩn

```text
1. Ingest tracking log
2. Rebuild session structure nếu course chưa có mapping Bài/Session
3. Recalculate học online cho lớp
4. Mở /analytics/learning để xem dashboard
5. Mở /student-management/classes/{classId} để xem chi tiết lớp
6. Chỉ dùng kết quả như tín hiệu nghi vấn, không kết luận vi phạm
```
