# RUN v25.9.16.7.2.21 — Worker-backed Auto Map All Jobs

## Mục tiêu

Bản này sửa đúng vấn đề production: `Auto map tất cả` là tiến trình nặng nên không chạy trong request của trình duyệt nữa. UI chỉ tạo parent job, worker xử lý nền, `/jobs` hiển thị tiến trình cho mọi người dùng có quyền.

## Deploy

```bash
cd /opt/ai-server

unzip -o ai-server-openedx-v25.9.16.7.2.21-worker-backed-auto-map-jobs.zip -d /tmp/ai-server-v25.9.16.7.2.21

rsync -a --delete /tmp/ai-server-v25.9.16.7.2.21/ai_server_openedx_v25_9_16_7_2_21/ /opt/ai-server/

docker compose -f docker-compose.prod.yml --env-file .env.production build backend frontend worker

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend

docker compose -f docker-compose.prod.yml --env-file .env.production exec backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend worker
```

## Env

```env
APP_VERSION=25.9.16.7.2.21
```

## Kiểm tra nhanh

1. Vào `/student-management`.
2. Chọn Hệ / Học kỳ / Cơ sở.
3. Bấm `Auto map tất cả`.
4. Trang phải báo đã tạo job và có link `Xem Jobs`.
5. F5 lại `/student-management`: nếu job còn chạy, vẫn thấy thông báo `Auto map đang chạy nền`.
6. Vào `/jobs`: thấy nhóm `Auto map / đồng bộ hàng loạt` và job `Auto map tất cả + đồng bộ CMS`.
7. Khi parent job chạy xong, các child job `Đồng bộ full CMS` tiếp tục chạy cho từng lớp.

## Kiểm tra DB

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec -T postgres sh -lc 'psql -U "$POSTGRES_USER" -d "$POSTGRES_DB" <<SQL
SELECT job_type, status, progress_current, progress_total, progress_label, created_at
FROM academic_bulk_operation_jobs
ORDER BY created_at DESC
LIMIT 10;
SQL'
```
