# v25.9.16.5.88 — StudentModule Denominator Fix

## Mục tiêu

Bản này sửa lỗi `Course completion` fallback bị chia cho mẫu số sai, ví dụ `15/70 = 21.4%`.

Nguyên nhân: các bản trước có thể lấy `total_blocks` từ course tree/Studio content summary, trong đó có section/subsection/unit/container hoặc block cũ còn nằm trong modulestore/cache. Đây không phải mẫu số đúng cho StudentModule fallback.

Từ v88:

- `StudentModule` fallback vẫn chỉ tính activity rows thật.
- Mẫu số fallback chỉ đếm **reachable leaf learning components** đang thấy từ LMS connector.
- Không tính `course`, `chapter`, `sequential`, `vertical`, `library_content`.
- Connector trả thêm breakdown để debug vì sao ra mẫu số.


## Cập nhật connector LMS/CMS

Sau khi copy plugin/override mới vào Open edX/Tutor, phải restart LMS/CMS:

```bash
tutor local restart lms cms
```

Kiểm tra code connector active:

```bash
tutor local run lms python - <<'PY'
import importlib
m = importlib.import_module('openedx_ai_connector.student_insight')
print('file=', getattr(m, '__file__', None))
print('CONNECTOR_VERSION=', getattr(m, 'CONNECTOR_VERSION', None))
PY
```

Phải thấy:

```text
CONNECTOR_VERSION= 25.9.16.5.88
```

Nếu vẫn là v86/v87 hoặc không có version, LMS đang chạy code cũ/cache cũ.

## Kiểm tra vì sao trước đó ra 70

Chạy trong LMS shell:

```bash
tutor local run lms python - <<'PY'
from opaque_keys.edx.keys import CourseKey
from xmodule.modulestore.django import modulestore
from openedx_ai_connector.student_insight import _completion_denominator_block_snapshot, CONNECTOR_VERSION

course_id='course-v1:FPT+COM1071+SU26'  # đổi theo course thật
k=CourseKey.from_string(course_id)
print('connector=', CONNECTOR_VERSION)
print(_completion_denominator_block_snapshot(k))
PY
```

Cần nhìn các trường:

- `raw_reachable_blocks`: số block LMS connector đang nhìn thấy trong cây course.
- `non_container_blocks`: số block không phải container; đây là chỗ dễ ra 70 ở bản cũ.
- `eligible_total`: mẫu số mới dùng để chia fallback.
- `breakdown_by_type`: tổng theo loại block.
- `eligible_breakdown_by_type`: những block được tính vào mẫu số.

Nếu Studio đã xóa nhưng LMS vẫn thấy block cũ trong `breakdown_by_type`, cần publish lại course/chờ modulestore cập nhật rồi restart LMS/CMS.

## Sau deploy

Trong AI Server vào màn chi tiết lớp:

1. Bấm **Cập nhật điểm**.
2. Kiểm tra dòng sinh viên chưa học thật không còn baseline `21.4%` do `15/70`.
3. Mở box chẩn đoán CMS, kiểm tra source là `StudentModule` và breakdown mẫu số mới.
