# v25.9.16.5.18.1 — Jobs Retry ActionMessage TypeScript Build Hotfix

## Fix

Frontend build failed at:

```text
app/jobs/page.tsx(69,75): error TS2353: Object literal may only specify known properties, and 'message' does not exist in type 'ActionMessageData'.
```

`ActionMessageData` uses `body`, not `message`.

Changed:

```tsx
setMessage({ type: 'success', title: 'Đã đưa lại job vào hàng đợi', message: ... })
```

To:

```tsx
setMessage({ type: 'success', title: 'Đã đưa lại job vào hàng đợi', body: ... })
```

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```
