# RUN v25.9.16.4.4 — Academic Security + Scale Hardening

Bản này sửa các vấn đề review toàn project cho Student Management / Open edX integration sau `v25.9.16.4.3`.

## Nội dung chính

1. Siết quyền các API mutate học vụ:
   - auto-map Course CMS
   - kiểm tra/tạo user CMS
   - enroll Course CMS
   - sync progress/grade

2. Chặn runtime settings hạ bảo mật trong production:
   - không cho bật `AUTH_MODE=demo`
   - không cho bật demo role header
   - không cho bật mock Open edX/LLM
   - validate security settings trước khi ghi runtime config

3. Alembic hardening:
   - widen `alembic_version.version_num` trong `env.py`
   - thêm migration `0042_v25_9_16_4_4_academic_security_scale_hardening`

4. Course mapping hardening:
   - dọn duplicate active mapping theo scope hiệu dụng
   - thêm unique functional partial index để xử lý `NULL`
   - dùng effective course mapping thống nhất, class override luôn thắng inherited mapping

5. Learning/enrollment snapshot hardening:
   - tách `enrollment_synced_at` và `learning_synced_at`
   - enrollment-only snapshot không còn làm learning sync bị skip nhầm
   - giới hạn batch sync còn 500 để tránh timeout request dài

6. Plugin Open edX hardening:
   - HMAC nonce replay protection qua Django cache
   - giới hạn body size và batch usernames
   - ẩn exception nội bộ trong response của endpoint student insight

7. Frontend hardening:
   - API client dùng `credentials: include` mặc định để hỗ trợ HttpOnly cookie
   - production không lưu access token vào `sessionStorage`
   - parse lỗi API/proxy thân thiện hơn
   - sửa metric CMS: tách `Chưa kiểm tra CMS`, `Cần xử lý CMS`, `Lỗi/không match`

8. Test bổ sung:
   - test enrollment-only snapshot không tính là learning data
   - test component score được tính là learning payload
   - test production runtime settings chặn security knobs

## Deploy

Bản này có migration DB mới.

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend \
  alembic -c alembic.ini upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

Nếu dùng endpoint Student Insight mới/hardening plugin, cần rebuild/redeploy plugin `openedx_ai_connector` vào LMS/CMS image rồi restart LMS/CMS.

## Kiểm tra sau deploy

1. Vào `/student-management`, F5 trang: không được gọi Open edX/plugin.
2. User chỉ có quyền `view_questions` không được bấm/sử dụng API sync CMS/enroll/learning.
3. Admin hoặc user có quyền sync học vụ vẫn sync được.
4. Class có course override phải enroll/sync đúng course override.
5. Chạy enrollment trước, sau đó learning sync không force vẫn phải lấy progress/grade nếu snapshot chưa có learning data.
6. Gửi lại cùng HMAC nonce trong plugin phải bị reject.
7. Runtime settings production không được bật demo/mock.
