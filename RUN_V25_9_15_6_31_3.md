# v25.9.15.6.31.3 - Bank Quiz Create Popup Settings UX

This frontend-only hotfix improves `/bank/quiz` UX.

## Changes

- The question plan and timer controls are no longer shown as large always-visible sections in the right panel.
- Clicking `Tạo Quiz` for one chapter or `Tạo Quiz (X)` for all ready chapters opens a popup.
- The popup lets users edit:
  - total questions
  - Easy / Medium / Hard percentage
  - custom timer enabled
  - time limit minutes
  - retake cooldown minutes
  - auto-submit on timeout
  - lock after timeout
- The popup also shows the FPT naming rule before confirmation.
- The implementation follows the existing bank modal/popup style already used by the Bank pages.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

Then open `/bank/quiz` and press Ctrl+F5.
