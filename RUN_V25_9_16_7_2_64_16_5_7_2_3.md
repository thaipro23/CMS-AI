# Run v25.9.16.7.2.64.16.5.7.2.3

This release changes frontend source only. It does not add a database migration or modify backend API behavior.

## 1. Pull source and update the displayed version

```bash
cd /opt/ai-server
git pull

sed -i 's/^APP_VERSION=.*/APP_VERSION=25.9.16.7.2.64.16.5.7.2.3/' .env.production
```

Confirm:

```bash
grep '^APP_VERSION=' .env.production
```

## 2. Run the focused source gate

```bash
chmod +x scripts/frontend-visual-ergonomics-report.sh
./scripts/frontend-visual-ergonomics-report.sh
```

Expected: `6 passed` and `READY`.

## 3. Build only frontend

Do not use `--no-cache`.

```bash
docker compose \
  -f docker-compose.prod.yml \
  --env-file .env.production \
  build frontend
```

## 4. Recreate only frontend

```bash
docker compose \
  -f docker-compose.prod.yml \
  --env-file .env.production \
  up -d --no-build --force-recreate frontend
```

No Alembic command is required. Do not rebuild backend/workers and do not delete volumes.

## 5. Verify

```bash
docker compose \
  -f docker-compose.prod.yml \
  --env-file .env.production \
  ps -a

docker logs ai-frontend --tail=120
```

Open a private browser window and verify:

- Chapter question-review typography is readable and not excessively bold.
- Chapter actions show `Tạo câu hỏi (x/100)` and `Duyệt câu hỏi (n câu chờ duyệt)`.
- The QA publish/rollback panel is absent.
- Bank hierarchy links appear in the topbar and are clickable.
- Quiz/Final configuration is two columns on desktop.
- Student Management scrolls vertically.
- Teacher filters stay in normal flow; avatar and control overlap are gone.
