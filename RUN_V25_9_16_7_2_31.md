# v25.9.16.7.2.31 — Teacher Report Fast Lite + Bank Quiz Notice Polish

## Mục tiêu

Bản này xử lý 3 điểm production UX/performance:

1. `/teacher-management` không còn rơi về đường tính full report nặng khi cache chưa có.
2. `/bank/quiz` không còn dính chữ trong cột Trạng thái và cảnh báo/bảng có khoảng cách rõ.
3. Thông báo thành công không bị tô đỏ chỉ vì nội dung có chữ "không".

## Deploy

```bash
cd /opt/ai-server

unzip -o ai-server-openedx-v25.9.16.7.2.31-teacher-fast-lite-bank-quiz-polish.zip -d /tmp/ai-server-v25.9.16.7.2.31

rsync -a --delete /tmp/ai-server-v25.9.16.7.2.31/ai_server_openedx_v25_9_16_7_2_31/ /opt/ai-server/

docker compose -f docker-compose.prod.yml --env-file .env.production build backend frontend worker

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend worker
```

Không có migration mới.
