# v25.9.16.7.2.32 — Backend-driven Notice Status Contract

## Mục tiêu

Bản này sửa đúng nguyên tắc: **backend phải trả trạng thái thông báo**, frontend không được đoán thành công/lỗi bằng nội dung text.

Đã xử lý:

1. Backend trả `ui_status`, `ui_title`, `ui_message` cho các response chính của `/bank/quiz`:
   - preview auto-map
   - apply auto-map
   - preview plan tạo Quiz/Final test
   - create Quiz/Final test
   - rollback bài kiểm tra
2. Frontend `/bank/quiz` dùng helper `inlineMessageFromBackend(...)` để lấy màu/tone từ backend status.
3. Rà static toàn FE: không còn heuristic kiểu `message.includes('không')` / keyword detection cho thông báo `/bank/quiz`.
4. Giữ lại các fix .31: teacher fast-lite, spacing cột Trạng thái, thông báo semantic.

## Deploy

```bash
cd /opt/ai-server

unzip -o ai-server-openedx-v25.9.16.7.2.32-backend-driven-notice-status.zip -d /tmp/ai-server-v25.9.16.7.2.32

rsync -a --delete /tmp/ai-server-v25.9.16.7.2.32/ai_server_openedx_v25_9_16_7_2_32/ /opt/ai-server/

docker compose -f docker-compose.prod.yml --env-file .env.production build backend frontend worker

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend worker
```

Không có migration mới.

## Test production nhanh

### 1. `/bank/quiz` response phải có trạng thái UI từ backend

```bash
curl -sS -X POST 'https://api-ai.cms-test.poly.edu.vn/api/question-bank-v2/quiz/auto-map/apply' \
  -H 'Authorization: Bearer <TOKEN>' \
  -H 'Content-Type: application/json' \
  -d '{
    "openedx_course_id":"course-v1:FPT+COM1071+SU26",
    "chapter_plan":[{"chapter_id":"<CHAPTER_ID>","action":"skip"}]
  }' | jq '{ok, ui_status, ui_title, ui_message, message}'
```

Kỳ vọng thành công hợp lệ:

```text
ui_status = "success"
```

Ngay cả khi message có chữ `không tạo Quiz`, UI vẫn phải màu xanh.
