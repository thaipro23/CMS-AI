```text

```

Root:

```text
ai_server_openedx_v25_9_16_7_2_64_16_1
```

Bản này tiếp tục trực tiếp từ `.64.16`. Không có migration mới; migration cuối vẫn là `0052_v25_9_16_7_2_27_learning_behavior_logic_calibration.py`.

## 1. Sao lưu cấu hình và kiểm tra migration

```bash
cd /opt/ai-server
cp .env.production ".env.production.backup.$(date +%Y%m%d-%H%M%S)"

docker compose -f docker-compose.prod.yml --env-file .env.production exec backend \
  alembic -c alembic.ini current
```

Không reset database, không xóa volume, không sửa tay `alembic_version`, không chạy `docker compose down -v`.

## 2. Giải nén và đồng bộ source

```bash
rm -rf /tmp/ai-server-v25.9.16.7.2.64.16.1
mkdir -p /tmp/ai-server-v25.9.16.7.2.64.16.1

unzip -q ai-server-openedx-v25.9.16.7.2.64.16.1-enterprise-visual-foundation-review-ux.zip \
  -d /tmp/ai-server-v25.9.16.7.2.64.16.1

rsync -a --delete \
  /tmp/ai-server-v25.9.16.7.2.64.16.1/ai_server_openedx_v25_9_16_7_2_64_16_1/ \
  /opt/ai-server/
```

## 3. Cấu hình production

```env
APP_ENV=production
APP_VERSION=25.9.16.7.2.64.16.1
NEXT_PUBLIC_APP_ENV=production

NEXT_PUBLIC_ENABLE_DIAGNOSTICS_UI=false

AUTH_MODE=openedx_sso
ALLOW_DEMO_ROLE_HEADER=false
AUTH_COOKIE_SECURE=true
```

CORS production chỉ giữ origin HTTPS đã phê duyệt. Giao diện production luôn dùng sidebar tối và vùng làm việc sáng; không còn theme switcher.

## 4. Build và triển khai

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production \
  build backend worker beat frontend

docker compose -f docker-compose.prod.yml --env-file .env.production \
  up -d --force-recreate backend worker beat frontend
```

```bash

  logs --since=10m backend worker beat frontend
```
