# v25.9.15.6.20 - Bank Entity Action Menu Click Hotfix

## Mục tiêu
Sửa nút hành động `...` ở card Bộ môn / Môn / Phiên bản môn / Bài không mở menu.

## Thay đổi
- Đổi `details/summary` sang button trạng thái React để không bị `preventDefault` làm hỏng toggle.
- Icon hiển thị thành `⋮` rõ hơn thay vì text `...`.
- Menu có hai hành động: `Sửa thông tin`, `Xóa`.
- Click icon/menu không điều hướng vào card.
- Tăng z-index để menu nổi trên card bên cạnh.

## Deploy
Bản này chỉ cần frontend AI Server, nhưng có thể build cả stack nếu muốn.

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

Nếu muốn chắc chắn đồng bộ backend hiện tại:

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```
