## Trước khi deploy

1. Backup PostgreSQL và `.env.production`.
2. Không chạy `docker compose down -v`.
3. Không reset database hoặc sửa tay `alembic_version`.
4. Xác nhận Redis production hoạt động; Redis là replay/revocation store của SSO.
5. Production public phải dùng HTTPS.

Các biến bắt buộc/khuyến nghị:

```env
APP_ENV=production
APP_VERSION=25.9.16.7.2.64.16.5.4
NEXT_PUBLIC_APP_VERSION=25.9.16.7.2.64.16.5.4
NEXT_PUBLIC_APP_ENV=production
NEXT_PUBLIC_ENABLE_DIAGNOSTICS_UI=false

AUTH_MODE=openedx_sso
AUTH_COOKIE_SECURE=true
AUTH_COOKIE_SAMESITE=lax
AUTH_SESSION_TOKEN_TTL_SECONDS=7200
OPENEDX_SESSION_BRIDGE_MAX_AGE_SECONDS=60
AUTH_EXCHANGE_RATE_LIMIT_PER_MINUTE=20
AUTH_EXCHANGE_TICKET_RATE_LIMIT_PER_MINUTE=3
REDIS_URL=redis://redis:6379/0
```

## Build và migration

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production \
  build backend frontend worker beat

# Chạy migration một lần trước khi recreate các service.
docker compose -f docker-compose.prod.yml --env-file .env.production \
  run --rm --no-deps backend alembic -c alembic.ini upgrade head

# Phải trả về 0053.
docker compose -f docker-compose.prod.yml --env-file .env.production \
  run --rm --no-deps backend alembic -c alembic.ini current

docker compose -f docker-compose.prod.yml --env-file .env.production \
  up -d --force-recreate backend frontend worker beat
```

Không scale nhiều backend replica trong lúc migration vì command runtime hiện vẫn có `alembic upgrade head` trước Gunicorn.

## Smoke test bắt buộc

### Diff permission

- Tài khoản chỉ có quyền xem gọi preview: trả kết quả, không tăng số row `ai_bank_version_diffs`.
- Tài khoản chỉ xem gọi `/diffs`: phải bị 403.
- Tài khoản sửa lưu cùng diff hai lần: nhận cùng `diff_id`.

### SSO

- Exchange response production không có `access_token`.
- Gửi lại cùng ticket lần hai: bị từ chối.
- Sau `Đăng xuất`, `/api/rbac/me` trả 401/unauthenticated.
- Đăng nhập lại bằng CMS hoạt động.
- Kiểm tra Redis có key TTL cho ticket used/revoked session, không log token.

### Errors

- Cố ý tạo validation/integration error: client chỉ thấy error code/message và request ID; log server giữ traceback.
