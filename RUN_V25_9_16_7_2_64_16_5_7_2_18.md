## 3. Database migration

Backup/snapshot PostgreSQL trước theo quy trình vận hành của cụm.

Kiểm tra hiện tại:

```bash
POD=$(kubectl -n openedx get pod -l app=ai-server-backend -o jsonpath='{.items[0].metadata.name}')
kubectl -n openedx exec -it "$POD" -- sh -lc 'cd /app && alembic -c alembic.ini current'
```

Khi image `.18` đã có migration files nhưng trước khi traffic backend mới dùng schema mới:

```bash
kubectl -n openedx exec -it "$POD" -- sh -lc 'cd /app && alembic -c alembic.ini upgrade head'
kubectl -n openedx exec -it "$POD" -- sh -lc 'cd /app && alembic -c alembic.ini current'
```

Expected:

```text

```

Nếu cụm dùng migration Job, ưu tiên Job release thay vì chạy nhiều pod đồng thời.

## 6. Smoke test Question Bank

### Manual authoring

1. Vào Chapter Workspace.
2. `+ Thêm câu hỏi`.
3. Tạo lần lượt:
   - Một đáp án;
   - Nhiều đáp án;
   - Trả lời ngắn;
   - Trả lời số.
4. Xác nhận câu mới ở `Chờ duyệt`.
5. Thêm PNG/JPEG/WebP với alt text; thử SVG phải bị từ chối.

### AI Multi-select

1. Chọn tỷ lệ Single/Multi, ví dụ 70/30.
2. Preview generation.
3. Generate.
4. Kiểm tổng type count khớp preview và không có Multi <2 hoặc >3 correct answer.

### Open edX import

1. Mở `Import Open edX`.
2. Preview OLX có single, checkbox, string, numerical.
3. Commit import.
4. Tất cả câu phải ở `Chờ duyệt` và giữ đúng response type.
5. `stringresponse type=regexp` phải bị reject, không tự đổi semantics.
