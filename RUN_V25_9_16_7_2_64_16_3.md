# Deploy v25.9.16.7.2.64.16.3 — Production

Artifact:

```text
ai-server-openedx-v25.9.16.7.2.64.16.3-training-operations-analytics-ux.zip
```

Root:

```text
ai_server_openedx_v25_9_16_7_2_64_16_3
```

Bản này tiếp tục trực tiếp từ `.64.16.2`. Không có migration mới; migration cuối vẫn là `0052_v25_9_16_7_2_27_learning_behavior_logic_calibration.py`.

## 1. Sao lưu cấu hình và xác minh migration hiện tại

```bash
cd /opt/ai-server
cp .env.production ".env.production.backup.$(date +%Y%m%d-%H%M%S)"

docker compose -f docker-compose.prod.yml --env-file .env.production exec backend \
  alembic -c alembic.ini current
```

Không reset database, không xóa volume, không sửa tay `alembic_version`, không chạy `docker compose down -v`.

## 2. Giải nén và đồng bộ source

```bash
rm -rf /tmp/ai-server-v25.9.16.7.2.64.16.3
mkdir -p /tmp/ai-server-v25.9.16.7.2.64.16.3

unzip -q ai-server-openedx-v25.9.16.7.2.64.16.3-training-operations-analytics-ux.zip \
  -d /tmp/ai-server-v25.9.16.7.2.64.16.3

rsync -a --delete \
  /tmp/ai-server-v25.9.16.7.2.64.16.3/ai_server_openedx_v25_9_16_7_2_64_16_3/ \
  /opt/ai-server/
```

## 3. Cấu hình production

```env
APP_ENV=production
APP_VERSION=25.9.16.7.2.64.16.3
NEXT_PUBLIC_APP_ENV=production
NEXT_PUBLIC_APP_VERSION=25.9.16.7.2.64.16.3
NEXT_PUBLIC_ENABLE_DIAGNOSTICS_UI=false

AUTH_MODE=openedx_sso
ALLOW_DEMO_ROLE_HEADER=false
AUTH_COOKIE_SECURE=true
AUTH_COOKIE_SAMESITE=lax
DEBUG=false
AUTO_CREATE_TABLES=false
DB_STATEMENT_TIMEOUT_MS=5000
```

CORS production chỉ giữ origin HTTPS đã phê duyệt. Sidebar luôn tối; topbar và vùng làm việc luôn sáng.

## 4. Build và triển khai

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production \
  build backend worker beat frontend

docker compose -f docker-compose.prod.yml --env-file .env.production \
  up -d --force-recreate backend worker beat frontend
```

## 5. Kiểm tra kỹ thuật

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production ps

docker compose -f docker-compose.prod.yml --env-file .env.production \
  logs --since=10m backend worker beat frontend

curl -fsS https://api-ai.cms-test.poly.edu.vn/api/health
```

Kiểm tra phiên bản thực tế:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend \
  python -c "from app.core.config import settings; print(settings.app_version)"
```

Kết quả phải là `25.9.16.7.2.64.16.3`.
