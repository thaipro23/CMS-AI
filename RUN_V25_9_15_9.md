# Run v25.9.15.9

## Build AI Server

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production build --no-cache backend worker frontend
```

## Migration

Bản này không thêm migration mới, nhưng vẫn chạy upgrade để chắc DB ở head:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head
```

## Up container

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker frontend
```

## Nếu có sửa connector plugin trong CMS

Copy plugin vào Open edX CMS repo/mount rồi restart:

```bash
cp openedx-connector-plugin/openedx_ai_connector/views.py /opt/openedx/CMS-FPT/openedx_connector_plugin/openedx_ai_connector/views.py
cp openedx-connector-plugin/openedx_ai_connector/urls.py /opt/openedx/CMS-FPT/openedx_connector_plugin/openedx_ai_connector/urls.py
tutor local restart cms cms-worker
```
