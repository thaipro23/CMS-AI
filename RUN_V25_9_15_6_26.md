# v25.9.15.6.26 - Bank Quiz UX + Sidebar Polish

## Mục tiêu

Bản này chỉ sửa frontend AI Server để trang `/bank/quiz` dễ dùng hơn, giảm thao tác kéo lên/kéo xuống khi tạo Quiz.

## Thay đổi chính

- `/bank/quiz` chuyển sang layout workbench 2 cột:
  - Kết quả map + lịch sử ở cột nội dung chính.
  - Cấu hình Course ID, số câu, độ khó, timer ở panel sticky bên phải.
- Panel cấu hình bám theo màn hình, có đủ action:
  - Tự tìm version và Section.
  - Lưu mapping tự động.
  - Tạo Quiz cho toàn bộ bài sẵn sàng.
- Thêm summary cards ở trên kết quả:
  - Course.
  - Version môn.
  - Release đã publish.
  - Section đã khớp.
  - Số bài sẵn sàng.
- Bổ sung CSS còn thiếu:
  - `.alert`
  - `.card-soft`
  - `.toggle-line`
  - `.option-grid`
  - các class riêng cho quiz workbench.
- Sidebar được nhóm lại và thêm icon:
  - Ngân hàng đề.
  - Tạo & duyệt.
  - Vận hành.
  - Quản trị.

## Deploy

Bản này là frontend-only. Cần build lại frontend AI Server, không cần migrate DB.

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build --no-cache frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

Nếu Docker Hub lỗi khi pull image node, thử build không no-cache:

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```
