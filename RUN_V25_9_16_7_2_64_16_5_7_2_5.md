# Deploy v25.9.16.7.2.64.16.5.7.2.5 — Batch 35.1

## 1. Chuẩn bị và backup source

```bash
cd /opt/ai-server
cp -a . /opt/ai-server-backup-before-batch35-1-$(date +%Y%m%d-%H%M%S)
```

Không dùng `docker compose down -v`, không xóa volume và không sửa tay `alembic_version`.

## 2. Chép source

```bash
rm -rf /tmp/batch35-1-deploy
mkdir -p /tmp/batch35-1-deploy
unzip -q /tmp/ai-server-openedx-v25.9.16.7.2.64.16.5.7.2.5-udemy-ui-ux-contract-batch35.1.zip -d /tmp/batch35-1-deploy
PATCH_ROOT=/tmp/batch35-1-deploy/ai_server_openedx_v25_9_16_7_2_64_16_5_7_2_5
cp -a "$PATCH_ROOT"/. /opt/ai-server/
sed -i 's/^APP_VERSION=.*/APP_VERSION=25.9.16.7.2.64.16.5.7.2.5/' .env.production
```

## 3. Validate Compose

```bash
docker compose --env-file .env.production -f docker-compose.prod.yml config >/tmp/compose-batch35-1.yml
```

## 4. Build frontend trong tmux

```bash
tmux new -s batch35-1
cd /opt/ai-server
docker compose --env-file .env.production -f docker-compose.prod.yml build frontend \
  2>&1 | tee /tmp/batch35-1-frontend-build.log
```

## 5. Recreate frontend

```bash
docker compose --env-file .env.production -f docker-compose.prod.yml \
  up -d --no-deps --force-recreate frontend
```

Batch 35.1 không có migration mới. Không cần rebuild worker, worker-heavy, beat, Open edX connector, Unit Reset hoặc Learning MFE.

## 6. Browser UAT

Thực hiện `docs/UDEMY_UI_UX_CONTRACT_BATCH_35_1.md`. Kiểm tra thêm:

```bash
docker compose --env-file .env.production -f docker-compose.prod.yml logs --tail=200 frontend
```

Deploy lại source Batch 35 `.2.4` và recreate `frontend`. Không downgrade Alembic vì Batch 35.1 không thay đổi schema.
