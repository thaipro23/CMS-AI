# v25.9.16.7.2.35 — Analytics Post-Ingest Recalculate Orchestrator

## Mục tiêu

Bản `.35` nâng từ `.34` để biến pipeline học online thành production-friendly: ingest tracking.log vẫn có thể chạy mỗi phút, nhưng recalculate không rebuild toàn bộ hệ thống. Sau mỗi batch ingest, hệ thống chỉ enqueue các lớp/course có event mới, có cooldown và giới hạn số job để không làm nghẽn worker/DB.

Các thay đổi chính:

1. Sau ingest, hệ thống lấy `course_id`/`username` có event mới trong batch vừa đọc.
2. Resolve `course_id` sang `class_id` bằng `AcademicClassCourseMapping` trước, sau đó fallback qua `AcademicCourseMapping` theo term/subject/block/campus/branch.
3. Enqueue `analytics_class_recalculate_task` theo lớp/course, không enqueue theo từng sinh viên.
4. Có throttle production:
   - không enqueue nếu lớp đã có job `queued/running`;
   - không enqueue lại lớp vừa tạo job trong cooldown;
   - giới hạn số job sau mỗi ingest;
   - tôn trọng giới hạn active analytics jobs.
5. Nếu thiếu mapping Bài/Session/video, job vẫn chạy qua rule hiện có để sinh snapshot mềm `Chưa đủ dữ liệu`, không làm UI báo sai `0 sinh viên`.
6. Không có migration mới. Reuse bảng `academic_class_sync_jobs` và `analytics_ingest_checkpoints`.

## Deploy

```bash
cd /opt/ai-server

unzip -o ai-server-openedx-v25.9.16.7.2.35-analytics-post-ingest-recalculate-orchestrator.zip -d /tmp/ai-server-v25.9.16.7.2.35

rsync -a --delete /tmp/ai-server-v25.9.16.7.2.35/ai_server_openedx_v25_9_16_7_2_35/ /opt/ai-server/

docker compose -f docker-compose.prod.yml --env-file .env.production build backend frontend worker beat

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend worker beat
```

Không có migration mới. Latest migration vẫn là:

```text
0052_v25_9_16_7_2_27_learning_behavior_logic_calibration.py
```

## Env production nên set rõ

```env
APP_VERSION=25.9.16.7.2.35
NEXT_PUBLIC_APP_VERSION=25.9.16.7.2.35

# Ingest chạy mỗi phút, nhưng recalculate được debounce/cap để an toàn.
ANALYTICS_INGEST_ENABLED=true
ANALYTICS_INGEST_SCHEDULER_ENABLED=true
ANALYTICS_INGEST_INTERVAL_SECONDS=60
ANALYTICS_POST_INGEST_RECALCULATE_ENABLED=true
ANALYTICS_POST_INGEST_RECALCULATE_COOLDOWN_SECONDS=900
ANALYTICS_POST_INGEST_RECALCULATE_MAX_JOBS_PER_RUN=10
ANALYTICS_BACKFILL_MAX_ACTIVE_JOBS=20
```

Gợi ý sizing ban đầu cho UAT khoảng 5.000 sinh viên, 300 course, 15.000 lượt học/kỳ:

```text
ANALYTICS_INGEST_INTERVAL_SECONDS=60
ANALYTICS_MAX_LINES_PER_RUN=50000
ANALYTICS_POST_INGEST_RECALCULATE_COOLDOWN_SECONDS=900
ANALYTICS_POST_INGEST_RECALCULATE_MAX_JOBS_PER_RUN=5-10
ANALYTICS_BACKFILL_MAX_ACTIVE_JOBS=10-20
```

Không nên đặt `MAX_JOBS_PER_RUN` quá cao ngay từ đầu. Tăng dần sau khi quan sát CPU, DB connections, query time và độ trễ `/jobs`.

## Test sau deploy

### 1. Beat/worker/health

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production ps

docker compose -f docker-compose.prod.yml --env-file .env.production exec backend alembic current

curl -sS https://api-ai.cms-test.poly.edu.vn/api/health | jq
```

Kỳ vọng:

```text
Backend/frontend hiển thị version 25.9.16.7.2.35 nếu env production đã set đúng.
Alembic current vẫn ở head 0052.
worker và beat đều Up.
```

### 2. Ingest có orchestrator

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production logs --tail=200 worker | grep -E "analytics_ingest_task|analytics_class_recalculate_task|post_ingest"
```

Hoặc kiểm tra DB/job qua API `/jobs`.

Kỳ vọng:

```text
Sau ingest có event mới, /jobs xuất hiện job loại Tính lại học online.
Không tạo tràn lan job cho cùng một lớp mỗi phút.
Job request_json có source=analytics_ingest_task và cooldown_seconds.
```

### 3. Kết quả học online theo roster AP

Mở:

```text
/analytics/learning?step=results&branch=poly&term_id=<TERM_ID>&campus=all&subject_id=<SUBJECT_ID>&class_id=<CLASS_ID>
```

Kỳ vọng:

```text
Tổng sinh viên lấy theo roster AP của lớp.
Có chỉ số Snapshot nhận định dạng snapshot_count/roster_count.
Có chỉ số Thiếu snapshot.
Sinh viên thiếu snapshot vẫn hiện trong bảng với nhãn Chưa đủ dữ liệu.
```
