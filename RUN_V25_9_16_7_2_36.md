# v25.9.16.7.2.36 — Responsive Sidebar Shell Fix + Analytics Orchestrator QA

## Mục tiêu

Bản `.36` nâng từ `.35` để xử lý lỗi sidebar đang thấy trên UAT/mobile emulation: menu bị chuyển thành block 2 cột, chiếm quá nhiều chiều rộng, làm vùng nội dung bị đẩy lệch và desktop/laptop nhỏ bị cắt nhãn.

Bản này vẫn giữ nguyên Analytics Post-Ingest Recalculate Orchestrator của `.35`: ingest tracking.log có thể chạy mỗi phút, nhưng recalculate chỉ enqueue theo lớp/course có event mới, có cooldown và giới hạn job.

## Thay đổi chính

1. Desktop/laptop `>1024px`: sidebar trái giữ layout một cột ổn định, không bị rule cũ `repeat(2, ...)` làm thành hai cột trong rail hẹp.
2. Tablet/mobile `<=1024px`: sidebar chuyển thành command strip ngang, `width: 100%`, `max-width: 100vw`, nav scroll ngang trong chính khung menu.
3. Mobile nhỏ `<=480px`: item nav gọn hơn, ẩn icon để dành chỗ cho nhãn, không tạo page-level horizontal overflow.
4. Ẩn badge phụ `Enterprise console` trên mobile để tránh làm brand/header đẩy chiều ngang.
5. Chặn overflow ngang ở `html/body/app-layout/main-area` cho shell responsive.
6. Không có migration mới. Reuse toàn bộ schema `.35`.

## Deploy

```bash
cd /opt/ai-server

unzip -o ai-server-openedx-v25.9.16.7.2.36-responsive-sidebar-shell-fix-analytics-orchestrator-qa.zip -d /tmp/ai-server-v25.9.16.7.2.36

rsync -a --delete /tmp/ai-server-v25.9.16.7.2.36/ai_server_openedx_v25_9_16_7_2_36/ /opt/ai-server/

docker compose -f docker-compose.prod.yml --env-file .env.production build backend frontend worker beat

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend worker beat
```

Không có migration mới. Latest migration vẫn là:

```text
0052_v25_9_16_7_2_27_learning_behavior_logic_calibration.py
```

