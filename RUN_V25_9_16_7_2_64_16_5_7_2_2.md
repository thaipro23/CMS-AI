# Run v25.9.16.7.2.64.16.5.7.2.2

## Purpose

Fix browser preflight requests to AI API when the frontend sends `X-Request-ID`.

## Deploy

```bash
cd /opt/ai-server
git pull

chmod +x scripts/cors-request-id-preflight-report.sh
./scripts/cors-request-id-preflight-report.sh

docker compose \
  -f docker-compose.prod.yml \
  --env-file .env.production \
  build backend

docker compose \
  -f docker-compose.prod.yml \
  --env-file .env.production \
  up -d --no-build --force-recreate backend
```

No migration is required. Frontend and workers do not need rebuilding for this hotfix.

## Confirm backend health

```bash
docker compose \
  -f docker-compose.prod.yml \
  --env-file .env.production \
  ps -a

docker logs ai-backend --tail=200
```

## Test the actual UAT preflight

```bash
curl -i -X OPTIONS \
  'http://api-ai.cms-test.poly.edu.vn/api/auth/openedx-session/exchange' \
  -H 'Origin: http://ai.cms-test.poly.edu.vn' \
  -H 'Access-Control-Request-Method: POST' \
  -H 'Access-Control-Request-Headers: content-type,x-request-id'
```

Expected:

- HTTP 200 or 204;
- `access-control-allow-origin: http://ai.cms-test.poly.edu.vn`;
- `access-control-allow-credentials: true`;
- `access-control-allow-headers` contains `X-Request-ID`.

Then open an incognito browser session and retry CMS → AI Server SSO.
