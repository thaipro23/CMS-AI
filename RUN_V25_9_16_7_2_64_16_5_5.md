## 1. Backup và kiểm tra hiện trạng

```bash
cd /opt/ai-server
docker compose -f docker-compose.prod.yml --env-file .env.production ps
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend alembic -c alembic.ini current
```

Không dùng `docker compose down -v`.

## 3. Giải nén và đồng bộ source

```bash
rm -rf /tmp/ai-server-v25.9.16.7.2.64.16.5.5
mkdir -p /tmp/ai-server-v25.9.16.7.2.64.16.5.5
unzip -q ai-server-openedx-v25.9.16.7.2.64.16.5.5-performance-worker-reliability.zip \
  -d /tmp/ai-server-v25.9.16.7.2.64.16.5.5
rsync -a --delete \
  /tmp/ai-server-v25.9.16.7.2.64.16.5.5/ai_server_openedx_v25_9_16_7_2_64_16_5_5/ \
  /opt/ai-server/
```

## 4. Build và triển khai

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production \
  build backend frontend worker worker-heavy worker-analytics beat

docker compose -f docker-compose.prod.yml --env-file .env.production \
  up -d --force-recreate backend frontend worker worker-heavy worker-analytics beat
```

Không có migration mới nhưng backend startup vẫn xác minh Alembic head hiện tại.

## 5. Kiểm tra sau deploy

```bash
./scripts/backend-runtime-name-audit.sh /tmp/runtime-audit
./scripts/performance-worker-reliability-report.sh /tmp/performance-worker

docker compose -f docker-compose.prod.yml --env-file .env.production ps
docker compose -f docker-compose.prod.yml --env-file .env.production logs --since=10m \
  backend worker worker-heavy worker-analytics beat
```

Smoke test:

1. Xuất báo cáo giảng viên nhỏ vẫn tải trực tiếp.
2. Xuất lớn tạo job, F5 không mất job và tải file sau khi hoàn tất.
3. Đóng/rời trang đang chờ job phải hủy polling.
4. Session hết hạn chuyển tới trang đăng xuất thay vì loading vô hạn.
5. Gán quyền tìm kiếm scope theo server, không tải toàn bộ 15.000 bài.
6. Xác minh task đi đúng queue bằng Celery inspect/log.
