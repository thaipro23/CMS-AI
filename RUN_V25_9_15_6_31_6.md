# v25.9.15.6.31.6 - Bank-first Operations Backend Audit Hotfix

## What changed

This build fixes the mismatch where the sidebar says the Operations/Admin pages follow the new Bank-first / Quiz-first workflow, but some pages were still reading legacy course-first data.

Updated pages:

- `/dashboard` now uses Bank overview + CourseQuizInstance + global audit/job data.
- `/jobs` now shows Generate jobs, Quiz Open edX instances, and publish/quiz/rollback audit operations.
- `/audit` now shows global Bank-first audit logs by default instead of hiding rows without `course_id`.
- `/users` now counts teacher work from audit logs, including bank changes, quiz creation, release publish, rollback, and failures.

Backend update:

- `/api/users/analytics` now includes audit-based activity counters.

## Deploy

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build --no-cache backend frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend
```

No DB migration is required.
