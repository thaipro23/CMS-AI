# Deploy v25.9.16.7.2.64.16.5.7.2.7 — Batch 35.3

```bash
cd /opt/ai-server

tmux new -s batch35-3

rm -rf /tmp/batch35-3-deploy
mkdir -p /tmp/batch35-3-deploy
unzip -q /tmp/ai-server-openedx-v25.9.16.7.2.64.16.5.7.2.7-training-platform-operations-batch35.3.zip -d /tmp/batch35-3-deploy
PATCH_ROOT=/tmp/batch35-3-deploy/ai_server_openedx_v25_9_16_7_2_64_16_5_7_2_7
cp -a "$PATCH_ROOT"/. /opt/ai-server/

sed -i 's/^APP_VERSION=.*/APP_VERSION=25.9.16.7.2.64.16.5.7.2.7/' .env.production

docker compose --env-file .env.production -f docker-compose.prod.yml config >/tmp/batch35-3-compose.yml

docker compose --env-file .env.production -f docker-compose.prod.yml build backend frontend worker worker-heavy \
  2>&1 | tee /tmp/batch35-3-build.log

docker compose --env-file .env.production -f docker-compose.prod.yml up -d --no-deps --force-recreate \
  backend frontend worker worker-heavy

docker compose --env-file .env.production -f docker-compose.prod.yml ps
```

Batch 35.3 không có migration mới. Không chạy sửa tay `alembic_version`, không reset DB và không xóa volume.
