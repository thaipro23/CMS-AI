# v25.9.16.7.2.50 — Campus RBAC Audit Hardening

## Mục tiêu

Bản này tiếp tục từ `.47` và tập trung đóng rủi ro phân quyền campus/scope ở backend cho UAT/production.

Mục tiêu là không để frontend chỉ ẩn nút trong khi backend vẫn lộ job/export/report ngoài scope. Các job học vụ chạy nền phải lưu phạm vi đã được duyệt và khi xem/tải lại phải kiểm tra lại scope.

## Thay đổi chính

- Thêm backend scope audit endpoint: `GET /api/rbac/scope-audit`.
- Thêm helper RBAC campus/scope trong `BusinessRBACService`:
  - `normalize_campus_code`
  - `campus_scope_for_user`
  - `can_access_campus`
  - `require_campus_access`
  - `ensure_requested_campus_filter_allowed`
  - `can_access_academic_scope`
  - `require_academic_scope`
- Teacher report cache/export job bị chặn nếu CAMPUS_MANAGER giới hạn scope nhưng không chọn campus cụ thể.
- Teacher report job list/detail/download lọc theo scope, không còn trả tất cả job cho mọi academic viewer.
- Bulk Auto map tất cả job cũng bị scope guard và chỉ hiển thị job phù hợp scope.
- Class sync jobs lưu `approved_campus_codes`, `approved_branch`, `approved_class_id`, `scope_enforced_by_backend` vào `request_json`.
- Không có migration mới.

## Deploy

```bash
cd /opt/ai-server
unzip -o ai-server-openedx-v25.9.16.7.2.50-campus-rbac-audit-hardening.zip -d /tmp/ai-server-v25.9.16.7.2.50
rsync -a --delete /tmp/ai-server-v25.9.16.7.2.50/ai_server_openedx_v25_9_16_7_2_48/ /opt/ai-server/
docker compose -f docker-compose.prod.yml --env-file .env.production build backend frontend worker beat
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend worker beat
```

## Verify nhanh

```bash
curl -sS 'https://api-ai.cms-test.poly.edu.vn/api/rbac/scope-audit' \
  -H 'Authorization: Bearer <TOKEN>' | jq

curl -sS 'https://api-ai.cms-test.poly.edu.vn/api/academic/training/teachers/report-jobs?status=all' \
  -H 'Authorization: Bearer <TOKEN>' | jq

curl -sS 'https://api-ai.cms-test.poly.edu.vn/api/academic/bulk-operation-jobs?status=all' \
  -H 'Authorization: Bearer <TOKEN>' | jq
```

Kỳ vọng:

- SYSTEM_ADMIN thấy toàn hệ thống.
- CAMPUS_MANAGER scope `ph` chỉ thấy job/report thuộc `ph` hoặc job do chính họ tạo trong scope hợp lệ.
- CAMPUS_MANAGER giới hạn scope không thể tạo teacher report export/cache với `campus` trống.
- Job detail/download ngoài scope trả 403.
