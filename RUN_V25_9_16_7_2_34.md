# v25.9.16.7.2.34 — Production Polish Version Sync + Analytics Roster QA

## Mục tiêu

Bản `.34` là bản polish production sau `.33`, tập trung vào việc khóa baseline đúng và làm rõ trạng thái dữ liệu học online:

1. Đồng bộ version/fallback từ backend, frontend, Docker compose, env example và footer UI về `25.9.16.7.2.34`.
2. Dọn changelog/RUN_CURRENT để không còn heading/fallback `.32` gây nhầm khi deploy.
3. `/analytics/learning` hiển thị rõ độ phủ snapshot: tổng roster AP, số snapshot nhận định đã có, số sinh viên còn thiếu snapshot.
4. Giữ nguyên nguyên tắc `.33`: sinh viên trong roster AP nhưng chưa có behavior snapshot vẫn hiện là `Chưa đủ dữ liệu`, không báo sai `0 sinh viên`.

## Deploy

```bash
cd /opt/ai-server

unzip -o ai-server-openedx-v25.9.16.7.2.34-production-polish-version-sync-analytics-roster-qa.zip -d /tmp/ai-server-v25.9.16.7.2.34

rsync -a --delete /tmp/ai-server-v25.9.16.7.2.34/ai_server_openedx_v25_9_16_7_2_34/ /opt/ai-server/

docker compose -f docker-compose.prod.yml --env-file .env.production build backend frontend worker

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend worker
```

Không có migration mới. Latest migration vẫn là:

```text
0052_v25_9_16_7_2_27_learning_behavior_logic_calibration.py
```

## Test sau deploy

### 1. Version/health

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production ps

docker compose -f docker-compose.prod.yml --env-file .env.production exec backend alembic current

curl -sS https://api-ai.cms-test.poly.edu.vn/api/health | jq
```

Kỳ vọng:

```text
Backend/frontend hiển thị version 25.9.16.7.2.34 nếu env production đã set đúng.
Alembic current vẫn ở head 0052.
```

### 2. Kết quả học online theo roster AP

Mở:

```text
/analytics/learning?step=results&branch=poly&term_id=<TERM_ID>&campus=all&subject_id=<SUBJECT_ID>&class_id=<CLASS_ID>
```

Kỳ vọng:

```text
Tổng sinh viên lấy theo roster AP của lớp.
Có chỉ số Snapshot nhận định dạng snapshot_count/roster_count.
Có chỉ số Thiếu snapshot.
Sinh viên thiếu snapshot vẫn hiện trong bảng với nhãn Chưa đủ dữ liệu.
Nếu đã có video/session progress nhưng chưa có behavior snapshot, dòng có lý do NO_BEHAVIOR_SNAPSHOT + HAS_LEARNING_ACTIVITY.
```
