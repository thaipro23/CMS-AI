## Nguyên tắc an toàn

- Không chạy `docker compose down -v`.
- Không reset database hoặc xóa volume.
- Không sửa tay `alembic_version`.
- Không có migration mới trong `.64.16.5`; Alembic head vẫn là `0052`.
- Backup database và `.env.production` trước khi triển khai.

## Triển khai

```bash
cd /opt/ai-server

rm -rf /tmp/ai-server-v25.9.16.7.2.64.16.5
mkdir -p /tmp/ai-server-v25.9.16.7.2.64.16.5

unzip -q ai-server-openedx-v25.9.16.7.2.64.16.5-production-ux-acceptance.zip \
  -d /tmp/ai-server-v25.9.16.7.2.64.16.5

rsync -a --delete \
  /tmp/ai-server-v25.9.16.7.2.64.16.5/ai_server_openedx_v25_9_16_7_2_64_16_5/ \
  /opt/ai-server/
```

Cấu hình version production:

```env
APP_VERSION=25.9.16.7.2.64.16.5
NEXT_PUBLIC_APP_VERSION=25.9.16.7.2.64.16.5
NEXT_PUBLIC_APP_ENV=production
NEXT_PUBLIC_ENABLE_DIAGNOSTICS_UI=false
AUTH_COOKIE_SECURE=true
AUTH_COOKIE_SAMESITE=lax
```

Build và recreate:

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production \
  build backend frontend worker beat

docker compose -f docker-compose.prod.yml --env-file .env.production \
  up -d --force-recreate backend frontend worker beat
```

## Kiểm tra runtime

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production ps

docker compose -f docker-compose.prod.yml --env-file .env.production \
  exec backend alembic -c alembic.ini current

docker compose -f docker-compose.prod.yml --env-file .env.production \
  exec backend python -c "from app.core.config import settings; print(settings.app_version)"
```
