# Deploy v25.9.16.7.2.64.16.5.7.2.4 — Batch 35

## 1. Chuẩn bị

```bash
cd /opt/ai-server
cp -a . /opt/ai-server-backup-before-batch35-$(date +%Y%m%d-%H%M%S)
```

Không dùng `docker compose down -v`, không xóa volume và không sửa tay `alembic_version`.

## 2. Chép source Batch 35

```bash
rm -rf /tmp/batch35-deploy
mkdir -p /tmp/batch35-deploy
unzip -q /tmp/ai-server-openedx-v25.9.16.7.2.64.16.5.7.2.4-udemy-production-hardening-batch35.zip -d /tmp/batch35-deploy
PATCH_ROOT=/tmp/batch35-deploy/ai_server_openedx_v25_9_16_7_2_64_16_5_7_2_4
cp -a "$PATCH_ROOT"/. /opt/ai-server/
```

## 3. Cập nhật `.env.production`

```bash
sed -i 's/^APP_VERSION=.*/APP_VERSION=25.9.16.7.2.64.16.5.7.2.4/' .env.production
```

Bổ sung các biến `ACADEMIC_UDEMY_*` từ `.env.production.example`. Giá trị mặc định production:

```env
ACADEMIC_UDEMY_IMPORT_MAX_FILES=50
ACADEMIC_UDEMY_IMPORT_MAX_FILE_BYTES=20971520
ACADEMIC_UDEMY_IMPORT_MAX_TOTAL_BYTES=209715200
ACADEMIC_UDEMY_IMPORT_MAX_ROWS=300000
ACADEMIC_UDEMY_XLSX_MAX_ENTRIES=10000
ACADEMIC_UDEMY_XLSX_MAX_UNCOMPRESSED_BYTES=419430400
ACADEMIC_UDEMY_XLSX_MAX_COMPRESSION_RATIO=200
ACADEMIC_UDEMY_UPLOAD_RATE_LIMIT_PER_MINUTE=6
ACADEMIC_UDEMY_FILE_RETENTION_HOURS=72
ACADEMIC_UDEMY_EXPORT_FILE_RETENTION_HOURS=48
ACADEMIC_UDEMY_SYNC_EXPORT_MAX_ROWS=5000
ACADEMIC_UDEMY_WORKER_MAX_RETRIES=3
ACADEMIC_UDEMY_CLEANUP_INTERVAL_SECONDS=21600
```

## 4. Validate Compose

```bash
docker compose \
  --env-file .env.production \
  -f docker-compose.prod.yml \
  config >/tmp/compose-batch35.yml
```

## 5. Build trong tmux

```bash
tmux new -s batch35
cd /opt/ai-server
docker compose \
  --env-file .env.production \
  -f docker-compose.prod.yml \
  build backend frontend worker-heavy beat \
  2>&1 | tee /tmp/batch35-build.log
```

## 6. Migration

```bash
docker compose \
  --env-file .env.production \
  -f docker-compose.prod.yml \
  run --rm --no-deps backend \
  alembic -c alembic.ini upgrade head
```

Xác nhận:

```bash
docker compose \
  --env-file .env.production \
  -f docker-compose.prod.yml \
  run --rm --no-deps backend \
  alembic -c alembic.ini current
```

Kết quả mong đợi:

```text
0057_v25_9_16_7_2_64_35 (head)
```

## 7. Recreate service

```bash
docker compose \
  --env-file .env.production \
  -f docker-compose.prod.yml \
  up -d --no-deps --force-recreate \
  backend frontend worker-heavy beat
```

Không cần rebuild/redeploy Open edX connector, Unit Reset hoặc Learning MFE.

## 8. Kiểm tra runtime

```bash
docker compose --env-file .env.production -f docker-compose.prod.yml ps
docker compose --env-file .env.production -f docker-compose.prod.yml logs --tail=200 backend
docker compose --env-file .env.production -f docker-compose.prod.yml logs --tail=200 worker-heavy
docker compose --env-file .env.production -f docker-compose.prod.yml logs --tail=200 beat
```

Kiểm tra worker:

```bash
docker compose --env-file .env.production -f docker-compose.prod.yml exec worker-heavy \
  sh -lc 'celery -A app.worker.celery_app inspect ping -d worker-heavy@$(hostname) --timeout=8'
```

## 9. UAT

Thực hiện checklist trong `docs/UDEMY_PRODUCTION_HARDENING_BATCH_35.md`. Chỉ chấp nhận production sau khi có evidence Docker build, migration, Redis/Celery, browser/RBAC và backup/restore.

## Rollback

1. Dừng tạo import/export mới.
2. Deploy lại source Batch 34.
3. Nếu cần rollback schema, chạy `alembic downgrade 0056_v25_9_16_7_2_64_33`; thao tác này chỉ gỡ ba index Batch 35.
4. Không xóa dữ liệu Udemy và không reset volume.
