# Deploy v25.9.16.7.2.64.16.5.7.2.6 — Batch 35.2

## 1. Backup source

```bash
cd /opt/ai-server
cp -a . /opt/ai-server-backup-before-batch35-2-$(date +%Y%m%d-%H%M%S)
```

Không dùng `docker compose down -v`, không xóa volume và không sửa tay `alembic_version`.

## 2. Chép source

```bash
rm -rf /tmp/batch35-2-deploy
mkdir -p /tmp/batch35-2-deploy
unzip -q /tmp/ai-server-openedx-v25.9.16.7.2.64.16.5.7.2.6-term-subject-management-batch35.2.zip -d /tmp/batch35-2-deploy
PATCH_ROOT=/tmp/batch35-2-deploy/ai_server_openedx_v25_9_16_7_2_64_16_5_7_2_6
cp -a "$PATCH_ROOT"/. /opt/ai-server/
sed -i 's/^APP_VERSION=.*/APP_VERSION=25.9.16.7.2.64.16.5.7.2.6/' .env.production
```

## 3. Validate Compose

```bash
docker compose --env-file .env.production -f docker-compose.prod.yml config >/tmp/compose-batch35-2.yml
```

## 4. Build trong tmux

Batch này thay đổi API, service dùng trong worker sync và frontend:

```bash
tmux new -s batch35-2
cd /opt/ai-server
docker compose --env-file .env.production -f docker-compose.prod.yml \
  build backend worker frontend \
  2>&1 | tee /tmp/batch35-2-build.log
```

## 5. Recreate

```bash
docker compose --env-file .env.production -f docker-compose.prod.yml \
  up -d --no-deps --force-recreate backend worker frontend
```

Không chạy Alembic; Batch 35.2 không có migration mới.

## 6. Kiểm tra log

```bash
docker compose --env-file .env.production -f docker-compose.prod.yml \
  logs --tail=300 backend worker frontend
```

Không được còn:

```text
psycopg.errors.GroupingError
column "academic_classes.branch" must appear in the GROUP BY clause
```

## 7. Smoke API

Mở `/subject-management`, chọn Hệ và Học kỳ. Network request phải có:

```text
GET /api/academic/subject-deliveries?...&management_scope=term
```

và không gửi `block_id`.

## Rollback

Deploy lại source Batch 35.1 và recreate `backend worker frontend`. Không downgrade Alembic.
