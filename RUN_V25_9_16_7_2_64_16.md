# Deploy v25.9.16.7.2.64.16 — Production

Artifact:

```text
ai-server-openedx-v25.9.16.7.2.64.16-app-shell-enterprise-ui-production.zip
```

Root:

```text
ai_server_openedx_v25_9_16_7_2_64_16
```

## 1. Sao lưu cấu hình và xác nhận database

```bash
cd /opt/ai-server
cp .env.production ".env.production.backup.$(date +%Y%m%d-%H%M%S)"

docker compose -f docker-compose.prod.yml --env-file .env.production exec backend \
  alembic -c alembic.ini current
```

Migration phải đang ở `0052_v25_9_16_7_2_27_learning_behavior_logic_calibration` hoặc được backend nâng đến head khi khởi động. Bản `.64.16` không có migration mới.

## 2. Giải nén và đồng bộ source

```bash
rm -rf /tmp/ai-server-v25.9.16.7.2.64.16
mkdir -p /tmp/ai-server-v25.9.16.7.2.64.16

unzip -q ai-server-openedx-v25.9.16.7.2.64.16-app-shell-enterprise-ui-production.zip \
  -d /tmp/ai-server-v25.9.16.7.2.64.16

rsync -a --delete \
  /tmp/ai-server-v25.9.16.7.2.64.16/ai_server_openedx_v25_9_16_7_2_64_16/ \
  /opt/ai-server/
```

Không chạy `docker compose down -v`.

## 3. Cấu hình production bắt buộc

```env
APP_ENV=production
APP_VERSION=25.9.16.7.2.64.16
NEXT_PUBLIC_APP_ENV=production
NEXT_PUBLIC_ENABLE_DIAGNOSTICS_UI=false
NEXT_PUBLIC_APP_VERSION=25.9.16.7.2.64.16

AUTH_MODE=openedx_sso
ALLOW_DEMO_ROLE_HEADER=false
AUTH_COOKIE_SECURE=true
AUTH_COOKIE_SAMESITE=lax
DEBUG=false
AUTO_CREATE_TABLES=false
DB_STATEMENT_TIMEOUT_MS=5000
```

CORS public chỉ dùng HTTPS. Không để origin HTTP/local trong whitelist production.

## 4. Build và triển khai

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production \
  build backend worker beat frontend

docker compose -f docker-compose.prod.yml --env-file .env.production \
  up -d --force-recreate backend worker beat frontend
```
