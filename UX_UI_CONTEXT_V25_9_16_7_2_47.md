# UX/UI Context v25.9.16.7.2.50

## Scope

`/bank/quiz` is now a production-oriented assessment mapping workbench. The screen must make it clear which rows create Quiz, which rows create Final test, and which rows are skipped.

## Rules

- Final test defaults to `Tạo Final test`.
- Assignment/ASM defaults to `Không tạo`.
- `Không tạo` never requires Bank Release or Open edX Section.
- Operators must see why a row is blocked: missing Section, missing Release, or both.
- Tables must keep horizontal overflow inside their own wrapper.
