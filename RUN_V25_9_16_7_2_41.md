# v25.9.16.7.2.41 — Bank Entity Actions Visible Fix

## Mục tiêu

Sửa lỗi UX/UI ở các bảng compact của Ngân hàng đề: cột **Thao tác** bị trống/không hiển thị đúng sau khi chuyển từ card lớn sang bảng ở bản `.38`.

Bản này giữ nguyên logic `.40` về username sinh viên bằng RollNumber. Không có thay đổi auth, không có migration mới.

## Thay đổi chính

1. Các bảng Bank hierarchy hiển thị thao tác dạng inline trong cột `Thao tác`:
   - `/bank/departments`
   - `/bank/departments/{departmentId}/subjects`
   - `/bank/subjects/{subjectId}/versions`
   - `/bank/subject-versions/{versionId}/chapters`

2. Không còn dùng menu `⋮` absolute trong bảng compact vì dễ bị clip bởi khung scroll ngang.

3. Dòng có quyền quản lý hiển thị rõ:
   - `Sửa`
   - `Xóa`

4. Dòng đã publish/khóa hiển thị:
   - `Đã khóa`

5. Dòng không đủ quyền hiển thị:
   - `Không có quyền`

6. Giữ nguyên:
   - `.40` CMS Student Username RollNumber Only.
   - `.38` Bank Compact Table UX + Sidebar Taxonomy.
   - `.37` Analytics Class Result Doctor.
   - `.36` Responsive Sidebar Shell Fix.
   - `.35` Analytics Post-Ingest Recalculate Orchestrator.

## Deploy

```bash
cd /opt/ai-server

unzip -o ai-server-openedx-v25.9.16.7.2.41-bank-entity-actions-visible-fix.zip -d /tmp/ai-server-v25.9.16.7.2.41

rsync -a --delete /tmp/ai-server-v25.9.16.7.2.41/ai_server_openedx_v25_9_16_7_2_41/ /opt/ai-server/

docker compose -f docker-compose.prod.yml --env-file .env.production build backend frontend worker beat

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend worker beat
```

## Env production nên set rõ

```env
APP_VERSION=25.9.16.7.2.41
NEXT_PUBLIC_APP_VERSION=25.9.16.7.2.41
```

## Test sau deploy

1. Vào các màn Bank dạng bảng.
2. Kiểm tra cột `Thao tác` luôn có nội dung: `Sửa/Xóa`, `Đã khóa`, hoặc `Không có quyền`.
3. Với subject version/chapter đã đưa lên CMS, xác nhận không còn ô thao tác trống mà hiện `Đã khóa`.
4. Mở mobile/tablet, xác nhận bảng vẫn scroll ngang trong khung riêng.
