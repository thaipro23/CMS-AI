# Triển khai v25.9.16.7.2.64.16.5.7.2

## 1. Phạm vi

Bản này tiếp tục trực tiếp từ `.64.16.5.7.1.1`, đóng contract thiết kế frontend toàn hệ thống và bổ sung batch API cho gán nhiều phạm vi RBAC. Không có migration mới; Alembic head vẫn là `0053_v25_9_16_7_2_64_16_5_4_diff_idempotency.py`.

## 2. Cập nhật source

```bash
cd /opt/ai-server
git pull
```

Không chạy `docker compose down -v`, không xóa volume và không sửa `alembic_version`.

## 3. Kiểm tra cấu hình build nhanh

Trong `.env.production` nên có:

```env
FRONTEND_NPM_VERSION=10.9.2
FRONTEND_VALIDATE_IN_IMAGE=false
```

`FRONTEND_VALIDATE_IN_IMAGE=false` chỉ bỏ việc chạy lặp lint/typecheck bên trong Docker image. `next build` vẫn luôn chạy. Lint và TypeScript đã được kiểm tra trước khi phát hành.

Với UAT HTTP, giữ:

```env
APP_ENV=uat
AUTH_COOKIE_SECURE=false
ALLOW_INSECURE_UAT_HTTP=true
AUTH_COOKIE_SAMESITE=lax
```

## 4. Chạy source gate

```bash
chmod +x scripts/full-frontend-design-contract-report.sh
./scripts/full-frontend-design-contract-report.sh
```

Kỳ vọng:

```text
READY — 30/30
```

## 5. Build

Không dùng `--no-cache` cho deploy bình thường:

```bash
docker compose \
  -f docker-compose.prod.yml \
  --env-file .env.production \
  build frontend backend worker worker-heavy worker-analytics beat runtime-init migrate
```

Bản này đặt `webpackBuildWorker: false` để tránh child-process build worker bị treo trên UAT tài nguyên hạn chế.

## 6. Migration

Không có migration mới nhưng vẫn có thể xác nhận head bằng service chuyên dụng:

```bash
docker compose \
  -f docker-compose.prod.yml \
  --env-file .env.production \
  run --rm migrate
```

## 7. Khởi động

```bash
docker compose \
  -f docker-compose.prod.yml \
  --env-file .env.production \
  up -d --no-build --force-recreate \
  frontend backend worker worker-heavy worker-analytics beat
```

## 8. Kiểm tra runtime

```bash
docker compose \
  -f docker-compose.prod.yml \
  --env-file .env.production \
  ps -a

docker logs ai-backend --tail=250
docker logs ai-frontend --tail=150
```
