# v25.9.15.6.24 - Quiz Slot Concept Balance Hotfix

## Mục tiêu

Sửa bước tạo Quiz từ Bank Release để đúng quy định FPT:

- 1 câu hỏi / 1 Open edX component không được xuất hiện ở 2 slot.
- Đủ số lượng EASY / MEDIUM / HARD theo tỷ lệ người dùng nhập.
- Mỗi slot là 1 câu hiển thị (`pick_count=1`, `max_count=1`).
- Nếu đủ concept/family: 1 concept/family không bị tách sang 2 slot.
- Nếu concept/family nhiều hơn số slot: chia nguyên concept vào các slot và cân bằng số câu candidate giữa các slot.
- Nếu concept/family ít hơn số slot: soft mode, tách concept lớn ra nhiều slot để đủ số câu, có warning rõ trong plan.

## Deploy

Bản này chỉ sửa backend planner, không cần migration.

```bash
cd /opt/ai-server

docker compose -f docker-compose.prod.yml --env-file .env.production build --no-cache backend worker

docker compose -f docker-compose.prod.yml --env-file .env.production run --rm backend alembic upgrade head

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend worker
```

Không cần build frontend, không cần copy connector.

## Test nhanh

- EASY = 3 slot
- MEDIUM = 1 slot
- HARD = 1 slot

Trong Studio, Unit `Quiz` phải có 5 Problem Bank, mỗi bank `max_count=1`.

Kiểm tra plan/API response:

- không có question/component trùng giữa các slot
