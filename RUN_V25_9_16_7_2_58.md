# v25.9.16.7.2.64.13 — Security Production Hardening

Bản này tiếp tục từ `.57`, không có migration mới. Mục tiêu là bổ sung security production gate read-only trước khi pilot/production thật: auth mode, demo header, JWT/cookie, CORS, metrics token, Open edX connector HMAC, AP/OpenAI secret, upload/SSRF guard và destructive cleanup guard.

## Deploy

```bash
cd /opt/ai-server
unzip -o ai-server-openedx-v25.9.16.7.2.64.13-pilot-release-candidate.zip -d /tmp/ai-server-v25.9.16.7.2.64.13
rsync -a --delete /tmp/ai-server-v25.9.16.7.2.64.13/ai_server_openedx_v25_9_16_7_2_64_13/ /opt/ai-server/

docker compose -f docker-compose.prod.yml --env-file .env.production build backend frontend worker beat
docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate backend frontend worker beat
```

## Security readiness

```bash
curl -sS 'https://api-ai.cms-test.poly.edu.vn/api/health/security-readiness' \
  -H 'Authorization: Bearer <TOKEN>' | jq
```

Hoặc xuất báo cáo:

```bash
API_BASE_URL=https://api-ai.cms-test.poly.edu.vn/api \
TOKEN='<TOKEN>' \
OUT_DIR=/tmp/ai-security-readiness-$(date +%Y%m%d-%H%M%S) \
./scripts/security-readiness-report.sh
```

Endpoint/script chỉ đọc cấu hình đã sanitize; không trả secret, không gọi Open edX/AP/OpenAI, không enqueue job, không recalculate, không scan raw tracking.log và không mutate dữ liệu.
