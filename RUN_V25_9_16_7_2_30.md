# v25.9.16.7.2.31 — Responsive Device-Adaptive UX

## Nội dung

Bản này chuẩn hóa UX/UI cho nhiều thiết bị:

- Desktop/laptop: giữ sidebar đầy đủ, bảng dữ liệu dày nhưng không tràn layout.
- Tablet: sidebar chuyển thành thanh điều hướng ngang gọn.
- Mobile: filter, KPI, card, modal, nút thao tác tự co về 1 cột; bảng cuộn ngang trong khung riêng.
- Sticky `STT + Sinh viên` được giảm width hợp lý trên mobile.
- Thêm viewport metadata để tránh lỗi scale/zoom trên thiết bị thật.

Không có migration mới.

## Deploy

```bash
cd /opt/ai-server

unzip -o ai-server-openedx-v25.9.16.7.2.31-responsive-device-adaptive-ux.zip -d /tmp/ai-server-v25.9.16.7.2.31

rsync -a --delete /tmp/ai-server-v25.9.16.7.2.31/ai_server_openedx_v25_9_16_7_2_30/ /opt/ai-server/

docker compose -f docker-compose.prod.yml --env-file .env.production build frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --force-recreate frontend
```

Backend không đổi logic trong bản này. Nếu muốn đồng bộ version container backend thì build thêm backend/worker cũng được.

## Kiểm tra sau deploy

Kiểm tra ở 4 breakpoint:

```text
1366 x 768   laptop phổ biến
1024 x 768   tablet ngang / màn nhỏ
768 x 1024   tablet dọc
390 x 844    mobile
```

Các màn cần test nhanh:

```text
/student-management
/student-management/subjects/<subject_id>/classes
/student-management/classes/<class_id>
/teacher-management
/analytics/learning
/bank/quiz
/jobs
/audit
```

Kỳ vọng:

```text
Không có scroll ngang toàn trang.
Chỉ bảng dữ liệu được cuộn ngang trong khung riêng.
Nút thao tác không lệch kích thước.
Filter/KPI tự xuống dòng hợp lý.
Modal không vượt chiều cao màn hình.
Sidebar không chiếm hết màn trên tablet/mobile.
```
