# Run v25.9.15.0

## 1. Build AI Server only

Không down Open edX/Tutor.

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production build --no-cache backend worker frontend

docker compose -f docker-compose.prod.yml --env-file .env.production up -d --no-deps backend worker frontend
```

## 2. Run migration

```bash
docker compose -f docker-compose.prod.yml --env-file .env.production exec backend alembic upgrade head
```

Migration mới:

```text
0009_v25_9_15_0
```

## 3. Update CMS connector if needed

Bản này giữ connector native ItemBank từ 14.6.1. Nếu server chưa có 14.6.1 thì copy plugin và restart CMS:

```bash
cp openedx-connector-plugin/openedx_ai_connector/views.py \
/opt/openedx/CMS-FPT/openedx_connector_plugin/openedx_ai_connector/views.py

tutor local restart cms cms-worker
```

## 4. Open UI

```text
/bank
```

Luồng mới:

```text
Tạo Bộ môn
→ Tạo Môn
→ Tạo Chapter
→ Tạo Bank Version
→ Tạo Bank Release
→ Map Open edX course vào Môn
```

## 5. Env cần cập nhật

```env
APP_VERSION=25.9.15.0-versioned-question-bank
QUESTION_BANK_RELEASE_LIBRARY_POLICY=one_release_one_openedx_library
QUESTION_BANK_VERSIONING_ENABLED=true
```
